# 文献调研总结

## 调研范围

围绕“中文预训练语料质量特征如何通过学习动力学影响模型能力，以及这一质量--效用关系能否跨来源和模型迁移”开展调研。重点覆盖 2021--2026 年，并保留规模律、训练数据记忆与数据抽取等奠基工作。

检索主题包括：预训练数据质量、数据筛选与策展、数据价值与影响估计、数据混合与领域重加权、去重与污染、学习动力学、中文语料及跨语言迁移。过程文件显示：10 组查询返回 499 条，合并后 415 条，去重后 406 条；经题名与摘要语义审查，形成 45 条核心候选和 50 条项目 BibTeX 条目。

## 主要认识

### 1. “质量”必须分层，不能用一个分数包办

现有工作大致包含三类对象：文档内在质量（完整性、可读性、信息密度等）、集合质量（重复、覆盖、多样性与来源配比）以及模型条件效用（样本对特定模型、训练阶段和目标能力的边际贡献）。三者相关但不等价。项目应把许可、隐私和来源可追溯性作为准入约束，避免与训练效用加权抵消。

### 2. 过滤收益与覆盖损失构成核心矛盾

去重和基础清洗通常能降低记忆与冗余，但强质量过滤可能同时删除口语、方言、低频知识和特殊语体。多样性选择、网页重写和多评分器融合提供了不同缓解路径，却尚未给出跨来源稳定的统一阈值。项目应以质量收益--覆盖损失的帕累托关系为分析对象，而非预设“分数越高越好”。

### 3. 数据效用具有模型状态和训练阶段依赖

影响估计、自影响重加权、领域重加权和动态选择方法均表明，样本价值随验证目标、模型状态与训练阶段变化。固定数据质量分数忽略了模型已经掌握的知识和当前能力短板。应把梯度贡献、学习顺序、遗忘行为等训练动力学信号作为质量特征影响能力的中介变量。

### 4. 数据混合把质量评价转化为条件化资源配置

DoReMi、DoGE、数据混合律与双层优化等工作已能在代理模型上优化领域配比，但小模型得到的排序和阈值能否迁移到更大模型仍是薄弱环节。公平比较至少要明确等 token、等独立样本和等算力三种口径，并同时报告处理开销和能力覆盖。

### 5. 中文与跨语言迁移仍有明显证据缺口

中文语料具有汉字、分词、简繁、古今语体和中英混写等特点。2025 年的多语言质量过滤工作显示跨语言迁移可以改善，但不能据此假定英文质量分类器直接适用于中文。项目需设置独立中文人工复核、语言规范与语体覆盖测试，并对跨来源、跨模型阈值漂移进行校准。

## 争议与反例

- 相同 token 预算不等于相同计算开销；经过筛选的数据可能被重复训练更多轮。
- 更低验证损失不必然意味着更好的知识、推理、规范性和长尾覆盖。
- 代理模型上的数据排序可能随模型规模、架构或 tokenizer 变化。
- 基准得分可能受到训练污染和反复调参影响，不能作为唯一效用证据。
- 合成或重写数据可提高表面质量，也可能强化生成模型自身偏差。

## 对本项目的直接切入点

1. 构建“文档内在属性--集合覆盖属性--模型条件效用”三层质量表征，并用人工复核验证其可靠性。
2. 在等 token 与等算力对照中，跟踪样本学习难度、梯度贡献与遗忘行为，检验其是否中介质量特征到能力变化的关系。
3. 以质量收益和覆盖损失的联合结果比较筛选策略，而非只看单一平均分。
4. 跨公开中文语料来源、模型尺度与训练阶段复核，区分稳定规律与需校准关系。
