# 全文配色决定

采用Academic Figure Color Expert的classic分支：复杂科学流程且多个模块，选择Nature Blue；无参考图、无用户指定品牌色，不采用宣传插画。

| 语义 | 色值 |
|---|---|
| 一级容器/核心风险规则 | #1B3A5C |
| 评价及中间操作 | #2E6B9E |
| 输出/辅助结构 | #5BA0D0 |
| 文字 | #333333 |
| 箭头 | #4D4D4D |
| 所有填充/画布 | #FFFFFF |

最多三种蓝色，不按红绿区分安全结论。灰度仍由标签、位置、实线/虚线和圈方几何锚点辨认。正文插图保持白底、细边框、无渐变/阴影/3D。中文Noto Sans CJK SC，英文Arial；183mm设计宽度，主标题10—12pt、标签8—9pt、辅助7—8pt，边框1.5pt、内部线1.0pt。最终以PDF实际字号验收，不能靠不断缩图避开排版问题。
