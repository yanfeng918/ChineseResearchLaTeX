# 研究方案与技术路线

> 输入：`03_科学问题与创新点.md`。执行期按面上项目口径：**2027.01—2030.12，共 4 年**。
> 标 `【暂定 …】` 的是可推定草稿值（月份、规模、阈值），不是申请人确认值；正文沿用时保留标记。

## 一、研究目标

**总体目标**：建立面向不完备文本描述的地理实体关系证据表示与跨模态匹配方法，形成可复现的评测协议，使遥感图文检索在关系敏感场景下的失效模式可识别、可缓解、可归因。

| 子目标 | 对应子问题 | 对应研究内容 | 可验证判据 |
|---|---|---|---|
| G1 建立关系证据的三态表示与可复核标注规范 | 子问题 1 | 内容一 | 关系词表与证据字段规范定稿；挑战子集标注者间一致性达标（Cohen's κ ≥ 0.7，`【暂定】`） |
| G2 提出仅约束可核验关系、屏蔽未知态的匹配方法 | 子问题 2 | 内容二 | 三臂消融中 (c) 相对 (b) 在关系挑战集显著改善且标准 mR 不显著下降 |
| G3 建立可归因的分层评测协议 | 子问题 3 | 内容三 | 同域/迁移/独立测试分别报告；等预算对照下改进依然成立 |

## 二、研究内容与方法的一一对应

### 内容一：不完备描述条件下的地理实体关系证据建模（对应 G1）

**方法**

1. **数据审计**：对每个候选基准分层抽样【暂定 200—400 组】影像及其全部配对描述，检查实体、关系、遗漏与矛盾，记录抽样规则；统计同图多描述之间的覆盖差异分布。
2. **关系词表构建**：由审计结果自下而上确定实体类别与关系类型（方位、邻接、包含、距离分级），控制规模【暂定 ≤20 类实体、≤10 类关系】，保证每类都有可判定的判据。
3. **三态判定规范**：为每条〈实体, 关系, 实体〉三元组定义「已支持 / 明确冲突 / 未知」的判定条件与证据字段（证据来源、置信度、判定人）。**坐标系固定**：左右/上下等相对关系一律基于影像坐标系定义，旋转与翻转增强时同步变换关系标签。
4. **弱标注与人工核验分离**：训练集允许使用自动抽取的弱标注；**独立评测样本必须人工核验**，并报告标注者间一致性。

**产出证据**：数据审计报告、实体关系词表、证据字段规范、关系挑战子集【暂定 1500—2500 组，人工核验】。

### 内容二：兼顾关系判别与未知信息的跨模态匹配（对应 G2）

**方法**

以已有视觉语言编码器（CLIP `radford2021clip` / RemoteCLIP `liu2024remoteclip`）为**起点**，采用参数高效适配（`yuan2023peft`、`zhou2022cocoop`）控制训练规模，研究关系证据参与匹配的方式。核心是**三臂对照**而非堆叠模块：

| 臂 | 处理方式 | 对应现状 |
|---|---|---|
| (a) | 忽略关系 | 主流全局—局部对齐基线 |
| (b) | 未知关系按负例处理 | 现有噪声/失配抑制思路的等价物 |
| (c) | 三态区分，仅对已支持/明确冲突施加约束，未知态屏蔽监督 | **本项目主张** |

具体实现候选（**择一为主线**，其余作为消融，不并列承诺）：关系证据引导的对齐损失加权、关系一致性重排序、关系条件下的局部匹配。主线由第一年最小实验结果选定。

置信度处理可借用不确定性/证据建模工具（`chun2021pcme`、`han2021tmc`、`li2023pau`、`qin2022decl`），但建模对象是**关系命题的可判定性**，与相似度不确定性不同，须在正文中区分表述。

**产出证据**：核心方法、训练与推理代码、三臂对照与消融结果。

### 内容三：标准检索与关系挑战的联合验证（对应 G3）

**方法**

1. **标准检索**：RSITMD、RSICD 上的双向检索，严格沿用原始划分与协议，报告 R@1/R@5/R@10 与 mR。
2. **关系挑战评测**：在人工核验子集上评测关系冲突误匹配率与关系判别准确率，**与标准结果分开报告**。
3. **覆盖度稳健性**：按描述覆盖程度分档，报告性能随覆盖度的变化；同时报告真实自然样本与人工扰动样本的结果差异。
4. **可归因性控制**：等参数量/等训练步数对照；跨数据集迁移前做近重复与同源切片去重；同域比较、目标域未参与训练的迁移、真正数据独立的测试**分别定义并分别报告**。
5. **效率**：可训练参数量、训练开销、索引与查询耗时，注明硬件、图库规模与批大小。

**产出证据**：评测协议、分层结果报告、轻量检索演示与复现材料。

## 三、评测指标与统计口径

| 类别 | 指标 |
|---|---|
| 标准 | 图→文、文→图 R@1/R@5/R@10 及六项均值 mR |
| 专项 | 关系冲突误匹配率、关系判别准确率、不同覆盖度分档下的性能变化 |
| 效率 | 可训练参数量、训练时长、索引与查询耗时 |
| 统计 | 关键训练实验 ≥3 个随机种子，报告均值、标准差与置信区间；关键对比做显著性检验 |

**不预设任何提升幅度**。事实库明确禁止"mR 提升 5%""准确率 95%"等无基线支撑的承诺；若正式表格要求量化阈值，须在完成预实验后由申请人决定可承担的承诺。

## 四、技术路线（总—分）

```
                    ┌──────────────────────────────────────┐
                    │  公开遥感图文数据（RSITMD / RSICD）   │
                    │  补充：SkyScript（许可满足时，小规模）│
                    └───────────────┬──────────────────────┘
                                    │ 数据审计 + 去重（原图/近重复/同源切片）
                                    ▼
        ┌───────────────────────────────────────────────────────┐
        │ 内容一：关系证据三态建模                               │
        │  实体关系词表 → 证据字段规范 → 弱标注（训练）          │
        │                              → 人工核验（评测）        │
        └───────────────┬───────────────────────────────────────┘
                        │ 三态标签（已支持 / 明确冲突 / 未知）
                        ▼
        ┌───────────────────────────────────────────────────────┐
        │ 内容二：关系约束的跨模态匹配                           │
        │  VL 编码器（CLIP / RemoteCLIP）+ 参数高效适配          │
        │  三臂对照 (a) 无关系 (b) 未知作负例 (c) 三态+屏蔽      │
        └───────────────┬───────────────────────────────────────┘
                        │ 检索模型
                        ▼
        ┌───────────────────────────────────────────────────────┐
        │ 内容三：分层验证                                       │
        │  标准检索 │ 关系挑战 │ 覆盖度稳健性 │ 迁移 │ 效率      │
        │  等预算对照 → 可归因性结论                             │
        └───────────────┬───────────────────────────────────────┘
                        ▼
                 方法 + 协议 + 代码 + 报告 + 轻量演示
```

**反馈回路**：内容三的错误归因结果回流到内容一（修订关系词表与判定规范）与内容二（调整约束方式），每年至少一次。
