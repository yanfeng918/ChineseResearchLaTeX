综述聚焦支撑本课题设计，覆盖矿山数据、变化表征、直接近邻、校准与选择性预测、空间验证。当前文献库为 31 条，其中 23 条为 2021 年以来工作；综述实际引用 28 条，另外 3 条申请人成果用于研究基础。

本轮按 `nsfc-full-pipeline` 的专题证据预算适配文献子流程，综述目标为 2500–6000 字、25–50 条引用。脚本计数为 3079 字、28 条引用，均通过。本轮不是按独立 Premium 默认 80–150 篇门槛开展的全面系统综述，不能将“未检出等价研究”作为绝对查新证明。候选问题共用本轮证据池，并分别审查与近邻工作的区别。

检索日期为 2026-09-05，覆盖 2021–2025 完整自然年及当年进展，保留必要奠基文献。来源包括 Crossref、arXiv 作者原文、出版社、PMLR、NeurIPS、JMLR、AAAI、RODARE 和作者代码仓库。题名、作者、正式出版年份与预印本区分核验；研究设计依赖原文或摘要，不从元数据推断实验收益。

两项关键修正：MineNetCD 原协议已按矿区划分，不能作为新创评测；DonaNet 使用正式 2025 年期刊题录，加入 CDDGNet（2026）与 FCCDN 等直接近邻。Crossref 中一个题名不符的 FCCDN 候选记录已排除。RSHR+ 的正式卷期为 2026 年 10 月，当前只使用可核验题录及已确认作者贡献，在线发表日期仍需终核。

实际数据状态仍是“核验发布入口、未下载全量数据、未运行基线”。本轮只完成申请书写作所需调研和方案设计。

导出采用文献技能官方编译、转换脚本。最终 PDF 共 7 页（补齐网络来源访问日期后重编译），Word 已同步更新。首次 PDF 编译因脚本仅搜索模板目录中的 `plainnat.bst` 失败，改用技能随附 `gbt7714-nsfc` 后成功；未修改公共样式或技能代码。正式申报附件仍需从实验室获得。
