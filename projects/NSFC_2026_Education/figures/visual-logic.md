## 一、Palette Decision

### 1.1 决策清单（Decision Checklist）

| # | 检查项 | 结论 |
|---|--------|------|
| 1 | 视觉风格家族 | **Classic academic**（下游用 `academic-figure-prompt`，非 pastel） |
| 2 | 是否触发硬约束 | **是** — ①框架图 ≥4 模块（F02 五功能区、F03 五阶段+双条带）；②中文基金申请书需黑白打印友好；③色盲安全默认必选 |
| 3 | 图类型偏好 | Overall Framework（≥4 模块）→ Nature Blue；Module Detail → Blue Monochrome（作为备选） |
| 4 | venue / domain | venue = None（NSFC 地区科学基金体例 / 实验室开放课题）；domain = 多模态学习 × 知识组织 × 工程教育资源 |
| 5 | 主选 + 备选 | 主选 **Nature Blue**；备选 **Blue Monochrome** |
| 6 | Hex 来源 | `academic-figure-color-expert/references/palettes.md` 第 12 号预设 |
| 7 | 决策分支 | **scene**（场景推荐分支：≥4 模块硬约束优先于 venue/domain） |

### 1.2 选定调色板：Nature Blue

| 角色 | HEX | 用途 | 白底对比度 | 灰度明度 |
|------|-----|------|-----------|---------|
| primary | `#1B3A5C` | 一级模块边框、一级标题文字、主流程箭头 | 11.4:1 ✅ | ~21%（深） |
| secondary | `#2E6B9E` | 二级模块边框、二级标题文字、次级连接线 | 4.9:1 ✅ | ~40%（中） |
| tertiary | `#5BA0D0` | 三级/内部元素边框、分组底纹描边 — **仅用于线与填充，禁作正文文字色** | 2.5:1 ⚠️ | ~61%（浅） |
| gray | `#8EAEC4` | 弱化元素（扩展模态、非支撑信息）边框 | 2.2:1 ⚠️ | ~68%（很浅） |
| text | `#333333` | 正文与标签文字 | 12.6:1 ✅ | ~20% |
| fill | `#FFFFFF` | 画布与全部模块填充 | — | 100% |
| section_bg | `#F7F7F7` | 区域分组底色（仅泳道/条带） | — | ~97% |
| border | `#CCCCCC` | 中性分隔线、辅助边框 | — | ~80% |
| arrow | `#4D4D4D` | 通用连接线与箭头 | 8.6:1 ✅ | ~30% |

**选择理由（一句话）**：三张核心图均为 ≥4 模块的框架/流程图，单色蓝阶梯在保证模块层级可分的同时避免多色喧宾夺主，且 `#1B3A5C` 正是中文基金申请书要求的克制深藏青，黑白打印后仍靠明度差保持层级。

### 1.3 受限告警强调色（Restricted Warning Accent）

| 角色 | HEX | 用途 | 白底对比度 | 灰度明度 |
|------|-----|------|-----------|---------|
| reject | `#A64B2A` | **仅限** 拒绝出口、失效类型、错配错误、退出通道 | 6.0:1 ✅ | ~35% |

**使用约束（强制）**：

1. 该色**不是**第 4 个常规色。在使用它的图（F03、F05、F06）中，它**顶替** `#5BA0D0` 的位置，使该图有彩色数仍为 3（`#1B3A5C` + `#2E6B9E` + `#A64B2A`），满足"每图 ≤3 有彩色 + 中性色"的硬规则。
2. F01、F02、F04、F07 **不得使用** `#A64B2A`。
3. `#A64B2A`（灰度 ~35%）与 `#2E6B9E`（灰度 ~40%）在黑白打印下接近，因此凡使用该色的元素**必须同时**采用虚线描边 + 显式中文标签双重编码，不得以颜色作为唯一区分手段。

### 1.4 备选方案

**Blue Monochrome**（`#1565C0` / `#42A5F5` / `#90CAF9`，arrow `#37474F`）。仅当用户明确反馈 Nature Blue 过暗、或需与已有蓝色系插图统一时切换。切换必须整套 7 图同步，不得混用。

### 1.5 无障碍与打印说明

- **色盲安全**：全套为单一蓝色相 + 一个受限暖色，红绿色盲、蓝黄色盲下均可通过明度阶梯区分；不存在依赖红/绿对立的编码。
- **打印**：白底占画面 ≥70%，模块一律白色填充、彩色仅上边框，灰度打印后靠"边框明度 + 线型 + 标签"三重编码保持可读。
- **文字对比**：正文文字仅使用 `#333333` / `#1B3A5C` / `#2E6B9E` / `#A64B2A`，全部 ≥4.5:1；`#5BA0D0` 与 `#8EAEC4` 严禁用于文字。

### 1.6 下游交接块（Handoff）

## 二、语义色彩绑定（Semantic Color Binding）

跨全部 7 图恒定。同一功能角色在任何图中必须使用同一颜色，读者一次学会、七图通用。

| 功能角色 | 边框色 | 填充 | 说明 |
|---------|-------|------|------|
| **一级结构**：研究内容主模块（RC1/RC2/RC3）、技术路线主阶段（S1–S5）、四层门控层名 | `#1B3A5C` | `#FFFFFF` | 承载图的骨架 |
| **二级结构**：主模块内的子块、判定闸门、字段槽位、科学问题框、目标框 | `#2E6B9E` | `#FFFFFF` | 骨架内部的构成件 |
| **三级/输入素材**：模态泳道、原始材料、知识源条目、片段 | `#5BA0D0` | `#FFFFFF` | 被加工的对象 |
| **弱化信息**：扩展模态（实验代码/产业案例）、非支撑说明、范围声明 | `#8EAEC4` | `#FFFFFF` | 视觉权重最低，与标书"单独报告/不作前提"口径一致 |
| **拒绝 / 失效 / 错配 / 退出** | `#A64B2A` + 虚线 | `#FFFFFF` | 仅 F03/F05/F06；必带中文标签 |
| **区域分组容器**（泳道、条带、独立性边界） | `#CCCCCC` 或 `#1B3A5C` 虚线 | `#F7F7F7` | 底纹极淡，不与模块争对比 |
| **主指标 / take-home 强调** | `#1B3A5C` 加粗边框（1.5×） | `#FFFFFF` | 全图至多 1 处，见 §五 |

**恒定映射示例（跨图一致性锚点）**：

- 资源单元 `u=(c,a,m,e,s)` 在 F02、F03、F04 中出现时，一律为 `#1B3A5C` 边框主体框。
- 三项研究内容 RC1/RC2/RC3 在 F02、F07 中出现时，一律为 `#1B3A5C`。
- 核心模态（课程文本 / 运行曲线图表 / 设备结构图）在 F01、F02、F03、F05 中一律为 `#5BA0D0`；扩展模态（实验代码 / 产业案例）一律为 `#8EAEC4`。
- 专家盲评侧（F06）与自动门控侧使用同一 `#1B3A5C`，**独立性靠虚线边界框而非颜色区分**——避免暗示两侧地位不等。

## 三、文字层级（Text Hierarchy）

| 层级 | 用途 | 相对字号 | 字重 | 颜色 |
|------|------|---------|------|------|
| T1 | 区域/泳道大标题（如"研究内容""独立效度验证"） | 1.00（基准，最大） | Bold | `#1B3A5C` |
| T2 | 一级模块标题（RC1、S1–S5、四层层名） | 0.85 | Bold | `#1B3A5C` |
| T3 | 二级子块标题（闸门名、字段槽位名、目标名） | 0.72 | Medium | `#2E6B9E` |
| T4 | 条目正文与标签（属性项、指标名、关系类型） | 0.62 | Regular | `#333333` |
| T5 | 注记、口径声明、范围限定、连线标签 | 0.52 | Regular | `#333333`；弱化注记可用 `#4D4D4D` |
| T6 | 拒绝/失效标签 | 0.62 | Medium | `#A64B2A` |

规则：

- 单图内文字层级**不超过 4 级**，避免密度失控。
- 所有中文标签横排，**不得竖排、不得旋转**（含泳道名）。
- 数学符号（`u=(c,a,m,e,s)`、`Q(u)`、`VRR`、`C_A`、`C_E`、`C_R`、`sim`）使用衬线斜体，与中文标签形成类型对比；不排完整公式，仅用符号名 + 中文语义。
- 英文缩写首次出现处必须括注中文（如 `VRR（有效资源单元通过率）`）。

## 四、边框、连接线与容器层级

### 4.1 边框层级（Border Hierarchy）

| 层级 | 线宽 | 颜色 | 线型 | 用于 |
|------|------|------|------|------|
| B1 | 2.0 pt | `#1B3A5C` | 实线 | 一级模块 |
| B2 | 1.5 pt | `#2E6B9E` | 实线 | 二级子块 |
| B3 | 1.0 pt | `#5BA0D0` | 实线 | 三级元素、输入素材 |
| B4 | 1.0 pt | `#8EAEC4` | 实线 | 弱化元素（扩展模态等） |
| B5 | 1.0 pt | `#CCCCCC` | 实线 | 中性分隔、表格线 |
| B6 | 1.5 pt | `#1B3A5C` | **虚线** | 区域分组容器、独立性边界、研究范围声明框 |
| B7 | 1.5 pt | `#A64B2A` | **虚线** | 拒绝/失效框（仅 F03/F05/F06） |

**填充规则**：所有模块填充 `#FFFFFF`；仅泳道与底部条带允许 `#F7F7F7`；**禁止任何彩色填充**（色彩只上边框）。

### 4.2 连接线层级（Connector Hierarchy）

| 层级 | 线宽 | 颜色 | 线型 | 语义 |
|------|------|------|------|------|
| C1 主流 | 2.0 pt | `#1B3A5C` | 实线 + 实心箭头 | 主执行流 / 主推进关系（每图唯一一条主链） |
| C2 次级 | 1.2 pt | `#4D4D4D` | 实线 + 实心箭头 | 一般有向关系、从属、产出 |
| C3 对位 | 1.0 pt | `#2E6B9E` | 实线 + 细箭头 | 一一对应映射（缺口↔问题、内容↔目标、能力↔任务） |
| C4 辅助 | 1.0 pt | `#4D4D4D` | **虚线** + 细箭头 | 旁路说明、注入、回流、共同作用 |
| C5 失效 | 1.2 pt | `#A64B2A` | **虚线** + 细箭头 | 拒绝分流、退出通道、错配分支 |
| C6 比对 | 1.2 pt | `#1B3A5C` | 实线 + **双向**箭头 | 一致性比对（**全套仅 F06 一处允许**） |

### 4.3 箭头语义总表（跨图强制统一）

| 视觉形态 | 唯一含义 | 反例（禁止） |
|---------|---------|-------------|
| 粗实线 + 实心箭头 | 主流程推进 | 不得用于表示"对应关系" |
| 细实线 + 细箭头 | 一一对应 / 从属 / 产出 | 不得用于表示流程 |
| 虚线 + 细箭头 | 旁路 / 回流 / 注入 / 共同作用 | 不得用于主流程 |
| 暖色虚线 + 细箭头 | 拒绝 / 失效 / 退出 | 不得用于任何正常路径 |
| 双向箭头 | 一致性比对 | **除 F06 比对框外全套禁止** |
| 汇聚箭头（两路合一） | 联合约束 / 共同输入 | 仅 F04 的 Kp+Kc 使用 |
| 无箭头细线 | 并列对照、时间轴、分隔 | 不得暗示方向 |

**回流走线规则**：所有回流/退回箭头统一走模块下沿绕行，**禁止穿越任何模块**；交叉不可避免时使用跨线小拱形。

### 4.4 容器层级（Container Hierarchy）

```
画布（白）
└─ L1 区域容器：泳道 / 满幅条带  — #F7F7F7 底 + #CCCCCC 或 #1B3A5C 虚线框
   └─ L2 一级模块框              — 白底 + B1 边框
      └─ L3 二级子块框            — 白底 + B2 边框
         └─ L4 条目行 / 标签      — 无框，纯文字或 B5 细分隔线
```

**嵌套上限 4 层**。超过则拆图或降级为条目行。

## 五、强调规则（Emphasis Rules）

1. **每图至多 1 个视觉焦点**。焦点通过"`#1B3A5C` 边框加粗至 1.5×（即 3.0 pt）+ 四周留白扩大 1.5×"实现，**不使用**彩色填充、阴影、发光或放大字号。
2. 各图指定焦点：
   - F01 → 核心矛盾框「可检索，但不可教学使用」
   - F02 → RC1→RC2→RC3 主链整体（作为一个视觉组强调）
   - F03 → S4 四层质量门控
   - F04 → 资源单元 `u=(c,a,m,e,s)` 五槽位主体框
   - F05 → 三道判定闸门串联段
   - F06 → 主指标 `VRR` 框
   - F07 → 底部「仍需本项目新开展并验证」边界带
3. **禁止**用色彩饱和度做强调（全套只有一个色相）。
4. 弱化同样是强调手段：扩展模态、非支撑信息一律 `#8EAEC4` 边框 + T5 字号。

## 六、图标规则（Icon Rules）

- **允许**：极简线性单色图标，`#2E6B9E` 或 `#5BA0D0`，线宽 1.0–1.2 pt，尺寸不超过同行文字高度的 1.6 倍。
- **允许的图标语义**（全套统一，同一概念必须同一图标）：
  | 概念 | 图标 |
  |------|------|
  | 课程文本 | 文档页 |
  | 运行曲线 / 图表 | 折线图 |
  | 设备结构图 | 简化设备/机组轮廓 |
  | 实验代码 | 尖括号 `</>` |
  | 产业案例 | 简化厂房/工业轮廓 |
  | 来源位置 / 证据 | 定位锚点 |
  | 专家盲评 | 人形 + 评分条 |
  | 质量门控 | 闸门/层栈横条 |
- **禁止**：拟物化插画、渐变图标、彩色图标、emoji、剪贴画、任何品牌标识、任何人物照片风格元素。
- 图标为辅助识别，**每个模块至多 1 个**；无合适语义时不放图标，宁缺勿凑。

## 七、字体、线宽、圆角与留白

### 7.1 字体（Typography）

- 中文：无衬线（黑体/思源黑体族），全套统一，**不混用字体家族**。
- 英文与数字：无衬线（Helvetica/Arial 族）与中文同族视觉。
- 数学符号：衬线斜体（Times 族），仅用于 §三 列出的符号名。
- **禁止**：手写体、艺术字、书法体、加阴影文字、描边文字、字符间距异常拉伸。

### 7.2 线宽（Line Weights）

全套只使用四档：**1.0 / 1.2 / 1.5 / 2.0 pt**（焦点强调时 3.0 pt）。禁止出现其他线宽或发丝线。

### 7.3 圆角策略（Corner Radius）

| 元素 | 圆角 |
|------|------|
| 一级/二级模块框 | 3 pt 小圆角（统一） |
| 区域容器/泳道/条带 | 4 pt |
| 判定闸门条（F05） | 直角 0 pt（与普通模块形成形态区分） |
| 四层门控横条（F06） | 直角 0 pt（同上） |
| 标签/角标 | 2 pt |

**规则**：同一图内圆角档位不超过 2 种；直角专用于"判定/门控"语义，是 F05/F06 与其他图的形态标识。

### 7.4 留白策略（Whitespace）

- 白底面积 ≥ **70%**。
- 模块内文字四周内边距 ≥ 文字高度的 0.6 倍。
- 相邻模块间距 ≥ 模块高度的 0.35 倍；跨区域间距 ≥ 0.6 倍。
- 画布四周外边距 ≥ 画布短边的 4%。
- **禁止**把模块拉满容器边缘，禁止为填满画面而放大元素。

## 八、灰度与可访问性总则

1. 全套图必须在**纯灰度打印**下仍可完整读解。检验方式：去色后，边框明度阶梯（21% / 40% / 61% / 68%）仍可区分四级结构。
2. **双重编码强制项**：
   - 拒绝/失效：暖色 **且** 虚线 **且** 中文标签（三重）
   - 扩展模态：浅灰蓝 **且** T5 字号 **且** "扩展"字样
   - 对应关系 vs 流程：颜色 **且** 线宽 **且** 箭头粗细
3. 文字对比度全部 ≥ 4.5:1；`#5BA0D0`、`#8EAEC4` 永不作文字色。
4. 不依赖颜色传达任何**唯一**信息。

## 九、全套共享规则（Shared Rules）

以下规则对 F01–F07 全部适用，prompt 中须逐条落实：

1. 纯白背景，扁平 2D 矢量信息图风格。
2. 所有模块白色填充，色彩只出现在边框、连接线与文字。
3. 每图有彩色 ≤3 种 + 中性色。
4. 单一主链方向明确：F01/F06 自上而下，F02/F03/F04/F05/F07 自左向右。
5. 术语全套统一，禁止同义替换：
   `资源单元` / `产业任务知识` / `课程知识` / `专业属性` / `来源位置` / `质量状态` / `有效资源单元通过率 VRR` / `示范课程模块` / `知识模块` / `跨来源留出` / `独立专家盲评` / `困难负例`
6. 中文为主语言；英文仅用于已在标书中出现的术语与指标（Recall@1、Recall@5、MRR、F1、VRR、Krippendorff's alpha、B0–B3）。
7. 涉及未来事实的数量（4 个知识模块、≥300 个资源单元、120 个盲评单元、≥3 名专家）**必须带"拟构建/拟抽取/拟邀请"前缀**，不得呈现为既有事实。
8. 任何图**不得出现**：学生画像、学习行为、个性化推荐、学习效果预测、教育云/生产平台接入、学生个人信息、企业敏感信息。
9. 无标题栏、无图注、无页码、无水印、无装饰性几何背景、无网格背景。
