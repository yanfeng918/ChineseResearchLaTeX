# 研究现状与切入点

## 摘要

面向新疆的 CIESM 气象场增强应从数据可辨识性出发。现有研究已分别乃至联合处理空间超分辨率、跨变量依赖、粗尺度去偏、概率重建和时空一致性，因而“多变量+物理约束”不足以单独构成新颖性。可检验的切入点是：在公开数据和一年期资源边界内，比较地形条件、变量联合与显式聚合算子的相互作用，给出对新疆地形单元、极端事件和域迁移的适用边界。

## 引言与数据基础

CIESM 的公开模式论文和 CMIP6 实验标准提供了来源、成员和历史试验的核查框架。ERA5 与 ERA5-Land 提供连续参考场；后者受前者的强迫驱动，两者之间的比较不能充当独立地面观测验真。CIESM 自由运行轨迹与真实天气并非按日对应，日期配准应只服务于季节统计和资料覆盖审计。

## 方法演进

DeepSD 和 DeepESD 支持卷积降尺度与 perfect-prognosis 思路。Stengel 等、Harris 等及 CorrDiff 将随机残差及空间结构纳入重建，但原始实验区域、变量和训练对的成立条件不同。本项目拟在再分析资料内部构造粗细尺度对应，在应用端对 CIESM 进行训练期限定的分布变换，并分别考察偏差校正与细节恢复的贡献。

Lange 的 ISIMIP3BASD 和 Cannon 的 MBCn 表明，趋势及跨变量分布应有明确校正对象；Wang 与 Tian 已研究六变量联合及趋势保持，构成本项目必须比较的近邻方法。Geiss 等和 González-Abad 等说明某些输出层条件可以严格满足；从这些结果推断到本任务时，只能把非负、变量定义关系和已定义聚合算子作为硬约束，不能无依据宣称水量与能量收支全面闭合。

近年的非配对扩散桥、粗尺度去偏后条件采样、尺度适应模型与时空一致性生成框架，进一步说明细粒度场具有条件不确定性。2026 年共享表示的 ESM 降水校正研究以及区域预训练研究，应作为本项目创新边界的直接参照。

## 讨论与方案取舍

一年期工作以四项明确任务形成闭环：可追溯数据、联合重建、约束分析、接口验证。日尺度为核心；目标 0.1° 与日内 6 小时增强为待数据审计确认的实验设置，不能把月输出插值成可验证的日极端事件。深度生成模型先选小规模残差版本，只有在验证概率校准收益且算力足够时扩展，不同时承诺多个复杂大模型。

## 展望与结论

预计最有价值的结果包括有效和无效条件：联合训练在哪里产生负迁移，约束在哪里改善粗细尺度兼容性，参考场依赖性怎样限制真实性表述。先在再分析内部进行配对检验，再在 CIESM 端评价季节分布、谱结构和聚合残差，最后把独立观测验证与实验室正式接收证据分开记录。此类边界结论比未经检验的全区域精度承诺更符合本课题规模。
