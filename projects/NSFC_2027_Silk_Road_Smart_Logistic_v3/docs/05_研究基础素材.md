# 研究基础素材（已核验事实与缺口）

## 可直接使用的事实

### 申请人与研究积累

- 申请人颜丰，博士，新疆大学副教授、硕士研究生导师，2023 年 10 月加入新疆大学，入选新疆大学高层次优秀青年 A 类博士引进人才。
- 研究方向覆盖多模态信息处理、视觉问答、跨模态检索、机器学习、深度学习、金融与新能源时间序列分析。
- 多模态与视觉代表性成果包括：SPCA-Net（The Visual Computer, 2022）、Knowledge-Aware Image Understanding（Machine Learning, 2024）、RSSR（Computer Vision and Image Understanding, 2026）、RSHR+（Expert Systems with Applications, 2026）、Feature Fusion Mamba Hashing（IEEE Signal Processing Letters, 2026）等。
- 时序代表性成果包括：DWT-Former（Energy, 2025）和 WaveKAN（Neurocomputing, 2026）。
- 工程经历覆盖软件技术、视觉缺陷检测、数据采集、知识库与问答系统、低空安全与场所安全等研发任务，可支撑算法实现与工程验证；现有材料不足以据此声称具有通信理论研究积累。

### 项目与团队

- 公开材料列出主持项目 7 项、参与纵向项目 4 项、参与横向项目 3 项。
- 与拟申请内容最接近的主持项目包括“多模态融合技术研究及其在新疆产业集群中的应用”“面向通用领域的多模态视觉问答关键技术研究”“基于 YOLO-V8 的贴片二极管表面缺陷检测”。
- 参与项目中，与时序预警、语义表征和安全场景相关的包括公路沙害智能预警、无人平台数据要素多层级语义结构化表征、低空安全与场所安全服务等。
- 申请人创建 ALPHA Group，现有材料列出参与研究生：孔哲、张建宏、杨铄、孟星宇、桑乐吕、中原、于得武；具体分工与投入时间未提供。

### 平台与算力

- 新疆大学计算机科学与技术学科具有多语言多模态认知计算与内容安全、信号检测与智能处理、大数据分析与智能控制等建设方向。
- 可依托平台包括教育部丝路多语言认知计算国际合作联合实验室、鹏城实验室新疆网络节点、新疆信号检测与处理重点实验室、新疆多语种信息技术重点实验室、新疆多模态智能处理与信息安全工程技术研究中心等。
- 学院人工智能算力中心材料记载有 GPU/NPU 服务器或工作站 130 余台、各型加速卡 600 余块，算力约 43 PFlops@FP32/120 PFlops@FP16；另有 A100 八卡服务器租赁服务。设备可用期限、排队制度和本项目可获得配额需申请人确认。

## 与两个研究内容的证据映射

| 研究内容 | 已有证据 | 仍缺的直接证据 |
|---|---|---|
| 状态—观测双过程联合推断 | 多模态表征、视觉问答、跨模态检索、时间序列预测和工业视觉缺陷检测经历 | 状态相关缺失四格先导数据、原因标签、概率校准与观测过程分解初步结果 |
| 端—收信念差异驱动的风险证据传输 | 长上下文高效注意力、软件研发和系统实现经验 | 固定端侧设备、真实/可复现弱网轨迹、ACK/缓存/重传日志、字节与尾时延先导结果 |
| 外层真实运输验证 | 新疆地域和相关科研平台 | 物流合作单位、线路/货物、数据授权、传感器与客观终点 |

## 不得推断的事项

- 各项目验收状态、申请人实际分工、部分项目批准经费及与本申请的经费边界。
- 与拟题直接相关的样本量、异常率、性能指标、能耗、通信节省或现场试验结果。
- 七名研究生的具体任务、专业结构和投入时间。
- 物流合作单位、真实线路、设备型号、数据授权或伦理/合规审批状态。
- 申请人是否曾主持并完成国家自然科学基金项目。

以上事项统一在 `docs/研究基础信息补充问卷.md` 中请求申请人确认。
