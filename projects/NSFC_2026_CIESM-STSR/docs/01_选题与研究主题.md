# 选题与研究主题

**题目**：面向新疆复杂地形的 CIESM 关键气象场多变量时空超分辨率与物理一致性校正研究。

**申报口径**：用户确认的 P02 开放课题，2027 年 1—12 月。研究对象为 CIESM 的区域气象场数据增强；新能源应用仅用于说明需求，不开展功率预测或模式动力核心开发。

**主题**：在跨资料分布差异下，研究地形条件与跨变量依赖如何帮助恢复气候场亚网格结构，并检验恢复细节与保持可定义的大尺度统计量是否能够兼容。

**四条内容与路线**：多源数据构建；多变量多尺度重建；地形与物理一致性约束；CIESM 接口集成与区域验证。

**核心问题**：如何建立可检验的粗细尺度对应关系，避免自由运行气候模拟与再分析资料的伪配对？联合变量是否能够改善空间结构及复合事件统计？哪些一致性条件适合严格满足，哪些只应作为经验约束并验证其适用边界？

**关系链**：气候模式大尺度状态 → 训练期限定的分布校正 → 地形条件下的多尺度联合重建 → 显式聚合一致性与物理范围校验 → 独立时段、地形及跨区域评估 → CIESM 数据处理接口。

**关键词**：CIESM；复杂地形；统计降尺度；时空超分辨率；多变量依赖；大尺度一致性；新疆。

**英文检索词**：Community Integrated Earth System Model; statistical downscaling; spatiotemporal super-resolution; multivariate dependence; complex terrain; conservative downscaling; bias adjustment; perfect prognosis; distribution shift; extreme events。

**检索范围**：2021—2026 年方法进展为主，补充 CIESM、CMIP6、ERA5 与降尺度验证的必要基础文献。核心检索词分别组合 bias correction / unpaired / trend preserving / hard constraints / out-of-distribution / temporal disaggregation。

**边界**：不把 ERA5-Land 当独立观测真值；不把原始 CIESM 与再分析日期对齐视为事件对应；不预先承诺公里级真实信息或小时级确定性恢复；公开数据可用不等于本项目已有实验结果。
