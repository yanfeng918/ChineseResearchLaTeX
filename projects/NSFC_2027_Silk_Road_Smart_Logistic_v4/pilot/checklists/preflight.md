# 运行前检查表

## A. 范围与安全

- [ ] 使用的是基础可控箱体/包装代理，无真实危险货物。
- [ ] 无人员识别；如不可避免拍到人员，已完成隐私处理和授权。
- [ ] 事件名称与 event_dictionary.yaml 一致，代理未写成真实设备或现场事件。
- [ ] 网络扰动运行在独立 namespace、容器、虚拟机或非关键接口。
- [ ] 不会中断当前远程管理连接或影响他人网络。

## B. 冻结项

- [ ] run_id、entity_id、session_id 和数据划分已经登记。
- [ ] 场景、事件操作、事件窗口和标签来源已经冻结。
- [ ] 三类时钟、对时方式和允许同步残差已经冻结。
- [ ] 网络配置、种子、决策截止期和资源初值已经冻结。
- [ ] 方法、模型容量、训练预算、主次指标和停止规则已经冻结。
- [ ] 保护性原始证据范围和压缩保真底线已经冻结。

## C. 设备与环境

- [ ] 所有采集、参考、接收设备的型号、系统和软件版本已记录。
- [ ] 采样率、单位、轴方向、图像尺寸和编码已记录。
- [ ] 存储空间、时间同步、网络接口和电源状态已检查。
- [ ] 若记录能耗，物理测量或估算方法及单位已写明。

## D. 日志与完整性

- [ ] 事件、采样、到达、采样指令、质量和设备健康字段可生成。
- [ ] 序号、分片、缓存、丢弃、重传和续传日志可生成。
- [ ] 原始层与派生层路径分离，原始层写入后只读。
- [ ] SHA-256 工具、证据清单和结果登记工作副本已准备。
- [ ] 标准输出、错误输出、系统环境和实际网络测量有保存路径。

## E. 干运行验收

- [ ] 至少完成一条正常和一条异常干运行。
- [ ] 三时钟均可读取并映射到参考时基。
- [ ] 同步残差低于冻结阈值。
- [ ] 同一母流、配置和种子可重复重放。
- [ ] 策略输入不包含截止期后数据或最终标签。
- [ ] 故意断连后缓存、校验和幂等续传行为可审计。
- [ ] 失败时能保留失败日志，而不是覆盖重跑。
