## 一、建议主选题

### 1. 中文题目

**矿山地表扰动遥感变化检测的跨域泛化与可信评估研究**

### 2. 英文题目

**Cross-Domain Generalization and Reliability Assessment for Remote Sensing Detection of Mining-Induced Surface Changes**

### 3. 指南对应

对应2026年指南重点资助领域第（4）项“矿山地质环境监测”。[S1]

### 4. 一句话定位

以公开矿山遥感影像和变化标注为基础，研究模型在未见矿区识别地表变化的稳定性，并输出能够辅助人工复核的可靠性信息。

### 5. 任务边界

“地表扰动”限定为公开影像及标注能够支持的地表覆盖与矿山足迹相关变化。核心任务是给定两个观测时相，识别变化位置、范围和可靠性，不是预测下一时刻，也不是确定变化发生的精确时间。

“可信评估”限定为检测结果的概率校准、错误识别与复核效用评估，不等同于矿山环境风险分级、因果归因或安全生产决策。

不以矿产资源定位、成矿机制、深部探测、重金属浓度反演、尾矿库失稳预警或地表沉降预测作为本课题核心任务。

## 五、公开数据核查与使用分工

### 1. 主数据：MineNetCD

作者原始工作报告100个全球矿区、超过7万对双时相图像切片及像素级变化标注。[D1]

HZDR的RODARE正式发布页提供完整版MineNetCD.zip，标注大小约3.5 GB，说明压缩包中包含矿区元数据，文件许可证为CC BY 4.0；作者同时提供代码和预训练模型入口。[D2][D3]

拟承担的任务：基线复现、矿区级数据分组、跨矿区泛化、变化误检漏检分析、预测可靠性评估。

重要限制：

- 数据不是新疆专用数据集，也不能未经核对就认为100个矿区均为有色金属矿。
- 论文所述双时相间隔较长，不能据此宣称能够开展实时监测、月度预警或准确定位扰动发生时刻。[D1]
- 变化二值掩码不等同于污染、沉降、尾矿库风险或生态修复成效标签。
- 2026-09-05核对页面、许可与发布入口；2026-09-06进一步取得作者MineNetCD256训练/验证四分片并核验SHA256。完整版ZIP未完整验收，矿区domain可读取，不等于逐切片地理位置和配准已经核实。

### 2. 扩展验证：EuroMineNet

原始工作描述了欧盟133个矿区、2015—2024年Sentinel-2多光谱年度影像与矿山足迹标注，支持足迹制图和跨时相变化检测。[D4]

2026年5月11日发布的RODARE记录提供EuroMineNet.zip，标注大小约18.4 GB；官方仓库提供数据读取、裁切、重建和划分脚本。[D5][D6]

拟承担的任务：验证方法是否能扩展到年度、多光谱和不同观测条件；不作为一期研究启动的必要条件。

重要限制：

- 不能把多光谱或双时相数据直接称为已经配准的“光学—SAR多模态数据”。
- EuroMineNet与MineNetCD的分辨率、输入波段、时相间隔和标签语义不同。应先分别建立各自基线，再决定是否开展跨数据集迁移。
- 不能直接把两个数据集的IoU相减解释为跨域性能下降，也不能在没有协议说明时声称零样本迁移。

### 3. 有色金属相关补充：全球铜矿公开数据

2025年Scientific Data论文公开了约1,313个铜矿的2022年矿山用地边界和属性，以及相关GEE代码。[D7]

拟承担的任务：在坐标、名称、年份和属性能够核对的条件下，辅助识别公开主数据中的铜矿样本或选择有色矿案例。匹配数量不足时，只做可核实案例分析，不宣称具有代表性的有色矿独立测试集。

重要限制：这是静态边界及属性资源，不是现成的双时相变化标注集；不能用2022年边界替代其他年份的真实变化掩码。新增变化真值需独立核验并记录质量。

### 4. 首轮数据验收清单

1. 确认归档可下载、可解压，记录版本、大小、校验值、许可证及引用方式。
2. 核对输入影像、标签值、无效像素、时相和空间分辨率；抽检影像—标签配对与配准。
3. 建立矿区ID—原始影像—裁切切片的追溯关系，检查重复、重叠和跨集合共享来源。
4. 区分“存在下载入口”“实际成功取得”“可用于本研究协议”“已跑通基线”四个状态。
5. 优先复现官方基线并建立误差案例，再判断研究假设是否成立。

## 六、科学问题、研究内容与创新约束

### 科学问题一：跨矿区条件下，如何保持对真实地表变化的判别能力？

工作假设：背景地物、纹理和观测条件变化可能导致模型混淆真实变化与外观差异。该假设的频率、严重程度及主导因素必须由公开数据上的基线误差核实。

拟考察：稳定背景与变化区域的表征关系、局部空间结构信息对干扰识别的作用，以及在域差异下维持变化敏感性的方法。

### 科学问题二：模型在未见矿区的置信度能否反映实际错误？

工作假设：高置信度输出未必能在新矿区保持相应正确率。拟研究独立校准、错误区域识别和复核优先级，检验可靠性信息是否具有实际复核价值。

不预设跨域校准具有分布无关保证，也不将置信度图本身当作可信性已经得到验证。

### 研究内容一：矿区分组基准与泛化误差诊断

形成数据清单、矿区来源追溯、可复现划分和误差分类协议。分别报告官方划分下的可比结果与严格矿区隔离的泛化结果。若官方协议已隔离矿区，则沿用并进一步审计，不能把重复实现的划分宣称为创新。

在可核实子集上分析裸地混淆、边界差异、细小变化和观测条件变化，不假定公开标签已提供这些细分类别。

### 研究内容二：变化判别与背景稳定性联合表征

在可靠基线之上，围绕一个主要失效机制设计方法，例如稳定背景参照与变化区域判别的联合约束。比较其对误检和漏检的不同影响，避免通过过度平滑压低误检却损失真实细小变化。

具体骨干、损失项和训练策略由前测决定，不预先把Transformer、Mamba、FFT、大语言模型、多智能体等模块全部写入路线。

### 研究内容三：检测可靠性与复核效用评估

输出变化概率与可靠性信息，在独立矿区上考察概率校准、错误排序和区域复核价值。采用固定复核预算比较剩余错误，同时报告漏检变化和被拒绝覆盖的面积，不能仅通过拒绝难例取得好看的准确率。

### 创新表述限制

已有DonaNet等研究针对遥感变化检测中的伪变化和跨域泛化提出方法，跨域变化检测本身不是研究空白。[R1]

本项目只能将“矿山特定混淆机制下的变化表征约束，以及面向矿区级复核的可靠性评价”作为待检验增量。正式申请前应进一步与通用域泛化、矿山变化检测和不确定性方法对照；不得使用“国内外首次”“填补空白”等未经系统核实的表述。

## 七、实验协议与可行性判据

### 1. 基线配置建议

| 层级 | 拟设内容 | 目的 |
|---|---|---|
| B0 | 简单孪生变化检测基线 | 确认数据与训练流程正常 |
| B1 | 官方MineNetCD基线，含可复现的ChangeFFT配置 | 与矿山任务已有方法直接比较 |
| B2 | 一种有可用实现的跨域变化检测方法，如经核查后的DonaNet | 避免只胜过普通模型却没有真正域泛化增量 |
| C0 | 概率未经校准与独立验证集温度缩放等简单校准方案 | 检验复杂可信模块是否优于简单处理 |
| Ours | 从主要误差中凝练的单一核心改进及必要组合 | 判断贡献来源与性能代价 |

B0—B2为建议实验配置，不表示本次已运行或完全核实各实现的环境兼容性。官方MineNetCD代码与模型入口见[D3]，DonaNet论文见[R1]。

### 2. 防止数据泄漏

- 以矿区或可验证的原始场景为分组单位，不让同一矿区裁切块分散进入训练和最终测试。
- 用于模型选择与校准的数据，与最终测试矿区分离；阈值不能在最终测试标签上调优。
- 官方MineNetCD预训练权重可用于复现原报告，但其训练范围可能覆盖自建测试矿区；未经排除覆盖，不能用来宣称对这些矿区完全未见。
- 自建跨矿区实验应按新划分重新训练，或严格核查所有预训练、微调与校准数据的矿区覆盖。
- 数据归一化等统计只使用协议允许的数据拟合。
- 目标域少样本微调或无标签适应应单独报告，不能和纯域泛化混为一谈。
- 元数据无法支持真实矿区隔离时，不继续使用“跨矿区泛化已验证”的结论。

### 3. 建议指标

检测质量：变化类F1、IoU、Precision、Recall；矿区宏平均及矿区间分布，避免大矿区或背景像素占比主导结果。

可靠性：Brier分数、校准误差，结合类别不平衡进行分层报告；必要时补充可靠性曲线与错误排序指标。

复核效用：风险—覆盖率关系，固定复核比例下的剩余错误、变化漏检和需要人工复核的区域负担。

稳定性：至少3个随机种子；按矿区而非把所有像素视为独立样本进行置信区间估计。具体检验方案根据矿区数量和实验设计确定。

效率：参数量、显存与推理开销。没有实际测量前，不承诺实时或特定硬件时延。

### 4. 题目与方法冻结条件

只有在主数据可用、矿区可追溯、基线跑通并确认具有足够普遍的泛化或可靠性问题后，才冻结方法性创新表述。

若前测证明主要瓶颈不是泛化，而是标签口径或配准质量，则先解决数据问题，不为了保留既定题目制造性能差距。若不存在清晰可复现的主要失效，不把多个算法模块拼接当作替代创新。

## 十一、申请摘要工作稿

本项目面向矿山地质环境监测中的地表变化识别需求，以公开矿山遥感影像及变化标注为基础，拟研究模型在未见矿区的泛化能力与预测可靠性。首先，构建按矿区隔离的数据划分和评测协议，复现代表性变化检测方法，分析背景地物差异、观测条件变化及边界模糊等因素与误检漏检的关系；在此基础上，研究兼顾变化判别与背景稳定性的表征方法，增强复杂场景下真实地表变化的识别能力；进一步开展独立矿区上的置信度校准、错误区域识别与人工复核效用评价，形成变化范围和可靠性信息协同输出的监测方法。在MineNetCD上完成主要研究，并在完成输入和标签适配后利用EuroMineNet开展扩展验证；对经核实的有色金属矿区样本进行专题分析。预期形成可复现的算法与评测流程，发表符合指南要求的SCI/EI源刊论文，为矿山地表扰动监测和辅助复核提供方法支撑。

本摘要描述拟开展研究，不包含已取得性能结果。最终方法、数据范围和量化目标应依据前测修改。
