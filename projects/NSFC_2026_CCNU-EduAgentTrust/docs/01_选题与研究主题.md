# 选题与研究主题

题目：高等教育场景下教育智能体可信评测与伦理风险监测机制研究。

主题：以可观测行为轨迹为证据，研究教育任务约束、风险发生位置与后续行动之间的关系，检验过程评测能否在控制任务能力差异后更早识别风险，并以可接受的误阻断和教学支持损失实施干预。

研究对象为高等教育课程答疑、文献学习辅助两类任务中的工具型单智能体，检索与记忆为可控组件；双智能体错误传递为压力测试。不开训练大模型、全校部署、全学科基准或长期学习成效研究。新疆高校可提供未来验证场景，当前合作与数据授权未落实。

核心问题：
1. 相同最终答案能否掩盖不同的权限、证据或教学约束违背？如何在外显行为记录中定位首个可观察风险？
2. 在相同模型、预算与误报率下，轨迹评价相比结果评价的增益来自哪些证据，能否跨任务模板成立？
3. 在动作执行之前，怎样以分级监测减少风险暴露，并量化误阻断、正常任务完成与教师干预负担？

关键词：Educational AI Agents; Higher Education; Trajectory Evaluation; Trustworthy AI; Pedagogical Appropriateness; Prompt Injection; Risk Monitoring; Selective Prediction; Human Oversight; Tool-use Safety。

检索扩展词：process-level assessment, agent safety benchmark, tutor agent evaluation, risk-aware planning, learning safeguards, indirect prompt injection, memory poisoning, pedagogical alignment, refusal utility trade-off。

机制链：教育任务与授权范围→可观测轨迹→风险事件及其证据→过程评价→动作前监测→阻断/重规划/人工复核→风险和任务效用的共同验证。

公开事实、他人研究结论、拟研究假说分开；不将工具日志等同于模型私有思维链，不将评测分数等同于真实学习获益。
