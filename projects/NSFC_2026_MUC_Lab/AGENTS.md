# 教育部重点实验室开放课题申请书 - AI 写作指令

本目录是 **中央民族大学「民族语言智能分析与安全治理」教育部重点实验室 2026 年度开放课题** 的 LaTeX 写作工作区，模板沿用 NSFC 地区基金结构，便于复用现有写作技能。AI 的核心任务是**辅助撰写和优化申请书内容**，不做版式开发，不改动 `extraTex/@config.tex`（除非用户明确要求调整版式）。

**项目性质校正（必须遵守）：**

- 这不是国家自然科学基金；最终提交物是实验室 Word 申请书 + 纸质一式两份。
- 类别：一般项目；经费：**5 万元**；期限：**2 年**。
- 指南方向：1(a) 民族语言多模态提取融合技术研究。
- 已选定题目：**场景文字增强的维吾尔语多模态表征融合与跨语言图像理解**。
- 稳定研究边界、数据口径与成果署名见 [`docs/00_项目基本信息.md`](docs/00_项目基本信息.md)。
- 第（一）部分建议控制在 **5000–7000 字**，不要按地区基金默认写满 8000 字；年度计划写 **两年**，不要写三年。
- 全文原则上不超过 **25 页**。成果承诺按实验室指南：至少 1 篇中科院三区及以上 SCI，实验室为第一署名单位。

## 写作顺序建议

```
明确科学问题
  → 立项依据（1.1）
  → 研究内容 + 目标 + 关键问题（1.2）
  → 研究方案及可行性（1.3）
  → 特色与创新（1.4）
  → 年度研究计划（1.5）
  → 研究基础（2.1） + 工作条件（2.2）
  → 承担/完成项目（2.3, 2.4）
  → 其他说明（3.x）
  → 全文质量控制
```

> **注意**：本课题借用地区基金结构，立项依据、研究内容、方案和计划合并在第（一）部分，控制在 5000–7000 字；不要按三年国自然地区基金写满 8000 字。

## 各章节写作要点

### （一）立项依据 → `extraTex/1.1.立项依据.tex`

写作逻辑：**研究意义** → **国内外研究现状及发展动态分析** → **科学意义或应用前景**

- 参考文献随立项依据之后渲染，通过 `\cite{key}` 引用，文献条目维护在 `references/myexample.bib`
- 可结合"科学研究发展趋势"论述科学意义，或结合"国民经济和社会发展的关键需求"论述应用前景

### （一）研究内容、目标、关键问题 → `extraTex/1.2.内容目标问题.tex`

- 研究内容：此部分为**重点阐述内容**
- 研究目标：明确、可验证
- 关键科学问题：1–3 个，需与研究内容高度对应

### （一）研究方案及可行性 → `extraTex/1.3.方案及可行性.tex`

- 包含研究方法、技术路线、实验手段、关键技术

### （一）特色与创新 → `extraTex/1.4.特色与创新.tex`

- 聚焦科学意义而非技术手段，1–2 条，言简意赅

### （一）年度研究计划 → `extraTex/1.5.研究计划.tex`

- 两年分年度，预期产出（论文/方法/评测协议等）具体可查
- 可包含重要学术交流活动、国际合作计划

### （二）研究基础 → `extraTex/2.1–2.4.*.tex`

- **2.1**：用证据链（代表性论文/项目/数据）证明申请人有能力完成本课题
- **2.2**：已具备条件 + 缺少的条件 + 解决方案，简洁务实
- **2.3–2.4**：如实填写，格式参照模板中的 `\NSFCBlankPara` 占位区

## 常用 LaTeX 命令速查

```latex
% 空白占位符（草稿期使用，填写内容后删除）
\NSFCBlankPara

% 正文文件开头推荐加（两端对齐 + 2em 段首缩进）
\justifying
\NSFCBodyText

% 列表项标题（加粗蓝色标题 + 正文内容）
\item \itemtitlefont{标题：}内容...

% 三级标题（自动编号 1.1 风格）
\subsubsection{标题}

% 四级标题（自动编号（1）风格）
\subsubsubsection{标题}

% 圈号行内小标题
\ssssubtitle{1}

% 插入图片
\begin{figure}[!th]
    \begin{center}
        \includegraphics[width=0.8\linewidth]{figures/图片名.jpg}
        \caption{图片说明文字}
        \label{fig:label}
    \end{center}
\end{figure}

% 引用文献
已有研究表明...\cite{bibkey}
```

## 工程原则

- **只改内容文件**：仅修改 `extraTex/*.tex`、`references/myexample.bib`、`figures/`；不改 `@config.tex` 版式（除非用户明确要求）
- **先读后写**：修改前先读取目标文件，了解现有内容和占位符再动笔
- **不造假引用**：添加参考文献必须经 `nsfc-bib-manager` 核实，不虚构 BibTeX 条目
- **篇幅意识**：第（一）部分建议 5000–7000 字；全文不超过 25 页；超出时优先用 `nsfc-length-aligner` 压缩
- **语言**：始终用简体中文与用户交流，撰写中文标书内容
- **研究边界**：本项目聚焦维吾尔语场景文字增强的多模态表征融合与维–汉跨语言图像理解；不写入民汉翻译系统、语音交互、舆情安全、古籍文字、新能源教学资源或产业集群应用。
- **数据口径**：核心评测只用 SUST/RUST 与 Multi30k-Distant；CUTE/MC² 仅作辅助预训练；不引用商业平行语料；不把拟建小规模理解题写成已有大规模维语 VQA 基准。
- **验证口径**：以跨语言图文检索 Recall@K/MRR 为主指标，以去掉场景文字通道的消融和 200–400 题图像理解准确率为辅助；拟构建评测协议不得表述为既有事实。
