## 检索策略

检索词表见 [`../01_选题与研究主题.md`](../01_选题与研究主题.md) 第七节。实际使用的入口：

- **Crossref REST API**（`api.crossref.org`）：按标题检索与按 DOI 拉取权威题录，用于**全部**条目的元数据核验；
- **Web 检索**：用于发现 2025—2026 年新进展（本地知识可能滞后），发现后一律回到 Crossref 核验；
- **出版方页面直取**：中文期刊（《遥感学报》《电子与信息学报》）与 PMLR 条目在 Crossref 中不可检索或未收录，逐条访问出版方页面核验；
- **Semantic Scholar API**：用于补充摘要（ESRN 摘要被出版方屏蔽，未取得）。

覆盖的主题簇：遥感图文检索方法与基准、遥感视觉语言基础模型、噪声/不完备图文对应、图文匹配中的关系与结构建模、组合与空间推理评测、不确定性建模、训练数据质量、参数高效适配。

## 与既有基准数字的使用纪律

本阶段**未复现任何基线**，因此：

- 文献中报告的 R@1/R@5/R@10/mR 只能作为「已有工作报告的数值」引用，不得写成本项目的对比结果；
- 不得据此在正文中承诺任何提升幅度；
- RemoteCLIP 在 RSITMD/RSICD 上的结果涉及训练数据重叠问题（见 `01_关键论断与证据.md` 论断 7），引用时必须同时说明该限制。
