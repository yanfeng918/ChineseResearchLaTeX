## 2. 研究题目与研究定位

### 已选定中文题目（候选 B）

**场景文字增强的维吾尔语多模态表征融合与跨语言图像理解**

### 简要项目名称

**场景文字增强的维语多模态图像理解**

### 英文项目名称

**Scene-Text-Enhanced Uyghur Multimodal Representation Fusion and Cross-Lingual Image Understanding**

### 未采用的候选（仅作对照，正文不要混写）

- 候选 A：视觉枢纽驱动的低资源维–汉跨模态语义对齐与检索
- 候选 C：面向黏着语形态稀疏的维–汉多模态特征融合与跨语言检索

### 研究定位

自然场景中的维吾尔语图像往往同时包含**物体外观**和**场景文字**（路牌、招牌、海报等）。现有多模态模型主要在英文/中文图文对上训练，对维吾尔语这种黏着语、从右向左书写、连写变体丰富的场景文字建模不足；仅用图像全局特征或仅用维汉平行文本，都难以把“图中写了什么”与“图中是什么”对齐到同一语义空间。

本项目以公开可核验数据为对象，研究：

1. 维吾尔语场景文字的视觉编码；
2. 图像外观、场景文字、维/汉描述三类异构特征的融合；
3. 在融合表征上完成**跨语言图像—文本检索**和**小规模跨语言图像理解**评价（维查询汉图、汉查询维图、图到维/汉描述）。

本项目形成的技术链条是：

> **场景维文视觉编码 → 图像—文字—双语描述多模态融合 → 跨语言检索与图像理解评价**

### 明确不做

1. 不把课题写成通用民汉机器翻译系统或语音交互系统（指南 1(b)(c) 仅作相关工作对照）；
2. 不采集社交网络舆情、不涉及敏感内容识别与安全对抗（指南方向 3）；
3. 不建设古籍数字化平台，不以东巴文/古彝文/水文/满文为主对象（指南方向 2）；
4. 不重复申请人已获资助课题的核心内容：
   - 天池英才「多模态融合技术研究及其在新疆产业集群中的应用」→ 本课题对象改为**民族语言场景图文**，不以产业集群为应用场景；
   - 新疆教育云开放课题「高校新能源多模态教学资源」→ 本课题不研究教学资源、课程知识或学习行为；
5. 不以学生个人信息、未授权街景人脸、未授权商业语料为数据来源；
6. 不承诺接入实验室生产系统或建设大型在线平台。

### 4.4 本课题拟自建的小规模评测协议（不是声称已有大规模维语 VQA 库）

在 Multi30k-Distant 测试集与 RUST 上，由研究团队按公开规则构造：

- 跨语言检索：汉查询→维描述图像、维查询→汉描述图像；
- 图像理解：针对图像中的物体/场景文字，构造有限数量的维/汉问题（建议正式评测 200–400 题，预实验另计），用于检验融合表征能否回答“图中写了什么 / 图中是什么”。

该评测集是项目**拟构建**的评价协议，不得在研究基础中写成已经完成的大规模基准。

## 5. 核心科学问题与基本假设（草案，流水线阶段 03 再收口）

1. **场景文字能否成为维语图像理解的稳定第三通道？** 在路牌、招牌等文字承载关键语义的图像上，加入维语场景文字编码，是否比纯图像编码器或纯图文 CLIP 式对齐更能提升跨语言检索和图像理解？
2. **异构特征如何在低资源下融合而不互相干扰？** 图像外观、连写维文、维/汉描述的粒度与噪声不同，何种融合与对齐目标能避免场景文字噪声损害物体语义，或物体特征淹没文字语义？
3. **视觉枢纽能否缓解维–汉远程语言对的对齐困难？** 维汉语序、形态和脚本差异大，以共享图像为枢纽，能否在缺少大规模维语 VQA 标注的条件下，仍然得到可检验的跨语言图像理解增益？

**基本假设：** 相对于（i）无场景文字的图文检索模型、（ii）仅做维语 OCR 再翻译、（iii）通用多语 CLIP 零样本，显式融合维语场景文字与图像外观，并在 Multi30k-Distant 上用图像作跨语言枢纽，可以提高汉↔维跨模态检索的 Recall@K / MRR，并提高小规模图像理解题的准确率。

## 6. 研究内容草案（流水线阶段 04–05 再展开）

1. **维吾尔语场景文字视觉编码**：在 SUST 上训练/适配词级场景文字编码器，在 RUST 上测试；输出供融合使用的文字区域特征，而不是停在 OCR 正确率竞赛。
2. **图像—场景文字—双语描述的多模态融合**：定义外观特征、文字特征、维/汉文本特征的输入输出与融合目标（对比学习 / 对齐损失），得到统一表征。
3. **跨语言检索与图像理解评价**：在 Multi30k-Distant 上报告 I2T/T2I、汉维互检索；在自建小规模理解题上报告准确率；对比无文字通道、OCR 流水线、通用多语视觉—语言模型等基线。
