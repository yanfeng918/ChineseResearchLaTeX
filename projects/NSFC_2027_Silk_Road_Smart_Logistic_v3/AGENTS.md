# NSFC 地区科学基金项目申请书 - AI 写作指令

本目录是 **国家自然科学基金地区科学基金项目**申请书的 LaTeX 工作区。AI 在此的核心任务是**辅助撰写和优化标书内容**，不做版式开发，不改动 `extraTex/@config.tex`（除非用户明确要求调整版式）。

第（一）部分建议 **8000 字以下**；全文原则上不超过 **30 页**，鼓励简洁表达。

---

## 文件职责映射

所有正文内容集中在 `extraTex/`，与 `main.tex` 中的章节一一对应：

| 文件 | 对应章节 | 内容要点 |
|------|----------|----------|
| `extraTex/1.1.立项依据.tex` | （一）1. 项目的立项依据 | 研究意义 / 国内外现状 / 发展趋势 / 应用前景 |
| `extraTex/1.2.内容目标问题.tex` | （一）2. 研究内容、目标、关键问题 | 研究内容 / 研究目标 / 拟解决的关键科学问题 |

| `extraTex/1.4.特色与创新.tex` | （一）4. 本项目的特色与创新之处 | 与三条研究主线对应的 1–3 条高含金量创新点 |
| `extraTex/1.5.研究计划.tex` | （一）5. 年度研究计划及预期结果 | 三年分年度计划 / 预期成果 / 学术交流计划 |

## 写作顺序建议

```
明确科学问题
  → 立项依据（1.1）
  → 研究内容 + 目标 + 关键问题（1.2）
  → 研究方案及可行性（1.3）
  → 特色与创新（1.4）
  → 年度研究计划（1.5）
  → 研究基础（2.1） + 工作条件（2.2）
  → 承担/完成项目（2.3, 2.4）
  → 其他说明（3.x）
  → 全文质量控制
```

> **注意**：地区科学基金与面上项目最大的结构差异在于，立项依据、研究内容、方案和计划**合并在第（一）部分**，统一控制在 8000 字以内。

## 各章节写作要点

### （一）立项依据 → `extraTex/1.1.立项依据.tex`

写作逻辑：**研究意义** → **国内外研究现状及发展动态分析** → **科学意义或应用前景**

- 参考文献随立项依据之后渲染，通过 `\cite{key}` 引用，文献条目维护在 `references/myexample.bib`
- 可结合"科学研究发展趋势"论述科学意义，或结合"国民经济和社会发展的关键需求"论述应用前景

### （一）研究内容、目标、关键问题 → `extraTex/1.2.内容目标问题.tex`

- 研究内容：此部分为**重点阐述内容**
- 研究目标：明确、可验证
- 关键科学问题：1–3 个，需与研究内容高度对应

### （一）研究方案及可行性 → `extraTex/1.3.方案及可行性.tex`

- 包含研究方法、技术路线、实验手段、关键技术

### （一）特色与创新 → `extraTex/1.4.特色与创新.tex`

- 聚焦科学意义而非技术堆叠，原则上与三条研究主线一一对应，1–3 条，言简意赅

### （一）年度研究计划 → `extraTex/1.5.研究计划.tex`

- 三年分年度，预期产出（论文/方法/数据库等）具体可查
- 可包含重要学术交流活动、国际合作计划

### （二）研究基础 → `extraTex/2.1–2.4.*.tex`

- **2.1**：用证据链（代表性论文/项目/数据）证明申请人有能力完成本课题
- **2.2**：已具备条件 + 缺少的条件 + 解决方案，简洁务实
- **2.3–2.4**：如实填写，格式参照模板中的 `\NSFCBlankPara` 占位区

## 常用 LaTeX 命令速查

```latex
% 空白占位符（草稿期使用，填写内容后删除）
\NSFCBlankPara

% 正文文件开头推荐加（两端对齐 + 2em 段首缩进）
\justifying
\NSFCBodyText

% 列表项标题（加粗蓝色标题 + 正文内容）
\item \itemtitlefont{标题：}内容...

% 三级标题（自动编号 1.1 风格）
\subsubsection{标题}

% 四级标题（自动编号（1）风格）
\subsubsubsection{标题}

% 圈号行内小标题
\ssssubtitle{1}

% 插入图片
\begin{figure}[!th]
    \begin{center}
        \includegraphics[width=0.8\linewidth]{figures/图片名.jpg}
        \caption{图片说明文字}
        \label{fig:label}
    \end{center}
\end{figure}

% 引用文献
已有研究表明...\cite{bibkey}
```

## 工程原则

- **只改内容文件**：仅修改 `extraTex/*.tex`、`references/myexample.bib`、`figures/`；不改 `@config.tex` 版式（除非用户明确要求）
- **先读后写**：修改前先读取目标文件，了解现有内容和占位符再动笔
- **不造假引用**：添加参考文献必须经 `nsfc-bib-manager` 核实，不虚构 BibTeX 条目
- **篇幅意识**：第（一）部分建议 8000 字以内；全文不超过 30 页；超出时优先用 `nsfc-length-aligner` 压缩
- **语言**：始终用简体中文与用户交流，撰写中文标书内容
- **原始指南为范围硬约束**：`docs/00_项目基本信息.md` 中的三项核心任务是本项目的单一范围基准，后续查新、科学问题凝练和评审只能提高其科学性与可检验性，不得擅自删除、合并或降级任一主线。若证据、设备或合作条件暂缺，应标记为“待补事实/分层验证”，不能据此改写研究意图；任何实质性缩题必须先取得用户确认。
- **稳定的三条研究主线**：研究内容一为货物多模态智能感知与异常识别，覆盖振动、倾斜、电子封志、光感和包装图像，服务运输全过程状态监测、包装破损/变形识别与异常告警；研究内容二为弱网通信、边缘计算与低功耗协同，覆盖 2G/3G 等弱网下的可靠上传、离线缓存、断点续传、自适应压缩、边缘推理和设备低功耗管理；研究内容三为仓储环境多源感知与异常预警，覆盖温湿度、安防视频、烟雾、门禁的实时监测、复合异常识别、分级预警与应急响应。三条主线共同服务新疆口岸—中亚运输—边境仓储链路，但不扩展为综合物流平台、运输路径优化或宏观供应链决策。
- **问题与内容一一映射**：研究内容一 ↔ 科学问题 Q1 ↔ 假设 H1（异步、缺失和噪声下多模态互补信息的可靠表征与货物异常辨识）；研究内容二 ↔ Q2 ↔ H2（通信、计算和能量耦合约束下，风险/信息价值驱动的感知—推理—压缩—缓存—续传协同边界）；研究内容三 ↔ Q3 ↔ H3（不同时标、不同可靠性的仓储多源证据如何形成可校准的复合风险演化与提前预警）。运输阶段状态可作为仓储模型的可选先验和扩展验证，但不能替代仓储主线，缺少货物级配对数据也不得删除研究内容三。
- **术语与验证口径**：弱网统一指高丢包、低带宽、长时延和间歇连接；边缘协同同时包含本地推理、摘要/压缩、优先缓存、断点续传、可靠上传与动态工作周期，低功耗属于核心目标而非附加指标。Q1 报告事件级 AUPRC/F1、包装损伤 mAP/IoU、Brier/ECE 及缺失/噪声退化；Q2 报告上传成功率、高风险漏报率、P95 告警时延、传输字节、推理开销和单位任务能耗；Q3 报告事件级检出率、误报率、预警提前量、校准误差和跨条件稳健性。所有数据按完整运输任务或完整仓储事件分组，严格执行 `available_time <= prediction_time`、训练/校准/测试分离和测试揭盲前冻结阈值。
- **文献与方法边界**：立项依据按“跨境物流需求—货物多模态可靠感知—弱网通信/边缘计算/低功耗—仓储多源异常预警—不确定性与稳健评价”组织证据链，引用紧跟所支撑主张。容迟网络、信息时效和任务导向通信用于解释可靠上传与信息价值，不能替代多模态异常识别、能耗约束或仓储风险建模；现场条件尚未落实时，以受控实验、公开数据和弱网轨迹回放建立内部有效性，并将真实场景验证写成有条件的外部验证，不虚构合作、设备或数据。
