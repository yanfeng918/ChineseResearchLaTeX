# 选题与研究主题

工作题：**矿山地表扰动遥感变化检测的跨域泛化与可信评估研究**。

英文：Cross-Domain Generalization and Reliability Assessment for Remote Sensing Detection of Mining-Induced Surface Changes。

研究对象是公开双时相遥感影像中与矿山足迹及邻近地表覆盖有关的可见变化。输出为变化位置、范围、变化概率及辅助复核的优先级。二值变化标注不能支持污染、沉降、尾矿库安全风险或采矿活动因果归因。

中心问题：在训练时未见的矿区，稳定背景的外观差异怎样影响变化判别，何种可靠性信息能够在固定人工复核预算下识别模型遗漏和误报？

子问题包括：矿区隔离后性能变化是否稳定出现，主要来自何类错误；仅约束训练数据中明确未变化的背景，能否降低背景误报且保留细小变化；独立矿区校准后，错误排序能否比原始置信度或简单温度缩放提供更有用的复核线索。

主数据为 MineNetCD，先核验矿区 ID 与切片来源，审计官方划分和模型权重训练覆盖。EuroMineNet 是条件性扩展，不能直接混合其足迹标签和 MineNetCD 的变化真值。新疆案例和矿企合作不作为已落实条件。

| 中文关键词 | 英文标准检索词 |
|---|---|
| 矿山地表变化 | mining-induced surface change; mining footprint |
| 双时相变化检测 | bi-temporal remote sensing change detection |
| 跨矿区泛化 | cross-site generalization; unseen mining sites |
| 域泛化 | domain generalization; domain-agnostic learning |
| 背景混淆 | pseudo-change; background confusion |
| 概率校准 | probability calibration; calibration under distribution shift |
| 选择性预测 | selective prediction; risk–coverage |
| 人工复核 | human review; error prioritization |
| 空间验证 | spatial cross-validation; spatial leakage |
| 公开基准 | MineNetCD; EuroMineNet |

检索组合：mining change detection + benchmark；remote sensing change detection + domain generalization；pseudo-change + background invariance；segmentation + calibration + distribution shift；selective prediction + error detection；spatial cross-validation + remote sensing。检索覆盖 2021–2025 完整自然年及截至 2026-09-05 的进展，同时保留校准和空间验证的奠基工作。

选题保留条件是公开数据能支持矿区追溯、基线可复现且失效可检验。当前处于方案阶段；若误差诊断指向配准或标签问题，优先处理数据，随后调整方法性假说。
