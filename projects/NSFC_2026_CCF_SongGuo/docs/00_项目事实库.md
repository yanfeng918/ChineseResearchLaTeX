## 2. 一句话项目定位

面向任务分布、工具环境与反馈质量持续变化的动态场景，研究大模型智能体的**参数高效持续后训练、可信轨迹学习与决策置信校准**方法，使 Agent 能够以较低训练成本持续获得新能力、抑制灾难性遗忘，并在高风险或低置信场景下做出可校准、可审慎的决策。

## 3. 选题逻辑与核心矛盾

本项目不把“时间序列预测”作为基金题目的主应用，而把其作为一种天然存在**非平稳性、分布漂移与不确定性**的动态验证环境。项目聚焦 Agent 自身的通用技术问题：

1. **参数效率 vs. 持续获得新能力**：Agent 面对新任务时，如何只更新少量参数并保持高效适配？
2. **适应新任务 vs. 保留旧能力**：持续后训练过程中，如何降低灾难性遗忘和能力相互干扰？
3. **模型置信度 vs. 真实决策可靠性**：Agent 如何识别“不知道”、错误反馈和高风险状态，并据此重规划、调用工具或拒答？
4. **训练样本规模 vs. 轨迹质量**：如何利用不确定性、验证器和多源反馈，从大量 Agent 轨迹中识别真正有价值的后训练样本？

## 4. 拟解决的关键科学问题

### Q1. 动态任务下参数高效能力适配的机制

如何建立任务状态、参数子空间与 Agent 能力变化之间的映射关系，在不进行全参数更新的情况下，动态决定“**更新哪些参数、分配多少参数、复用哪些历史适配器**”，实现高效持续适应？

### Q2. 不确定性驱动的 Agent 轨迹质量建模与可信后训练机制

如何联合利用模型不确定性、工具执行结果、验证器反馈和轨迹一致性，建立 Agent trajectory 的可信质量评分，并进一步转化为后训练中的**样本筛选、加权、重采样与偏好构造信号**？

### Q3. 持续后训练中的抗遗忘与可信决策校准机制

如何在学习新任务的同时保持历史能力，并对 Agent 的答案、动作和工具调用置信度进行校准，使其在任务分布漂移和风险上升时能够主动**重规划、追加验证、降级执行或拒绝输出**？

## 5. 总体研究目标

构建一套面向动态任务的 PACT-Agent 方法与原型框架，形成“**动态任务感知 → 参数高效适配 → 可信轨迹学习 → 持续抗遗忘 → 决策校准 → 风险感知执行**”的闭环后训练体系，并在通用 Agent 任务以及动态时序任务中验证其有效性、泛化性和计算效率。

具体目标：

- 建立动态任务感知的参数高效后训练策略；
- 建立不确定性驱动的 Agent 轨迹质量评估与训练样本构造方法；
- 建立面向持续任务的经验记忆、适配器复用与抗遗忘机制；
- 建立 Agent 行为置信度校准和风险感知决策机制；
- 构建可复现实验框架，并形成算法、代码、数据/轨迹资源与论文成果。

## 6. 研究内容

### 研究内容一：动态任务感知的参数高效 Agent 后训练

研究任务表征、任务漂移检测与参数子空间分配之间的关系，探索动态 LoRA rank、Adapter routing、任务条件化低秩参数及历史适配器组合机制。在给定算力预算下，使 Agent 能够根据任务变化自动调整可训练参数规模与更新位置。

**预期产出：** 动态参数分配算法 + 参数高效 Agent 后训练模块。

### 研究内容二：不确定性驱动的高质量 Agent 轨迹筛选与学习

针对自动生成轨迹存在错误步骤、伪成功、工具异常和错误反馈累积的问题，联合模型置信度、执行反馈、轨迹一致性和 verifier 结果构建 trajectory quality score，并用于样本过滤、样本加权、偏好对构造和难例挖掘。

**预期产出：** 可信轨迹评分机制 + 高质量后训练数据构建流程。

### 研究内容三：持续任务下的能力记忆与抗遗忘后训练

研究 Adapter Memory、experience replay、能力簇记忆和参数正则化等机制，在连续任务或任务分布切换场景中降低灾难性遗忘；探索历史适配器选择、合并、冻结与增量更新策略。

**预期产出：** 持续 PEFT/Adapter Memory 算法 + 动态任务连续学习协议。

### 研究内容四：Agent 决策可信校准与风险感知执行

研究答案置信度、工具调用置信度与任务成功概率之间的校准关系，引入 calibration、selective prediction、verifier 和 risk-aware planning，使 Agent 在低置信状态下触发重新规划、工具复核、追加证据或拒绝执行。

**预期产出：** Agent 决策校准模块 + 风险感知执行策略。

## 7. 建议技术路线

```text
动态任务/环境变化
      ↓
任务状态表征与分布漂移检测
      ↓
动态参数预算与 Adapter/LoRA 路由
      ↓
Agent 交互与多步轨迹生成
      ↓
不确定性 + 工具反馈 + Verifier + 一致性评估
      ↓
可信轨迹筛选 / 加权 / 偏好构造
      ↓
参数高效持续后训练
      ↓
Adapter Memory + Replay + 抗遗忘约束
      ↓
置信度校准与风险感知规划
      ↓
通用 Agent + 动态时序场景双层验证
```

## 8. 建议创新点

### 创新点1：从“固定 PEFT”转向动态任务驱动的参数预算分配

不再预先固定 LoRA rank 或单一 Adapter，而是根据任务状态、能力缺口和漂移程度动态决定参数更新预算，实现训练成本与适应能力的自适应平衡。

### 创新点2：将不确定性建模引入 Agent trajectory 后训练数据选择

从“只看最终 reward/成功标签”扩展到“步骤级不确定性 + 工具执行证据 + verifier + 轨迹一致性”的可信质量建模，提高自动生成后训练数据的有效信息密度。

### 创新点3：联合 Adapter Memory 与轨迹记忆抑制持续后训练中的灾难性遗忘

把参数记忆和经验轨迹记忆统一到持续 Agent 后训练过程中，实现新任务学习、历史能力保持和适配器复用之间的协同。

### 创新点4：把可信校准从答案层扩展到 Agent 动作与工具调用层

对“回答什么”之外的“是否继续推理、是否调用工具、是否重规划、是否拒绝执行”进行风险校准，使可信性真正进入 Agent 决策闭环。

## 9. 实验设计框架

### 9.1 双层实验环境

**A. 通用 Agent 环境**  
选择多步推理、工具调用、规划/执行类 Agent 基准，检验方法的通用性。

**B. 动态时序环境**  
构造金融、能源或气象等具有明显分布漂移和不确定性的任务序列，用作动态任务和可信决策验证环境；时序场景用于体现研究积累，但不把项目收缩为单一行业应用。

### 9.2 主要对照

- Base LLM / Base Agent（无后训练）
- Full Fine-tuning
- Static LoRA / QLoRA
- 动态 rank / Adapter 类 PEFT 方法
- 仅 replay 的持续学习方法
- 仅 verifier/trajectory filtering 方法
- 仅 calibration 方法
- **PACT-Agent 完整方法**

### 9.3 核心消融

- 去除动态参数分配；
- 去除轨迹不确定性评分；
- 去除 Adapter Memory；
- 去除 replay；
- 去除可信校准；
- 不同任务漂移强度；
- 不同可训练参数预算；
- 不同轨迹噪声比例；
- 不同模型规模/不同 Agent backbone。

## 10. 建议评价指标

### Agent 能力
- Task Success Rate / Pass Rate
- Reward / Goal Completion
- Tool-use Accuracy
- Planning / Step Accuracy

### 持续学习
- Average Accuracy / Success
- Forgetting Rate
- Backward Transfer / Forward Transfer
- 新任务适配速度

### 可信与校准
- ECE（Expected Calibration Error）
- Brier Score
- NLL
- Selective Risk / Risk-Coverage Curve
- 高风险任务错误执行率

### 效率
- Trainable Parameters
- GPU Memory
- Training Time / GPU Hours
- Inference Overhead

## 15. 申报书摘要的核心叙事（供后续展开）

动态任务环境中，大模型智能体需要持续学习新知识、新工具与新策略，但现有全参数后训练成本高，固定参数高效微调难以适应任务变化，自动生成轨迹又存在质量不稳定和错误反馈累积问题。同时，Agent 的语言置信度并不等价于行动可靠性，导致其在分布漂移或高风险任务中仍可能过度自信执行。本项目拟研究面向动态任务的大模型智能体参数高效自适应后训练与可信校准方法，建立动态任务感知的参数预算与适配器路由机制、基于不确定性和多源反馈的可信轨迹学习方法、面向持续任务的能力记忆与抗遗忘机制，以及面向答案—动作—工具调用全过程的决策校准方法，形成低成本持续适应与风险感知决策一体化的 PACT-Agent 框架，并在通用 Agent 与动态时序任务上开展系统验证。
