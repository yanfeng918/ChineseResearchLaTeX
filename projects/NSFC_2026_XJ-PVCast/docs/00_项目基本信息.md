# 项目基本信息

- 题目：多源气象驱动的新疆光伏功率多尺度概率预测与爬坡风险预警研究。
- 类别：中国沙漠气象科学研究基金自由申报类；对应“丝路核心区气象服务关键技术”第5方向。
- 研究期：2027年1月至2028年12月；建议申请3万元，未获批。
- 对象：新疆典型并网光伏场站；具体站点和数据许可为F-XJ-01。
- 主线：可用气象信息的跨尺度增益、天气变化下概率校准、保持时间依赖的爬坡事件预测。
- 范围：以15分钟级短时预测设计为草案；日前预测仅在NWP归档落实后作为扩展，不承诺省域部署或业务准入。
- 模板：借用现有NSFC正文；正式提交需官方附件3、附件4和签章，见申报口径核查报告。
- 事实来源：共用申请人档案与本项目事实库，不复制他项人员/声明。
