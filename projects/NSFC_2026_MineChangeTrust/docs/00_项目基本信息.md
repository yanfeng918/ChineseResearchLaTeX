# 本次全流程的项目口径

本次申报对象为中南大学有色金属成矿预测与地质环境监测教育部重点实验室 **2026 年开放课题**。以项目事实库及其 2026 年指南来源为准，目录名和通用 NSFC 面上模板说明不改变申报类别。

用户指定运行 `nsfc-full-pipeline`；本次复用其 00–14 阶段组织正文，属于针对本项目的流程适配。该技能原生面向 NSFC，不能由此推断开放课题适用 NSFC 年限、经费、限项或声明。正文 PDF 是研究方案工作稿，官方申请书附件尚未取得，不能直接作为正式申请书提交。

| 项目 | 执行口径 |
|---|---|
| 题目 | 矿山地表扰动遥感变化检测的跨域泛化与可信评估研究（工作题） |
| 申请人 | 颜丰，新疆大学；稳定事实读取仓库共用申请人文件 |
| 研究期限 | 建议 24 个月，最终由批复确定；不套用模板中的三年安排 |
| 模板布局 | `main.tex` 实际启用的三段式正文及其他说明 |
| 篇幅 | 保留项目模板 30 页内部上限；以约 15–20 页为草稿组织预算。该预算不是开放课题官方篇幅要求 |
| 正文范围 | 立项依据、研究内容、特色与创新、年度计划、研究基础、工作条件、相关项目和启用的其他说明 |
| 不适用项 | NSFC 申请代码、NSFC 特有完成情况和年度申报声明；原正文文件按项目指令保持不写不问，仅在工作稿总说明解释不适用，不追问 NSFC 系统声明 |
| 禁用文件 | `extraTex/3.5.其它相关说明.tex`、`extraTex/4.5.生成式人工智能.tex` 未被主文件启用，不写入 |
| 主数据 | MineNetCD；公开发布页存在不等于本项目已经取得、核验并运行数据 |
| 扩展验证 | EuroMineNet，输入与标签适配后单独报告；铜矿边界仅作案例属性匹配 |
| 科学结论边界 | 所有方法收益均为待验证假设，不填虚构性能或前期结果 |
| 申报组件 | 摘要仍是事实库工作稿；预算、正式声明和附件待完成；申请代码不适用 |

文献子流程按本项目的证据需要执行，采用全流程技能的 25 条以上、目标 30–50 条参考口径，集中查证数据、变化表征、域泛化、校准和空间验证。研究选题子流程复用该证据池逐候选查新，不将资料充分性误写为已经完成实验。

事实使用特别约束：共用申请人文件中含“本申请”的成员配置、成果选择和项目排除意见带有其他项目语境，不能移植为本矿山课题已确认名单。只复用稳定身份、已核验成果、明确设备条件和项目主体事实。

指南原始来源：[2026 年开放课题申请指南](https://gip.csu.edu.cn/info/1381/8673.htm)，本轮复核日期 2026-09-05。项目事实源：[项目事实库](00_项目事实库.md)。
