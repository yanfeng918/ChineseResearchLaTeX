# 4. 拟解决的核心科学问题

## 4.1 总体科学问题

> **复杂气象驱动下，新能源功率在不同时间尺度上的非平稳波动是如何形成并相互耦合的，以及如何将这种多尺度规律转化为可泛化的预测能力，并进一步把预测误差转化为可校准、可解释的运行不确定性与风险信息？**

## 4.2 科学问题1：多时间尺度气象驱动与功率波动的耦合机制

核心问题：

> 不同气象变量在不同时间尺度上如何影响新能源功率，其驱动作用是否具有时间尺度依赖性、动态性和场景差异性？

需要回答：

- 功率波动中哪些成分具有明显周期性、趋势性和突变性；
- 辐照度、温度、风速、云量等气象因素对不同尺度成分的影响是否不同；
- 正常天气与极端天气条件下驱动规律是否发生变化。

## 4.3 科学问题2：多尺度异构信息如何形成稳定、可泛化的预测表征

核心问题：

> 如何避免简单分解—独立预测—机械叠加导致的信息割裂，使多尺度功率模式、历史功率、历史气象和未来气象预报信息能够协同建模？

需要回答：

- 不同时间尺度的信息如何提取；
- 不同来源变量如何动态融合；
- 如何控制复杂度，避免过拟合；
- 如何提升跨季节、跨场景和极端波动条件下的泛化性能。

## 4.4 科学问题3：预测误差如何转化为可信的不确定性与运行风险信息

核心问题：

> 如何由单一确定性预测进一步获得统计意义可靠的不确定性区间，并使其能够反映极端误差、快速爬坡等安全运行关注事件？

需要回答：

- 如何估计不同运行状态下的预测不确定性；
- 如何保证区间覆盖率与区间宽度之间的平衡；
- 如何进行预测区间校准；
- 如何将不确定性结果进一步映射为爬坡风险、异常偏差风险等信息。

# 5. 研究目标

本项目只设置**3个研究目标**，不增加第4、第5目标。

## 目标1：揭示规律

揭示复杂气象条件下新能源功率的多时间尺度波动特征，以及关键气象因素与不同尺度功率变化之间的动态耦合关系，为预测模型设计提供规律依据。

## 目标2：提高预测

构建多时间尺度信息与异构气象信息协同建模的新能源功率预测方法，提高常规、季节变化及极端波动场景下的预测精度和泛化能力。

## 目标3：形成可信风险信息

建立新能源功率预测不确定性量化、校准与运行风险表征方法，由单一“点预测”扩展至“预测值—不确定性—风险信息”联合输出，为高比例新能源电力系统安全运行提供可信信息支撑。

# 6. 研究内容

> **硬约束：研究内容固定为3项。**  
> 三项之间必须具有递进关系：**规律认识 → 精准预测 → 可信风险评估**。

## 6.1 研究内容一：复杂气象驱动下新能源功率多时间尺度波动规律研究

### 研究目的

明确新能源功率多尺度变化模式及其与关键气象因素之间的关联，为后续模型结构设计提供物理/统计依据。

### 主要任务

1. 建立新能源功率与气象数据的标准化分析体系；
2. 利用时域、频域及时频域分析刻画功率序列：
   - 趋势；
   - 周期；
   - 高频随机波动；
   - 突变/爬坡。
3. 研究不同时间尺度上气象变量与功率波动之间的动态关联；
4. 对比正常天气、季节变化和极端波动场景中的驱动差异；
5. 形成可用于后续预测模型的多尺度先验与关键影响因素集合。

### 建议方法

- DWT/小波时频分析；
- 相关性与滞后相关分析；
- 条件互信息或轻量非线性依赖分析；
- 多尺度统计特征；
- 功率爬坡事件识别。

### 本部分产出

> 多尺度功率模式 + 不同尺度关键气象驱动因素 + 典型复杂场景划分。

---

## 6.2 研究内容二：多时间尺度异构信息协同的新能源功率预测方法研究

### 研究目的

解决多尺度功率模式以及历史功率、历史气象、未来气象信息之间的协同建模问题。

### 主要任务

1. 构建多时间尺度功率特征表示；
2. 分析历史功率、历史气象和未来NWP/气象预报信息的差异化作用；
3. 设计多尺度特征与气象条件信息的协同融合机制；
4. 建立统一预测模型输出未来新能源功率；
5. 开展跨季节、不同预测步长和极端波动场景验证；
6. 通过消融实验分析各模块贡献。

### 方法设计原则

模型结构强调：

```text
多尺度表征
   +
气象条件信息
   +
动态协同融合
   ↓
新能源功率预测
```

允许采用 Transformer、iTransformer、TCN、MLP/KAN 等作为基础组件或基线，但**申请书不得以堆叠模型名称作为创新点**。

### 本部分产出

> 一个结构清晰、复杂度适中、能够处理多尺度和异构条件信息的新能源功率预测模型。

---

## 6.3 研究内容三：新能源功率预测不确定性量化与运行风险表征研究

### 研究目的

将确定性功率预测扩展为具有可靠统计含义的可信预测结果，并建立与安全运行相关的风险表征方法。

### 主要任务

1. 分析不同天气、季节和功率变化状态下的预测误差分布；
2. 建立概率预测或区间预测方法；
3. 研究预测区间校准方法，提高覆盖可靠性；
4. 研究极端天气、功率爬坡等场景下的不确定性变化；
5. 构建由预测偏差、区间宽度、爬坡概率等信息组成的风险表征指标；
6. 形成面向安全运行的“预测—不确定性—风险”联合输出。

### 建议技术

优先考虑：

- 分位数回归；
- Conformal Prediction；
- 自适应/条件化区间校准；
- 概率分布或预测分位点；
- 爬坡风险检测。

### 本部分产出

```text
预测点值
+
预测区间/概率分布
+
区间可信度
+
极端波动/爬坡风险指标
```

# 7. 核心研究假设

后续写作可以围绕以下3个假设展开：

### H1：尺度依赖假设

新能源功率受气象因素驱动的作用机制具有明显的时间尺度依赖性；显式建模这种尺度差异能够提升复杂场景下的预测稳定性。

### H2：条件协同假设

不同尺度功率信息与历史/未来气象条件对预测的贡献随时间、天气状态及预测步长动态变化；自适应协同融合优于固定融合与简单拼接。

### H3：状态依赖不确定性假设

新能源预测误差不是独立同分布的固定随机噪声，而与气象状态、功率变化速率和预测时域密切相关；条件化与校准的不确定性建模能够形成更可靠的风险信息。

# 9. 关键方法与指标

## 9.1 确定性预测指标

正文中建议使用：

- MAE
- RMSE
- nMAE / nRMSE
- MAPE（仅在数值条件适用时使用）

避免仅报告单一指标。

## 9.2 概率/区间预测指标

优先考虑：

- PICP（Prediction Interval Coverage Probability）
- PINAW（Prediction Interval Normalized Average Width）
- Winkler Score
- CRPS（若输出完整概率分布）
- Calibration Error / Reliability

核心评价原则：

> **区间不是越宽越好，必须同时关注覆盖率与尖锐度（sharpness）。**

## 9.3 极端/爬坡事件指标

建议：

- Precision
- Recall
- F1-score
- Event-based Recall
- 极端场景MAE/RMSE
- 爬坡幅度误差、发生时间误差（根据数据条件选用）

# 10. 数据与实验设计约束

## 10.1 数据使用原则

1. 优先使用具有明确来源、可复现的公开新能源功率与气象数据；
2. 可同时使用光伏和风电数据验证方法普适性；
3. 可结合新疆高比例新能源基地作为应用背景和典型场景；
4. **若未取得新疆实际场站/电网私有数据，不得在申请书中写成已经拥有或已经完成真实新疆场站数据验证；**
5. 可表述为：
   - “面向新疆大型新能源基地的典型需求”；
   - “选取公开数据和代表性新能源场景开展验证”；
   - “后续结合合作条件进一步开展区域场景验证”。

## 10.2 推荐实验维度

实验至少覆盖：

### A. 常规预测实验
- 不同预测步长；
- 不同季节；
- 不同数据规模。

### B. 对比实验
传统方法 + 主流深度时序基线 + 本项目方法。

### C. 消融实验
重点验证：

- 无多尺度建模；
- 无气象条件协同；
- 无动态融合；
- 无不确定性校准。

### D. 复杂场景实验
至少选取：

- 天气突变；
- 强波动；
- 功率爬坡；
- 极端预测误差样本。

### E. 泛化实验
根据数据条件选择：

- 跨季节；
- 跨场站；
- 光伏→光伏不同场站；
- 风电→不同风场。

# 11. 项目创新点

> **创新点固定为3点。**  
> 每一点必须写成“问题—新认识/新方法—价值”，不得写成纯模块清单。

## 创新点1：复杂气象驱动的新能源功率多时间尺度动态表征

突破将新能源功率简单作为单一时间尺度序列建模的方式，从不同时间尺度分析气象驱动与功率变化之间的动态耦合关系，为预测模型建立具有明确依据的多尺度结构。

**关键词：** 多尺度、气象驱动、动态耦合、非平稳。

## 创新点2：多尺度功率模式与异构气象条件的自适应协同预测

针对历史功率、历史气象、未来气象以及不同尺度功率特征预测价值动态变化的问题，研究轻量、自适应的协同融合机制，增强复杂天气和跨场景条件下的预测稳定性与泛化能力。

**关键词：** 异构信息、条件融合、自适应、泛化。

## 创新点3：面向安全运行风险的预测不确定性校准与表征

突破只优化单点误差的传统预测范式，研究状态依赖的预测区间与可靠性校准方法，并结合极端偏差和功率爬坡事件形成风险表征，实现由“准确预测”向“可信预测”的扩展。

**关键词：** 不确定性、校准、可信预测、风险表征。

# 16. 明确禁止扩展的内容

后续 Codex/full-pipeline **不得自行加入以下主线**：

## 16.1 不以LLM/Agent为主线

禁止把项目变成：

- 大语言模型赋能新能源预测；
- 电力智能体；
- 多智能体调度；
- Agent自治运行；
- RAG电力知识库。

LLM/Agent若出现，只能作为远期展望，不进入三项核心研究内容。

## 16.2 不扩展成完整电网调度控制项目

不把本项目扩展为：

```text
功率预测
→ 优化调度
→ 机组组合
→ 最优潮流
→ 安全控制
→ AGC
→ 电网闭环控制
```

本项目的边界停留在：

> **为安全运行提供“可信预测与风险信息支撑”。**

## 16.3 不虚构电力系统机理研究

申请人主要优势是人工智能和时间序列预测，因此不应为了“像电力项目”而虚构：

- 暂态稳定机理模型；
- 电磁暂态仿真；
- 电网稳定控制器设计；
- 电力电子器件控制；
- 大规模潮流优化。

可合理使用电力系统业务概念，但必须与实际研究能力相匹配。

## 16.4 不堆算法名称

避免：

> DWT + EMD + SSA + VMD + Transformer + KAN + GNN + LLM + Diffusion + MoE……

原则：

> **一个核心多尺度机制 + 一个统一预测主干 + 一个不确定性校准机制即可。**

## 16.5 不重复现有已立项项目

如果申请人已有新能源功率预测相关国家/省部级在研项目，必须在后续正式申请书中明确区分：

- 研究对象；
- 核心科学问题；
- 技术路线；
- 项目目标；
- 预期成果。

本课题应突出：

> **“安全运行需求下的多时间尺度可信预测与不确定性风险表征”**

而不是复制已有项目的技术方案。

# 18. 建议的项目摘要逻辑模板

后续生成正式摘要时严格遵循以下5句逻辑：

### 第1句：背景与需求
高比例新能源接入使功率波动性和不确定性显著增强，准确、可信的新能源功率预测是新型电力系统安全运行的重要信息基础。

### 第2句：现有问题
现有方法对复杂气象驱动下的多时间尺度非平稳规律刻画不足，多源气象与功率信息协同能力有限，同时以单点精度为主的预测结果难以反映实际运行风险。

### 第3句：研究内容
本项目研究新能源功率多时间尺度波动及气象驱动规律，构建多尺度异构信息协同预测方法，并进一步建立状态依赖的预测不确定性量化与校准机制。

### 第4句：风险支撑
结合极端误差和功率爬坡等典型场景，形成“预测值—不确定性—风险信息”联合表征。

### 第5句：意义
研究成果将为高比例新能源电力系统安全运行提供更加准确、可靠和可量化的新能源功率预测信息支撑。

# 22. 最终冻结版本

## 项目名称

**面向高比例新能源电力系统安全运行的多时间尺度功率预测与不确定性评估方法研究**

## 项目主线

**多尺度规律 → 协同预测 → 不确定性校准 → 风险表征 → 安全运行支撑**

## 三项研究内容

1. **复杂气象驱动下新能源功率多时间尺度波动规律研究**
2. **多时间尺度异构信息协同的新能源功率预测方法研究**
3. **新能源功率预测不确定性量化与运行风险表征研究**

## 三个研究目标

1. 揭示多尺度波动与气象驱动规律；
2. 构建多尺度异构信息协同预测方法；
3. 建立可信不确定性与运行风险表征方法。

## 三个创新点

1. **多时间尺度气象驱动动态表征**
2. **多尺度功率—异构气象信息自适应协同预测**
3. **面向安全运行风险的预测不确定性校准与表征**

## 最终研究边界

> 本项目研究终点是**可信新能源功率预测与风险信息支撑**，不是电网优化调度与闭环控制。
