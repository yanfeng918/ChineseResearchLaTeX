# 研究方案与技术路线

## 一、总体目标与设计原则

本项目拟解释中文预训练语料中“相近低质量表征为何形成不同作用路径与反事实响应”。研究不以开发更高分的过滤器或寻找统一最优阈值为目标，而是围绕两个可被独立反证的路径展开：一是结构缺陷损伤及恢复是否使训练更新更对齐有效学习目标；二是移除结构完整但模型低熟悉的中文语体时，非冗余语义支持损失是否导致相应能力下降。两套估计量不被解释为同一种过滤效应的方向比较；结论限定在预先定义的数据来源、中文语体和模型范围内。

总体设计遵循四项原则：其一，区分文档级结构缺陷、集合级语义支持、训练轨迹级候选中介、模型运行级能力结局和环境级外部效度；其二，采用可逆干预、恢复和负对照形成反事实，而非依赖质量分数与能力的相关回归；其三，固定非 padding token、模型初始 checkpoint、训练配置和数据曝光口径，以独立训练运行为推断单位；其四，设置操纵、科学效应和外部复核三类停止闸门，允许假设被否定并据此收缩后续任务。

## 二、研究目标、内容与证据对应

### 目标 1：识别结构缺陷削减路径

围绕段落错序、异常截断、连接结构破坏等可逆低层缺陷，构造“结构完整—结构破损—sham 编辑”对照。在语义单元、来源、字符/token 长度、序列数、packing 边界和训练预算可比的条件下，检验原文恢复是否改变能力定向梯度对齐并改善独立通用能力。

预期证据包括：结构完整臂相对结构破损臂的运行级能力效应；结构完整臂相对 sham 臂的处理特异效应；处理先改变能力定向梯度对齐、后改变能力的时间顺序；在留出种子和第二来源上，动力学读出对能力变化提供超出处理标签和静态质量特征的预测。能力结果揭盲前先验收 sham；预期为结构完整优于结构破损与 sham，且破损与 sham 等效。若 sham 与完整等效，则判为操纵失败或当前剂量下结构效应不可识别，结构路径停止，不以优化器重调作结果后挽救。

### 目标 2：识别非冗余语义支持路径及状态边界

选择一类确认性中文语体对，暂定为“规范书面表达—结构完整、来源可核验但模型低熟悉的网络/地域书写语体”；另选一种书写或语体现象作稳健性复核，暂定为简繁/异体或中英混写中的一种。正式对象须经人工盲审确认语义完整、事实一致和语体合法，并在至少两类异质质量表征上与结构破损样本形成足够分数重叠。

在固定目标语体 token 曝光量、文档长度、平均质量分、来源可信度和训练预算时，分别补入同语体非冗余样本、同语体等量重复/窄支持样本和主流高分文本。比较三者对目标语体与长尾能力的影响，检验非冗余支持而非单纯语体曝光、等量补数或评测词汇重叠能否解释恢复效应。共同 checkpoint 后的小规模随机分叉用于观察处理前知识状态是否调节该路径；状态分析不用于训练动态选样算法。

关键支持模式为：同语体非冗余补回优于主流文本补回和同语体窄支持补回，并使覆盖敏感能力回到完整参考臂的预注册等效范围。若仅同语体 token 数决定结果，或恢复优势在作者/站点、时间、主题和模板隔离后消失，则非冗余支持机制被否定。

### 目标 3：检验双路径的有限外部效度

在来源 A 完成确认性研究后冻结数据处理协议、主终点、主动力学读出、效应方向和分析代码，在独立来源 B 上复核两条主效应。来源 B 用于回答效应能否运输或在哪些条件下失效，不重新选择最有利语体、阈值或指标。只有前两项研究越过科学效应闸门时，才启动同家族更大尺度模型的边界探索。

外部效度分为三个口径：效应方向能否复现、效应量是否落入来源 A 的冻结预测区间、支持重叠不足时不确定性能否触发拒绝外推。固定小样本校准只允许执行一次；若不能改善来源外误差，应将该环境判为不可直接运输，而不是继续增加来源或模型追求同向结果。模型尺度只作探索，不识别 tokenizer、架构和基础训练史各自的因果作用。

## 三、数据、处理臂与测量体系

### 3.1 数据来源与准入

来源 A 与来源 B 将从许可条款清楚、来源可追溯、允许科研处理的公开中文语料中确定，暂定分别覆盖异质网页/社区表达和相对规范的百科或知识文本。正式选择前完成数据卡，记录许可、抓取或发布版本、来源组成、隐私与敏感内容处理、去重版本和可公开范围。无法核验许可或来源的文档直接排除，不以模型效果抵消合规风险。

每个来源按来源层、语体层、主题/实体层和重复簇建立索引。确认性训练前须保证最严格处理臂仍能提供预定独立 token，不通过增加重复曝光凑足预算；若不满足，则所有处理臂统一下调到共同独立 token 上限。

### 3.2 六个共享处理臂

| 代码 | 处理臂 | 识别作用 |
|---|---|---|
| A0 | 共同破损前体经精确逆操作恢复，并保留原目标语体支持 | 两条路径的共同参考 |
| A1 | 保留共同前体的结构破损状态 | 估计结构损伤总效应 |
| A2 | 对共同破损前体作等量无效操作，不恢复结构 | 检验结构处理特异性 |
| A3 | 移除目标低频语体，补入等 token、匹配长度和质量分的主流文本 | 支持损失与主流伪恢复对照 |
| A4 | 移除同一集合，补入不重合的同语体非冗余样本 | 检验同语体支持恢复 |
| A5 | 移除同一集合，补入同语体等量重复或窄支持样本 | 区分非冗余支持与语体曝光 |

A0/A1/A2 的目标文档与 A3/A4/A5 的语体目标集合原则上不重叠，避免共享参考臂受到交叉干预。A3—A5 严格匹配目标语体 token 量或明确记录其差异；主要支持效应由 A4-A3 和 A4-A5 两个对比共同界定，而不是只看 A4 相对基线的提升。

### 3.3 质量表征、人工审计和能力终点

质量表征至少采用两类相互异质的方法：基于模型困惑度/可学习性的连续评分，以及基于来源与规范性的分类或多维评分。二者用于构造“分数重叠、生成机制不同”的样本层，不作为因果变量。人工复核在不知道处理臂和模型结果的条件下标注结构完整性、语义保持、事实一致性与语体合法性；一致性低于暂定返工线 Krippendorff $\alpha=0.67$ 时，修订操作定义并重新标注。

设置两个确认性能力终点：$Y_{general}$ 汇总通用语言与知识保持任务，$Y_{register}$ 汇总目标语体与长尾能力任务；具体任务、聚合方向和权重在揭盲前冻结。综合榜单分只作描述，不用任意权重证明效应。训练集、诊断集与最终测试集按文档、作者/站点、时间、主题和高阶模板隔离，并报告不同词汇重叠阈值下的敏感性结果。

### 3.4 主动力学读出

唯一主动力学读出为“能力定向梯度对齐”：在预注册 checkpoint 和固定 probe mini-batch 上，对末层低秩投影梯度计算处理语料与完全独立通用/目标语体诊断集之间的单位 token 归一化余弦；内积只作敏感性分析。主公式、投影维度、checkpoint、probe 和归一化均在揭盲前冻结。该读出只表示一次局部更新对诊断损失的预期方向，不等同于完整因果中介。

## 四、实验规模与统计分析

下表为不依赖尚未确认 GPU 资源的保守上限草案；所有规模均标记为暂定，并由首轮吞吐、功效和独立 token 审计校准。

| 执行阶段 | 任务 | 处理与重复 | 单次 token（暂定） | 运行数上限 | 闸门 |
|---|---|---:|---:|---:|---|
| 第一年度 | 数据/评测流水线与操纵先导 | A0--A5 各 1 次 | 0.10B | 6 | 非推断性；评分重叠、人工一致性、语义保持或平衡失败即返工 |
| 第二年度 | 来源 A 双路径确认 | A0--A5 × 6 个全新成对种子 | 0.40B | 36 | 任一路径落入预定无效区间即停止该分支外推 |
| 第三年度 | 来源 B 冻结协议外部复核 | A0、A1、A3、A4 × 6 个成对种子 | 0.40B | 24 | 方向反号或一次校准无改善即判拒绝外推 |
| 第四年度 A | 处理前知识状态探索 | 2 个共同 checkpoint × A4/A5 × 2 分叉种子 | 0.10B | 8 | 支持路径失败则取消；只报告方向和区间 |
| 第四年度 B | 同家族尺度探索 | A0、A1、A3、A4 × 2 个成对种子 | 0.25B | 8 | 来源复核失败则取消；不作普遍显著性主张 |

上限共 82 次训练运行、约 27.4B 处理 token；其中来源 A 的 36 次构成核心确认性证据，来源 B 的 24 次构成冻结协议外部复核，16 次状态/尺度运行均可按闸门取消。工程 smoke test、失败重跑和纯评测不计入科学运行，但另预留 20%--30% 运维余量。若首年实测资源不足，按“取消尺度探索—取消状态探索—统一降低单次 token”的顺序收缩，优先保护来源 A 的六个成对主种子和关键负对照。

统计推断以独立训练运行为单位。同一主种子在各处理臂间成对映射语料抽样、batch 顺序、dropout 和评测随机状态。结构与支持路径各预分配单侧 $\alpha=0.025$，不设路径间门控。结构路径要求 A0--A1、A0--A2 的单侧 $97.5\%$ 随机化反演置信下界均超过实践阈值；支持路径要求 A0--A3、A4--A3、A4--A5 满足同一规则，且 A4--A0 的双侧 $95\%$ 区间完全落入等效界值。任一必要条件失败即不确认完整路径，区间跨界时报告证据不足。功效模拟低于 $80\%$ 时先把可选 2.8B token 转给来源 A 增加配对种子，仍不足则降为区间估计性研究。

结构路径要求 A0 相对 A1、A2 均优效；支持路径先以 A0--A3 定义支持损失总效应，再要求 A4 在 $Y_{register}$ 上优于 A3、A5，并与 A0 等效；A4 未与 A0 等效时只称部分恢复。动力学证据同时满足处理改变、时间先行、共同逆转和留出预测增益才支持候选机制，其中六种子留出预测只作探索性支持。

## 五、技术路线

总体路线为：

`许可与来源审计 → 中文语体预注册与人工盲审 → 两类质量表征及同分层构造 → 六臂反事实语料生成与平衡审计 → 来源 A 成对随机继续预训练 → 能力定向梯度对齐与独立能力评价 → 路径特异效应/等效性判定 → 来源 B 冻结复核 → 条件化运输或拒绝外推 → 可选状态/尺度边界探索`。

其中，数据层输出可复核的数据卡、处理清单和干预生成器；训练层输出带唯一编号的 run manifest、checkpoint 和资源日志；证据层输出运行级效应、等效区间、动力学—能力时间序列及反证结论；外部效度层输出“直接运输、条件校准、拒绝外推”三类边界判定。任何阶段未通过前置闸门，后续仅执行仍能回答科学问题的最小分支。

## 六、风险、早期信号与替代路线

1. **“同分”前提不成立。** 早期信号是两类评分器中结构破损与目标语体的分布均无法达到预设重叠。此时中心“低质量表征效用异质性”命题判为不成立；结构与支持干预至多成为独立子研究，不再支持本项目题目所述中心结论。
2. **sham 对照失真。** 若 sham 意外改善可读性或 tokenization，先缩小到最易配平的段落错序/连接破坏；仍无法构造时只报告结构干预总效应，不作路径特异归因。
3. **支持恢复被曝光量解释。** 若 A4 与 A5 无差异而均优于 A3，结论改为目标语体曝光效应，不宣称非冗余支持；若三者均无差异，则停止支持路径。
4. **能力测试泄漏。** 若近邻/模板重叠敏感性分析显著削弱效应，重新隔离评价集；无法隔离时不报告语体救援机制。
5. **动力学读出失败。** 若能力总效应存在但能力定向梯度对齐不共同逆转，保留随机化总效应，删除动力学候选中介；不以次级指标替换。
6. **来源 B 复核失败。** 来源/操纵不合格时判不可复核，区间过宽时判证据不足；只有条件通过后仍反号或持续落在冻结区间之外、且一次预注册校准无改善时，才判拒绝外推，不追加来源追逐稳定性。
7. **计算或存储不足。** 现有稳定资源按事实库仅包括 A40×8 与 3090 Ti×6；A40 用于同构训练，3090 Ti 用于评分、检索、评测和 smoke test。以首年不超过 10M token 的基准运行实测吞吐、显存、I/O 与 checkpoint 占用，再校准上限矩阵；不假设 A100 可用。

## 七、年度计划与阶段成果口径

### 第一年度：操作定义与操纵验证

完成来源许可和版本审计，冻结确认性中文语体对、复核语体现象、两类质量表征、人工审查规范、六臂生成器、训练/评价隔离规则及统计分析计划。完成非推断性先导和数据平衡表。阶段成果以可复核协议、数据卡、人工一致性与工程稳定性为准，不以单次模型性能作为科学结论。

### 第二年度：来源 A 的双路径确认

完成六个处理臂的成对随机继续预训练和两个主能力终点评价，检验结构恢复特异性、支持恢复特异性及能力定向梯度对齐的候选中介证据。阶段成果为两条路径的运行级效应区间、支持/否定决定和可复现分析代码；未通过闸门的分支停止扩展。

### 第三年度：独立来源外部复核

在不改变主终点和分析方向的条件下，用来源 B 复核存活路径；评估冻结预测、一次固定预算校准和拒绝外推条件。阶段成果为来源间效应比较和适用边界，不承诺普遍迁移或统一阈值。

### 第四年度：边界探索与综合凝练

仅对前三年存活路径开展处理前知识状态与同家族尺度探索，综合形成“路径—状态—来源”边界图。完成研究结果整理、论文和可公开派生资产发布。论文数量、具体会议/期刊与开放范围均按实际结果和语料许可确定，不把平台、标准或全部原始语料公开列为必达成果。

## 八、预期证据与结论边界

项目可能得到支持、部分支持或反证三类结果。若两条路径均获支持，形成中文质量表征效用异质性的反事实机制证据；若仅一条路径成立，则收缩为单路径规律；若两条均失败，仍可明确现有静态质量表征差异是否主要由曝光、分词/packing、优化器或评价对齐解释。无论结果方向如何，结论都不超出公开可许可中文语料、小中规模开源基座继续预训练和预设能力终点，不推断商业模型、7B 以上系统或从零预训练的普适规律。
