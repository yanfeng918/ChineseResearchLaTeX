# 模拟专家评审：全稿

> **终态说明：** 本报告先记录修复前初评，后记录定点修复后的第二轮复评。最终裁决以文末“修复版复评与终态裁决”为准：函评中等把握给过，会评高把握不给过；唯一跨组 P0 是缺少本项目真实直接先导。

## 评审设置与总判定

本轮按国家自然科学基金面上项目、约 50--60 万元资助约束组织 3 个相互独立的专家组；每组包含 7 个评审角色，共形成 21 份独立判断。只评审 `main.tex` 实际纳入的正文、说明和参考文献，不把注释掉的 3.5、4.5 当作申报内容。跨组共识阈值为至少 2/3 组。

| 环节 | 角色票 | 专家组结论 | 聚合结论 |
|---|---:|---:|---|
| 函评 | 给过 9/21，不给过 12/21 | 1 组给过，2 组不给过 | **不给过（把握中）** |
| 会评 | 给过 3/21，不给过 18/21 | 3 组均不给过 | **不给过（把握高）** |

总体评价：项目以“相近低质量表征、不同作用路径”为切入点，六臂负对照、运行级推断和失败停止规则具有辨识度；当前竞争力受四个问题压制：中心主张超出实际估计量、sham 反证规则可被事后解释、六个配对种子的统计规则并非唯一可执行方案，以及没有本项目专属先导证据。

## 跨组共识 P0

### P0-1：中心主张与实际估计量没有完全闭合

结构路径估计“完整相对人工破损/sham”的损伤或恢复效应，支持路径估计“移除后不同补回策略”的效应。两者不是同一种过滤操作下的共同估计量，因此现有设计能够支持“两类低质量表征具有不同作用路径和反事实响应”，不能直接支持“筛选效应方向相反”。

最小修复：不增加训练臂，统一把中心命题收窄为“低质量表征效用异质性的双路径解释”；结构路径只报告损伤/恢复效应，筛选策略意义放在讨论层。用“主张—处理—对照—估计量—允许结论”表逐项核验。

### P0-2：sham 的预期排序和失败解释没有锁死

稿件同时出现“恢复不优于 sham 即否定结构路径”和“sham 与完整等效时优先解释为工程失配”两套口径，阴性结果存在被事后挽救的空间。

最小修复：能力结果揭盲前完成操纵验收；结构路径预期为完整优于破损和 sham，破损与 sham 落入预设等效区间。若 sham 与完整等效，首先判为操纵失败或结构效应不可识别，不得以轻微优化器重调继续声称路径成立。

### P0-3：六种子下的统计决策树不可按现有表述执行

6 个配对块的双侧精确符号翻转检验最小可达 $p=2/2^6=0.03125$；若两条主路径先做 Holm，首个阈值 0.025，理论上无法拒绝。稿件把精确随机化、区间、等效性、顺序检验和“必要时 Holm”并列，仍给结果后选法留下空间。

最小修复：保留六种子时，每条路径采用预注册的联合成功判定，两个必要方向对比均达实践阈值才通过；两条路径采用固定顺序传递 $\alpha=0.05$。等效性只按预设区间裁决，功效不足时必须报告“证据不足”，不能把不显著当成等效。冻结脚本须用空效应、全同向和单路径失败三组模拟数据演练。

### P0-4：缺少本项目专属先导证据，且确认性对象尚未冻结

现有代表作能证明变量分解、模型训练和评价组织能力，但申请书已经如实说明尚无中文语料质量、继续预训练或能力定向梯度分析的专属数据、代码与日志。来源 A/B、确认性语体、主要能力任务和目标 token 剂量仍待首年确定。对于面上项目，这会让科学对象是否存在、操纵是否可行和资源是否兑现均停留在计划层。

最小补充：正式提交前至少提供许可与独立 token 审计、约 50--100 篇双人试标、六臂平衡样例、不超过 10M token 的吞吐/显存/I/O 日志和一张梯度读出复现图。每项保留数据版本、代码提交、随机种子和原始日志；不得把这些先导材料写成主效应已获支持。

## 跨组共识 P1

1. **直接研究基础偏弱。** 代表作与本项目研究对象不同；应把可迁移能力和直接证据分开写，避免以通用机器学习成果替代语料机制先导。
2. **干预剂量和功效依据未冻结。** 每臂一次的工程先导不能估计种子间方差；最小实践意义阈值应来自 benchmark 重测误差、外部方差先验和科学意义，不应来自单次先导。
3. **梯度读出仍有选择自由度。** 需固定主公式、参数层/投影、checkpoint、probe 和归一化；其地位只能是候选动力学证据，不能声称严格因果中介。
4. **来源 B 的解释范围偏宽。** 四臂设计只能复核冻结主对比，不能再次验证 sham 或窄支持特异性；来源不合格、操纵失败、估计不精确和真实反号必须分开判定。
5. **资源总账需要闭合。** 27.4B token 上限应拆成首年 0.6B、来源 A 14.4B、来源 B 9.6B、可选状态/尺度 2.8B，并用 10M token 实测换算 GPU 时、存储和失败重跑余量。
6. **语体构念缺少专业复核。** 经费约束下不必虚构合作者，但应设置第三方盲态抽查或争议样本专家复核，分维度报告一致性及主要分歧。
7. **表达负荷偏高。** 建议用一张六臂表和四句统计决策规则替代多处协议式复述，统一“结构完整/结构破损/sham/主流补回/同语体非冗余补回/同语体窄支持补回”六个臂名。

## 独立意见与事实校核

- 单一来源 B 和同 tokenizer 家族的少量尺度探索，是 50--60 万元面上项目下合理的聚焦；不得据此宣称一般迁移规律。
- A40×8 和 3090 Ti×6 在算术训练量上可支撑约 1B 模型的计划，真正风险在多运行调度、I/O、checkpoint/probe 存储、评测和重跑，需由首年实测确认。
- 有评审角色质疑参与项目 62466056 未写入“承担项目情况”。根据申请人已确认的事实口径，只有 P-H01、P-H04 与本申请相关；62466056 只用于申请单位一致性说明。因此该质疑不成立，不列为修改项。
- 四项“其他说明”仍为合法待补事实，不计入科学评审票，但提交前必须由申请人确认并删除占位标记。

## 最小翻盘序列

1. 收窄中心主张，使每项结论都能由一个明确反事实对比推出。
2. 锁死 sham 的盲态操纵验收、预期排序和唯一失败解释。
3. 冻结六种子下唯一统计决策树，取消“必要时选择方法”。
4. 固定来源、语体、能力终点、干预剂量和梯度读出；补六臂及年度资源总表。
5. 用真实先导五件套证明对象存在、操纵可行和计算可兑现。
6. 把来源 B 限定为冻结主对比的病例式运输复核。

完成前 3 项可提高函评稳定性；完成全部 6 项后，才有较现实的会评翻盘可能。凡涉及真实先导、资源实测和申请人声明的内容，本轮不生成、不猜测，转入待补清单。

## 修复版复评与终态裁决

三组在定点修复后再次独立评审，仍各模拟 7 个专家角色。复评票数如下：

| 专家组 | 函评 | 会评 | 组结论 |
|---|---:|---:|---|
| G001 | 给过 6/7 | 给过 4/7 | 函评高把握给过；会评低把握给过 |
| G002 | 给过 3/7 | 给过 1/7 | 函评中等把握不给过；会评高把握不给过 |
| G003 | 给过 5/7 | 给过 2/7 | 函评中等把握给过；会评中高把握不给过 |
| **合计** | **给过 14/21** | **给过 7/21** | **函评给过（中）；会评不给过（高）** |

### 三组确认的实质改善

1. 中心问题不再比较两套估计量的“方向”，而是解释不同作用路径与反事实响应；该修复被三组认定为实质变化。
2. sham 已加入能力揭盲前操纵验收、预期排序和失败停止，不再允许优化器重调事后挽救。
3. 六臂首次可由一张表独立审计；低熟悉候选定位与确认性基座/评价数据已隔离。
4. 梯度读出由可能被误写为中介，收缩为固定余弦、可失败的候选动力学证据。
5. 来源 B 不再冒充完整机制复现，并区分准入、操纵、证据不足和真实异质。
6. 27.4B token 已按 0.6B、14.4B、9.6B 和可选 2.8B 闭合。

### 复评后完成的最后一轮安全修复

三组指出的文本级残余已继续处理：

- A0、A1、A2 统一从共同破损前体出发；A0 精确逆操作恢复，A1 保留破损，A2 作等量无效操作，编辑历史不再含混。
- 支持路径明确 A0--A3 为支持损失总效应，A4--A3 为恢复效应，A4--A5 为非冗余特异性；A4 未与 A0 等效时只称部分恢复。
- 两条路径各分配单侧 $\alpha=0.025$，分别独立反证；每个必要优效对比须由单侧 $97.5\%$ 随机化反演置信下界越过实践阈值，等效性须由双侧 $95\%$ 区间完全进入等效界值。六种子功效不足时，先转用可选 2.8B token 增加来源 A 配对种子，仍不足则降为区间估计性研究。
- 工程先导不得读取臂间效应方向，也不得据此修改主方向、终点、对比和阈值。
- 技术路线中“反号或校准失败就是边界”的简化表述已删除，统一为不可复核、证据不足、可运输和拒绝外推的分层判定。

这些修改消除了第二轮指出的最后一项统计可执行性 P0；但不能改变以下证据状态。

### 最终跨组 P0

**缺少本项目专属直接先导证据。** 当前没有同分样本、真实六臂样例、标注一致性、10M token 训练日志或梯度读出负对照。三组对其严重度判断不同，但按跨组共识升级规则，最终保留为 P0。它不是“方案写得不够细”，而是面上项目尚未证明研究对象存在、操纵可行和计算可兑现。

最小翻盘材料仍是五件套：许可与独立 token 审计、50--100 篇双人试标、六臂平衡样例、≤10M token 吞吐/显存/I/O/存储日志、一个固定梯度 probe 及无关诊断集负对照。无需展示有利主效应，但每项必须有数据版本、样本量、随机种子、代码提交或原始日志。

### 最终 P1

- 来源 A/B、确认性语体、具体能力任务、目标 token 剂量仍待真实先导冻结。
- 无已落实的语言学/语料库合作者；需第三方盲态抽查或争议样本专业复核。
- 资源账是预算上限，不是 GPU 时、队列、I/O、存储和重跑余量的实测兑现表。
- F-LLM-01 至 F-LLM-04、P-H01/P-H04 提交日状态、AI 人工核验和 2027 官方披露字段仍待申请人处理。

### 最终判定

修复版已从“设计有硬伤”进入“设计可审计但证据基础不足”。按 21 个角色投票，函评达到中等把握给过；会评仍为高把握不给过。继续润色的边际收益已经很低，最可能改变会评结果的动作只有真实先导五件套和据此冻结研究对象、剂量及资源表。
