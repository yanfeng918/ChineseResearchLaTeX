# 公开数据预实验

## 用途与边界

本预实验用于确认公开数据/模型可获取、结构扰动管道可运行、逆操作可核查，并初步观察静态评分对扰动的响应。本轮没有进行继续预训练，没有测量能力终点或能力定向梯度，也不得解释为因果机制已验证。

## 数据与模型

- 数据：[CASIA-LM/ChineseWebText2.0](https://huggingface.co/datasets/CASIA-LM/ChineseWebText2.0) 公开 `test.jsonl`，数据卡声明 Apache-2.0；语料论文见 [arXiv:2411.19668](https://arxiv.org/abs/2411.19668)。
- 原始文件：1,000 条，2,720,476 bytes，SHA256 `cb094e6902a20213e6ef5b6e27740fd385bb1458b8eea4eceb373ce40e1b0a93`。
- 模型：[Qwen/Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B)，模型卡声明 Apache-2.0；revision `060db6499f32faf8b98477b0a26969ef7d8b9987`，权重 SHA256 `88c142557820ccad55bb59756bfcfcf891de9cc6202816bd346445188a0ed342`。
- 固定随机种子：`20270906`。

Qwen 复核筛选了 400--600 字、发布方 `quality_score >= 0.35`、`toxicity.label = 0` 的样本，得到 122 条。30 条用于标定扰动强度，50 条用于参数冻结后的评估。最大长度设为 1,024 token，五个条件的截断触发率均为 0。

## 操纵与评分

每条文本生成五个条件：

1. 简体归一化原文；
2. 顺序和语义不变的繁体字形变体；
3. 固定宽度字符块随机置换的结构扰动；
4. 依保存索引精确逆变换的恢复文本；
5. 从同一破损前体出发、但不执行逆变换的独立 sham 置换。

标定集在 4、8、16、32、64、128 字六个候选块宽中，按“扰动与完整字形变体的中位 loss 距离最小”选定 128 字，之后不再用评估集调参。

## Qwen 复核结果

| 条件 | loss 中位数 | 均值 | 四分位区间 |
|---|---:|---:|---:|
| 原文 | 3.101 | 3.154 | 2.798--3.575 |
| 完整字形变体 | 3.049 | 3.121 | 2.774--3.476 |
| 结构扰动 | 3.379 | 3.403 | 2.990--3.779 |
| 精确恢复 | 3.101 | 3.154 | 2.798--3.575 |
| sham | 3.368 | 3.394 | 3.012--3.800 |

- 结构扰动 $-$ 原文的成对中位差为 0.211（95% bootstrap CI: 0.180--0.276）。
- sham $-$ 原文为 0.219（95% bootstrap CI: 0.191--0.280）。
- 字形变体 $-$ 原文为 -0.048（95% bootstrap CI: -0.095--0.002）。
- 精确恢复率、sham 非恢复率和五条件字符长度一致率均为 100%。
- 扰动与字形变体的直方图重叠率为 0.66，但成对中位差为 0.303（95% bootstrap CI: 0.220--0.360），不支持两者已达统计等价。

另以字符三元语言模型对 100 条样本复核，原文/精确恢复的中位 log-perplexity 均为 7.327，结构扰动为 7.736，sham 为 7.732，方向与 Qwen 一致。

## 解读与后续

数据下载、版本固定、结构扰动、精确恢复、sham 对照和静态模型评分已经打通。但当前的繁简字形变体会改变 token 数，固定字符块也只是工程先导操纵。正式实验应改用段落错序与连接破坏，加入双人语体/语义保持审计，严格匹配 token 与 packing，再进入 10M token 继续预训练 smoke test。
