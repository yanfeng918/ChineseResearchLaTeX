## 本次确定的申报设计

| 内容 | 现行方案 |
|---|---|
| 场站与记录 | 1个新疆主研究场站，目标连续24个月记录，连续12个月为启动场站方法验证的最低覆盖要求；第2场站为取得授权后的扩展验证 |
| 时间与预测 | 统一北京时间，每15分钟采样和发布，输出未来15–240分钟、步长15分钟的预测，重点报告1、2、3、4小时 |
| 时间划分 | 训练、验证、初始校准、测试按50%/15%/15%/20%连续划分，边界隔离4小时；24个月记录的最终测试约4.8个月，季节结论限于实际测试月份 |
| 预测模型 | DWT-Former分位数模型为主，WaveKAN作结构替换对照；主要模型和消融使用3个随机种子 |
| 分位数与校准 | 0.05–0.95、间隔0.05，共19个分位数；报告80%和90%区间；30天滚动校准，每15分钟更新，14天和60天作敏感性分析 |
| 爬坡事件 | 30分钟功率净变化幅度超过装机容量20%；主终点为发布时间后第60至90分钟的下降爬坡，10%和30%阈值作敏感性分析 |
| 辐照状态 | 过去60分钟四个完整15分钟GHI均值除以同窗口Haurwitz晴空参照；以指数中位数及最大相邻变化，按训练期冻结分位阈值划分快速变化、高指数平稳、其他及未知；沙尘另依可核验记录分层，不交叉扩充模板类别 |
| 轨迹与证据门槛 | 每次生成100条轨迹，50条和200条作敏感性分析；按自然日计评价块，有记录支持的同一跨日过程才合并。重点分层至少30个含该状态/事件的有效日或过程块；事件结论要求30个含相应事件的块。该门槛不保证独立性或统计功效，仍结合配对分块自助区间判断 |
| 告警约束 | 验证段在每有效日平均误报事件≤1次且发布时间网格误报时间比例≤5%下选取召回率最高的阈值，并列取较高阈值；无可行阈值或无实测事件则不发该类告警。测试锁定阈值并报告实际误报，不声称测试期等误报 |
| 进度与成果 | 2027年完成数据核验、尺度分析及概率预测基线，2028年完成校准、爬坡评价和离线原型；完成并投稿论文1篇，交付算法软件1项，7名研究生参与、重点培养2名 |

以上方案以 [研究计划](../extraTex/05-plan.tex#L1) 和 [考核指标](../extraTex/assessment.tex#L1) 为现行申请口径，正式考核以批准合同为准。场站及气象数据的真实来源、授权和覆盖期仍按以下事实缺口核验。

2026年9月21日按用户修正授权补全天气、评价块和告警定义。10度太阳高度、训练期分位阈值、30块报告门槛及5%误报时间上限均属于研究设计，不是已验证最优值或业务标准。Haurwitz参照的GHI输出及天顶角输入依据 [pvlib官方文档](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.clearsky.haurwitz.html)，仅作为归一化参照，不认定实际天气为晴空。修正不新增场站授权、先导结果、合作或资格确认事实。
