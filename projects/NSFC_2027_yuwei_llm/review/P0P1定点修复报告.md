# P0/P1 定点修复报告

## 修复结论

本轮针对质量控制和 3 组、21 个专家角色模拟评审的交集意见完成定点修复。可依赖现有材料安全修改的问题已进入正文和参考文献；需要真实实验、申请人身份判断或 2027 年官方规则的信息没有生成，以待补项保留。

修复后的核心命题为：**结构破损文本与结构完整但模型低熟悉的中文语体可能获得相近低质量表征，但分别通过结构缺陷损伤/恢复和非冗余语义支持损失/补回形成不同作用路径与反事实响应。** 两条路径不再被写成同一种过滤操作下可直接比较方向的估计量。

## 已消除的 P0

1. **主张—估计量错位。** 立项依据、研究内容、创新点及选题/研究方案文档已同步收窄主张，并在六臂表后明确允许结论。
2. **sham 规则不唯一。** 已固定能力揭盲前操纵验收、预期排序及失败后的唯一降级口径；删除“优化器轻调即可挽救结构路径”的表述。
3. **六种子统计规则不可执行。** 删除 Holm 和路径间门控，两路径各分配单侧 $\alpha=0.025$；必要优效对比以单侧 $97.5\%$ 随机化反演置信下界越过实践阈值判定，等效区间须整体入界，区间跨界时只报证据不足。
4. **参考文献硬错误。** 删除错置摘要，补全已核验出版信息，修复重音字符；最新 `main.bbl` UTF-8 解码通过，PDF 未发现替换字符。

## 已降低的 P1

- 用独立定位模型和隔离分片降低“低熟悉”循环定义风险。
- 把梯度主读出固定为末层低秩投影的单位 token 归一化余弦，其他读出降为敏感性分析。
- 把来源 B 限定为四个冻结主对比的有限运输复核，并区分准入、操纵、精度和真实异质。
- 明确每臂一次先导只验证工程与操纵，不估计运行方差或证明等效。
- 正文新增六臂矩阵；27.4B token 按 0.6B、14.4B、9.6B、2.8B 分项闭合。
- 修正文献强度、引用元数据、题目漂移和设备名 overfull box。
