## 申报书概览

- **研究主题**：中文预训练语料低质量表征效用异质性的双路径机制。
- **中心科学问题**：结构破损文本与结构完整但模型低熟悉的中文语体，为何获得相近低质量表征，却形成不同训练效用和反事实响应。
- **三项研究内容**：①构建“同分异源”可识别样本层；②识别结构缺陷削减的效应、动力学与来源边界；③识别非冗余语义支持损失及状态—来源—尺度边界。
- **核心识别策略**：结构恢复/sham 与非冗余/窄支持/主流补回两组正交反事实。
- **主要动力学读出**：能力定向梯度对齐；只作为候选机制证据，不宣称完整因果中介。
- **推断单位**：训练运行；token、checkpoint、probe 文档和 benchmark 条目不作为额外重复。
- **总体框架模块数**：`module_count_framework: 9`。

## 分图设计

### F1 同一低分下的两类中文语料及过滤悖论

- **目标**：解释结构破损文本和结构完整但低熟悉的中文语体可落入相近低分区，而统一过滤会产生方向不同的后果。
- **必须出现**：结构破损文本卡；完整低熟悉语体卡；困惑度型和规范性/来源型双评分；低分重叠带；统一阈值；结构噪声减少与语义支持收缩两种后果。
- **视觉锚点**：破碎段落、完整低频文本、双评分散点概念图、漏斗、语义覆盖网络。
- **布局**：左侧两类输入 → 中央评分重叠 → 右侧统一过滤 → 上下两种后果。
- **推荐位置**：立项依据 1.1 第 2--4 段后。
- **图注保留**：分数与散点均为概念示意；低熟悉不等于结构破损；静态分数只用于定位。

### F2 低质量表征效用异质性的双路径假设

- **目标**：把“同一表面低分、两个潜在来源、两套正交反事实、两个能力终点”压缩成机制假设图。
- **必须出现**：顶部相近低质量表征；左侧结构缺陷 → 低目标对齐更新 → 通用能力/知识保持；右侧完整低熟悉语体 → 非冗余支持 → 语体/长尾能力；两侧恢复与负对照；知识状态仅调节支持路径。
- **视觉锚点**：分叉节点、文本缩略图、梯度向量夹角、覆盖网络、共同 checkpoint。
- **布局**：对称双泳道；中轴注明“两估计量不直接比较”。
- **推荐位置**：立项依据 1.4 中心科学问题后。
- **图注保留**：两条路径可独立被否定，失败不以状态依赖或重新校准挽救。

### F3 三项研究内容与双路径证据闭环

- **目标**：以“内容一供给实验对象、内容二和三并行识别、来源 B 冻结复核”体现三项研究内容之间的闭环。
- **必须出现**：双来源语料；来源审计与盲标；同分样本层；六臂生成器；路线二与路线三双泳道；来源 A 共同 checkpoint 和成对种子；能力与动力学联合判定；冻结协议；来源 B 复核；边界结论。
- **视觉锚点**：双数据库、数据卡、重叠分布、六臂扇出、模型层堆叠、梯度向量、置信区间、冻结清单、边界地图。
- **布局**：上层“内容一”，中层“内容二/三”并行，下层证据汇合与外部边界；主流程实线，停止/取消虚线。
- **推荐位置**：1.4“总体技术路线”之后，并替换现有流程文字。
- **图注保留**：来源 B 不是调参环境；外部复核已分别嵌入研究内容二、三，不再构成第四项研究内容。

### F4 路线一：同分异源样本层构建

- **目标**：说明候选公开语料如何转化为可审计、可匹配且可生成六臂的实验输入。
- **必须出现**：来源 A/B 候选；许可/版本/隐私审计；规范化、去重、编码检查；来源—语体—主题/实体—重复簇索引；双评分；双人盲标四维度；匹配集公式 `M_epsilon`；重叠与平衡闸门；互不重叠的结构/支持目标集；A0--A5 生成器。
- **视觉锚点**：数据卡、四层索引树、双评分小散点、双标注者、公式卡、验收门、两只分离数据托盘。
- **布局**：左到右流水线；评分与人工标注上下并行后汇入匹配/验收闸门。
- **推荐位置**：研究内容一对应路线之后；可与 F8 二选一。
- **图注保留**：`epsilon` 在不读取能力结果时冻结；若两类评分不能形成共同重叠，中心命题不成立。

### F5 路线二：结构缺陷削减、动力学与来源边界

- **目标**：展示 A0/A1/A2 来自同一破损前体，并将结构效应、处理特异性、动力学证据和来源边界连成一条路线。
- **必须出现**：结构完整原文 → 共同破损前体；A0 精确恢复、A1 保留破损、A2 等量 sham；tokenization/packing/预算平衡；来源 A 共同 checkpoint 与六个成对种子；`tau_str`、`tau_spec`；能力定向梯度对齐；通用能力终点；联合闸门；冻结 A0--A1 后进入来源 B；直接运输/校准/证据不足/拒绝外推。
- **视觉锚点**：段落卡、可逆箭头、sham 符号、平衡秤、checkpoint、配对种子、向量角、区间条、来源切换。
- **布局**：上部反事实构造，下部成对训练 → 双证据 → 来源 B；失败分支向下终止。
- **推荐位置**：研究内容二对应路线之后。
- **图注保留**：训练运行是推断单位；结构路径失败则停止其外部复核。

### F6 路线三：非冗余语义支持及状态—来源—尺度边界

- **目标**：区分非冗余支持、单纯语体曝光和等量主流补数，并展示状态、来源与尺度的条件边界。
- **必须出现**：固定待移除集合；A0 完整参考、A3 主流补回、A4 同语体非冗余补回、A5 同语体窄支持补回；等 token/长度/质量分/曝光约束；`tau_loss`、`tau_restore`、`tau_breadth` 与 A4≈A0；目标语体梯度对齐与语体/长尾终点；结论分级；两个共同 checkpoint 的状态分叉；冻结 A4--A3 后进入来源 B；至少一路保持方向才进入同 tokenizer 家族尺度复核。
- **视觉锚点**：四臂卡、覆盖网络、重复簇、平衡条、向量角、等效区间、双 checkpoint、双来源、大小模型。
- **布局**：四臂 → 共同训练 → 证据矩阵 → 结论分级；底部串联状态、来源与尺度三个条件闸门。
- **推荐位置**：研究内容三对应路线之后。
- **图注保留**：A4 与 A5 的差异排除“只要同语体曝光即可”；尺度探索为条件触发项。

### F7 双路径共享的冻结外部复核

- **目标**：把研究内容二、三共同采用的来源复核规则画成共享子流程，避免误解为独立的第四项研究内容或“换数据再调一次”。
- **必须出现**：来源 A 存活路径；冻结包（处理规则、终点、方向、区间、代码）；来源 B 的 A0--A1 与 A4--A3 关键对比；来源准入、操纵验收、区间精度、方向/冻结区间四级检查；一次固定预算校准；不可复核、证据不足、直接运输、条件校准、拒绝外推；至少一路保持方向才触发尺度探索。
- **视觉锚点**：双路径汇入口、封存清单、第二来源数据库、四级门、置信区间、边界地图、条件尺度分支。
- **布局**：左到右单向决策流；结构/支持两路只在冻结入口并列，失败结果向下终止，禁止回流到指标选择。
- **推荐位置**：研究内容二、三之后作为共享增强图，或置于答辩技术路线页。
- **图注保留**：外部复核是两项研究内容内部的共同边界检验，不单列为研究内容；只有准入和操纵合格后持续反号/区间外且一次固定校准无改善，才拒绝外推。

### F8 六臂反事实实验与预注册主对比

- **目标**：替换六臂文字表格，明确共同参考 A0 与两套不可直接比较的估计量。
- **必须出现**：A0--A5；上排结构三臂与下排支持四状态；互不重叠目标文档集合；共同背景池、等 token、等预算；结构对比 A0−A1、A0−A2；支持对比 A0−A3、A4−A3、A4−A5、A4≈A0。

- **布局**：上排结构、下排支持；A0 在两组中作为“参考定义”重复显示，但用非重叠托盘说明不是同一目标集合。
- **推荐位置**：直接替换研究内容一的六臂表格。
- **图注保留**：共同参考不等于两条路径的估计量可以直接比较。
