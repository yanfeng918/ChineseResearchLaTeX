# 证据验收清单

> 只有全部必需项通过，且具体结果在登记表中为 accepted，才允许形成相应层级的标书表述。

## G0 文档化与完整性

- [ ] README、数据说明卡、运行清单、配置和字段定义齐全。
- [ ] 所有必需产物在 evidence_manifest 中登记。
- [ ] 文件路径可解析，SHA-256 重算一致。
- [ ] 缺失文件有原因、影响和处置，不以空模板代替。

## G1 三时钟

- [ ] 事件、采样、到达时钟来源彼此区分。
- [ ] 原生时间、对齐时间、对时方法和同步残差均保留。
- [ ] sample_seq_no 可区分未采到与已采未送达。
- [ ] 截止期后到达的数据未进入在线决策。
- [ ] 时钟/支持不满足时，结果按区间或拒判处理。

## G2 母流与共同随机数

- [ ] 原始母流不可变且哈希有效。
- [ ] 每个派生重放指向 mother_stream_id。
- [ ] 配对方法共享网络配置、种子、资源初值和截止期。
- [ ] 任何行为策略外推都具有支持诊断；无支持时不外推。
- [ ] 锁定评估标签只开启一次并留有签名记录。

## G3 公平比较与统计

- [ ] 基线与候选方法使用相同模态、时间元数据、动作空间、预算和划分。
- [ ] 同一 entity_id 的窗口、帧和重放副本未跨集合。
- [ ] 分析与区间按独立实体聚合。
- [ ] 主终点、次终点、阈值和截止期在查看锁定结果前冻结。
- [ ] 负对照、消融、失败案例和支持不足均报告。

## G4 协议与资源

- [ ] 保护性原始证据无静默丢弃。
- [ ] 分片哈希一致、续传状态幂等。
- [ ] 缓存溢出、重传和超期全部登记。
- [ ] 配置速率/延迟/丢包与实际测量值分开。
- [ ] 能耗明确标注 measured、estimated 或 not_available。

## G5 主张边界

- [ ] W0–W4 只称参数化压力回放。
- [ ] 没有设备和原始日志时不称电子封志或代表性板卡实测。
- [ ] 没有物理功耗测量时不称实际能耗或续航提升。
- [ ] 没有现场授权与记录时不称口岸、跨境运输或仓储现场验证。
- [ ] 没有统一货物标识、实体配对和功效时不声称 H3b 已验证。
- [ ] 每个回写数字可由 result_id 追溯到 evidence_id、文件和哈希。
