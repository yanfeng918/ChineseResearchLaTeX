# Research-Idea：中文预训练语料低质量表征效用异质性的双路径机制

## 调研摘要

- 输入资料：项目选题边界、申请人事实库、预训练语料质量系统综述及经 DOI/官方出版页复核的 50 条参考文献。
- 核心方向：从“更高质量分是否带来更高效用”转向“相近低质量表征为何形成不同作用路径与反事实响应”，以两套干预区分结构缺陷削减与非冗余语义支持损失。
- 最终建议：以候选 1 为唯一中心假设；候选 2 作为机制证据层，候选 3 作为有限外部效度层，不另立平行主线。

## 多个科学问题-科学假设对

### 候选 1：低质量表征同分异效的双路径机制

**科学问题**：中文语料中，结构破损文本与结构完整但模型低熟悉的中文语体为何会获得相近的低质量表征，却形成不同作用路径与反事实响应；缺陷削减与非冗余语义支持损失能否由彼此独立的反事实干预分离？

**可证伪科学假设**：中文语料的静态低质量表征混合了两类机制不同的成分。结构破损产生与有效学习目标低对齐的更新；结构完整但模型低熟悉的中文语体则提供面向相应能力的非冗余更新。因此，保持语义支持的结构修复应改善通用能力，而保持语体曝光量的非冗余支持恢复应选择性改善语体与长尾能力。若任一路径的特异恢复不能区别于相应负对照，则完整双路径假设被推翻。

**关键预测**：

- 在来源、语义单元、token、分词/packing 和编辑量匹配时，原文恢复相对结构破损与 sham 编辑将提高面向独立通用诊断集的能力定向梯度对齐，且独立后测能力同向恢复。
- 在目标语体 token 曝光量、长度、质量分数和来源可信度匹配时，同语体非冗余补回相对主流文本补回以及同语体等量重复/窄支持补回，将选择性提高语体与长尾能力。
- 前一路径的方向效应相对稳定；后一路径随处理前模型对目标语体的掌握程度变化，但该状态依赖必须由共同 checkpoint 后的随机分叉检验。

**反证路径**：

- 结构修复与 sham 编辑效果等同，说明结果可能来自编辑流程、tokenization 或 packing 变化，而非结构缺陷路径。
- 同语体非冗余补回不优于同语体重复补回或主流文本补回，说明结果可由语体曝光、数据混合或评测对齐解释，而非非冗余支持路径。
- 在文档、站点/作者、时间、主题和高阶模板隔离后效应消失，说明先前结果可能来自记忆或评测污染。

**查新结论**：部分研究但关键缺口存在。质量过滤与多样性/覆盖权衡已有充分讨论，不能作为本项目的独立创新；关键缺口在于用“只修复不删除—同语体支持恢复—伪恢复”定义路径特异反事实，并检验中文表面规范性与训练效用的非等价关系。候选保留并作为中心方案。

**初步评价**：

- 新颖性：高；贡献落在可干预的双路径分解，而不是新建质量分数或寻找最优阈值。
- 重要性：高；它直接关系到低资源语体是否会被通用质量过滤系统性误删。
- 可行性：中高；可在小中规模开源模型继续预训练中通过六个共享处理臂、成对随机种子和独立外部来源复核。

### 候选 2：结构缺陷的能力定向动力学机制

**科学问题**：在语义单元、来源、分词/packing 与训练预算匹配的可逆干预中，结构破损及其原文恢复如何改变训练更新的目标方向；该读出是否构成通向独立通用能力变化的可重复候选中介？

**可证伪科学假设**：结构破损会降低训练 batch 梯度与独立能力诊断集梯度之间的单位 token 归一化对齐；原文恢复而非 sham 编辑将使这种“能力定向梯度对齐”与独立后测能力共同逆转。若干预不改变该读出、读出对后续能力无留出预测增益，或二者在恢复实验中解耦，则动力学机制假设被削弱或推翻。

**关键预测**：

- 结构破损剂量变化先于能力变化，并在多个成对训练运行中形成方向一致的能力定向梯度对齐差异。
- 加入该读出后，对留一种子和留一来源的后续能力变化预测优于只含处理臂、静态质量和训练步的模型。
- 轻微优化器重调不应完全消除结构修复效应；否则结论应降格为训练配置与数据难度失配。

**反证路径**：

- 能力定向梯度对齐不随结构修复变化，或只在与最终测试重合的诊断集上成立。
- 次级的损失波动、梯度有效秩或遗忘率显著，而唯一预注册主读出失败；不得事后替换主机制。
- 动力学读出恢复而能力不恢复，或能力恢复而读出不恢复，均反对所指定中介链。

**查新结论**：部分研究但关键缺口存在。梯度相似性、影响估计、动态数据价值和训练阶段依赖已有大量工作；可保留的新意是把能力定向读出嵌入随机化结构修复与 sham 对照，作为候选 1 的机制证据。候选不作为独立主线。

**初步评价**：

- 新颖性：中；指标思想与既有梯度估值相邻，创新依赖反事实设计而非指标名称。
- 重要性：中高；可回答结构修复为何有效，而不仅是是否有效。
- 可行性：中；需固定小型 probe 集和少量 checkpoint 的低秩/末层梯度计算，避免全数据全参数影响函数。

### 候选 3：双路径效应的非对称外部效度

**科学问题**：结构缺陷路径与非冗余支持路径的效应方向和强度，能否在独立中文语料来源中复现；处理前知识状态和同家族模型尺度如何限定其外推范围？

**可证伪科学假设**：结构缺陷路径的方向效应较支持路径稳定，而支持路径的效应量受目标语体支持重叠和模型既有知识状态调节。来源 A 冻结的路径模型只能在有充分支持重叠的来源 B 上直接运输；若固定小样本校准仍不能改善预测，则应拒绝外推。若两条路径均频繁反号、状态变量无解释增益且拒绝规则不能富集高误差环境，则该非对称外部效度假设被推翻。

**关键预测**：

- 在冻结处理协议、终点和方向预测后，结构修复效应在第二来源更可能保持方向，支持恢复效应则随目标语体基线能力和支持重叠发生幅度变化。
- 固定预算的分层校准只在观测支持充分时改善来源外预测；超出支持域时，风险—覆盖规则应优先拒绝高误差案例。
- 同家族尺度复核只提供边界线索，不应据少量运行声称跨架构普适。

**反证路径**：

- 结构效应在来源间频繁反号，或其异质性完全由 tokenization、优化器或处理强度差异解释。
- 分层校准不优于源域直接应用、简单目标域均值或标签打乱负对照。
- 拒绝外推规则不能识别高误差环境，说明所谓适用边界不可操作化。

**查新结论**：部分研究但关键缺口存在。代理模型迁移、数据混合校准和不确定性拒绝已有研究；可查新部分是两条机制路径具有不同的外部效度结构。候选保留为第三研究内容和边界验证，不把校准算法本身写成创新。

**初步评价**：

- 新颖性：中；路径非对称迁移是可检验增量，校准与拒绝工具本身并不新。
- 重要性：中高；能约束小模型、单来源实验被过度外推到“大模型训练规律”的风险。
- 可行性：中；一个独立来源可作确认性外部复核，模型状态与同家族尺度只宜作带停止条件的探索。

## 为什么选择这些科学问题-科学假设对

三个候选分别对应中心方案的现象与主效应、训练轨迹证据和外部效度，不是三项彼此竞争的工程任务。候选 1 把已有“质量—多样性权衡”改造成可被特异恢复和伪恢复反驳的双路径命题；候选 2 规定一种具有时间顺序和目标方向的候选中介，避免在 loss、梯度和遗忘指标中事后挑选；候选 3 则把迁移失败视为科学边界，而不是通过不断加数据或换模型追求成功。

中文不是简单的数据标签。项目将预注册一类“结构完整、来源可核验但模型低熟悉”的中文语体作为确认性对象，以第二类书写/语体现象作稳健性复核；它们与真正结构破损在质量评分上可能重叠，却有不同的语义支持作用。删除“中文”后，这一核心对照的操作定义会改变，但项目不宣称该机制为中文独有。

## 最佳科学问题-科学假设对

**最佳选择**：候选 1：低质量表征同分异效的双路径机制。

**原因**：

- 科学重要性：它追问通用质量筛选为何可能同时移除真正结构缺陷与有价值的低频中文表达，关系到数据治理与能力覆盖之间的根本矛盾。
- 新颖性：创新不在“质量与覆盖权衡”，而在两类低分来源的可干预分解、路径特异救援和中文表面规范性—训练效用非等价机制。
- 可证伪性：结构恢复、sham 编辑、同语体非冗余补回、同语体窄支持补回和主流文本补回均提供明确反证；任一路径失败即删除相应机制。
- 可行性：核心确认性研究可在两个公开中文来源、约 1B 开源基座、六个共享处理臂和成对随机种子下完成；无需从零训练通用大模型。
- 解释力：同一框架能解释为什么某些清洗稳定有益、为什么某些筛选损害长尾能力，以及为什么质量效应随来源和模型状态漂移。

**优化后的科学问题**：中文语料中，结构破损文本与结构完整但模型低熟悉的中文语体为何会获得相近的低质量表征，却经由结构缺陷削减和非冗余语义支持损失形成不同作用路径与反事实响应；这种效用异质性如何受模型既有知识状态调节？

**优化后的可证伪科学假设**：中文语料的静态低质量表征混合了结构缺陷与低模型熟悉度两类成分。保持语义支持的结构修复应提高训练更新的能力定向梯度对齐并改善通用能力；保持语体曝光量的非冗余支持恢复应选择性改善语体与长尾能力。前一路径的方向效应相对稳定，后一路径受处理前知识状态调节。若原文恢复不优于 sham 编辑，或同语体非冗余补回不优于等量重复/窄支持及主流文本补回，则相应路径被否定。

**最关键的反证实验/观察**：

1. `结构破损—原文恢复—sham 编辑` 三臂可逆干预，检验结构修复是否产生超出编辑流程的动力学与能力恢复。
2. `主流文本补回—同语体非冗余补回—同语体等量重复/窄支持补回` 三臂，固定语体曝光量后检验非冗余支持的特异作用。
3. 在文档、作者/站点、时间、主题和高阶模板隔离的独立后测集上复核，并以来源 B 的冻结预测决定运输或拒绝外推。

## 三条创新点

1. **质量筛选效应的路径特异分解。** 区分并识别筛选同时诱发的结构缺陷削减效应与非冗余语义支持损失效应，以保持支持的结构修复、保持 token 但不恢复支持的伪恢复及同语体支持恢复构成反事实证据，不以综合质量分或阈值最优为结论。
2. **中文表面规范性与训练效用的非等价机制。** 利用语义匹配的规范书面表达—模型低熟悉中文语体对，检验质量表征是否把模型低熟悉度误作数据低质量，并揭示其与真实结构破损在能力定向学习信号和能力后果上的分化。
3. **双路径效应的非对称外部效度。** 检验结构缺陷路径与语义支持路径在跨语料来源时的不同稳定性，分析支持路径随处理前知识状态和目标支持重叠变化的条件效应，据此限定可运输范围；校准与拒绝规则只是验证手段，不作为独立算法创新。

## 风险与下一步

- 最大不确定性：两类目标样本未必能在两个异质质量表征上达到“相近低分”。若操纵检验失败，应将问题降格为特定评分器的条件失配，不能维持一般同分异效表述。
- 最容易失败的地方：sham 编辑可能意外改善结构；同语体恢复与主流文本补回可能无法同时匹配 token、长度、质量分和难度；能力测试可能与恢复语料发生主题或词汇泄漏。
- 最强替代解释：语体曝光量、tokenization/packing、优化器失配、数据混合重分配、评分器条件失配和评测记忆均可产生表面“双路径”。方案必须逐一设置平衡表、负对照和敏感性分析。
- 证据边界：结论限定于公开可许可中文语料、小中规模开源基座的继续预训练；一个独立来源只能验证有限运输或暴露拒绝边界，不能证明跨架构普适的大模型定律。
- 下一步：冻结一个确认性中文语体对、一个复核语体现象、两类预注册质量表征、六个共享处理臂、两个主能力终点和“能力定向梯度对齐”这一主动力学读出；用不超过 0.1B token/臂的非推断性工程先导完成操纵检验后，再决定是否进入确认性训练。
