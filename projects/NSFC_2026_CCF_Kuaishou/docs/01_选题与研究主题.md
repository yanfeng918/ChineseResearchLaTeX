# 选题与研究主题

项目名称：面向长程多步骤智能体的自适应上下文压缩、动态卸载与按需证据恢复研究（ACORE）。
申报方向：CCF—快手大模型探索者基金课题1.7；采用现有NSFC面上模板组织正文。

主题：在固定上下文和总调用预算下，研究任务状态保真、可校验证据恢复与调度决策如何共同影响多步骤智能体成功率及长程可靠性。对象为文本/工具调用智能体；原始多模态建模、大规模基座预训练、生产系统上线不作为一年期核心任务。

机制链：任务阶段改变未来信息价值→压缩改变可见状态→卸载改变取证成本→恢复决定动作所依赖的证据版本→调度在总成本和失败风险间选择。

核心问题：
1. 任务约束、未完成子目标及证据依赖比文本显著性更能预测压缩引起的后续动作错误吗？
2. 可寻址的原文保留在什么检索与校验条件下才能转化为恢复成功，而非只证明字节仍在？
3. 在计入压缩/检索/校验开销后，状态感知调度在什么任务长度和工具噪声条件下仍产生净收益？

关键词：长程智能体/long-horizon agents；上下文压缩/context compression；上下文卸载/context offloading；任务状态/task state；证据恢复/evidence retrieval；记忆管理/memory management；来源追溯/provenance；预算控制/budgeted control；工具使用/tool use；顺序决策/sequential decision making。

检索扩展：prompt compression, context folding, memory consolidation, working memory, long-term memory, trajectory, information retention, memory-augmented agents, non-inferiority, counterfactual ablation。

资料边界：已有事实支持研究方向及申请人算力；尚无本项目先导实验。所有性能、规模和进度数值仅可作为暂定设计，不能画成已测曲线。
