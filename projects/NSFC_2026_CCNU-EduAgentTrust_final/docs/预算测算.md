# 经费预算测算

本方案用于申请书拟稿，是计划支出，不是获批经费、已发生费用或已订立的采购/聘用安排。总额按[官方一般课题指南](https://aielab.ccnu.edu.cn/info/1101/6491.htm)的5万元编制，研究期1年。科目分配与单价由本轮研究方案测算，正式执行前由申请人与所在单位审核。

| 科目 | 金额（万元） | 测算与研究用途 |
|---|---:|---|
| 业务费：模型调用与补充计算服务 | 0.60 | 12个计费月×500元/月封顶，支持双模型轨迹生成、语义评价及分支重放；优先使用现有设备与本地模型，依据预实验实际单价控制调用量 |
| 业务费：论文出版与成果整理 | 0.60 | 1篇论文相关出版费用预留6000元，按实际需要支出；不假定所有期刊收费，不足时优先选择无强制收费渠道 |
| 业务费：合作交流及案例调研 | 0.60 | 2人次×3000元/人次估算交通和住宿，用于教学规则讨论与案例核查；地点与行程落实后依单位标准核算 |
| 业务费：文献、资料与印制 | 0.20 | 文献资料1000元、标注手册与案例材料印制1000元；优先使用学校已有数据库和电子材料 |
| **业务费小计** | **2.00** | 0.60＋0.60＋0.60＋0.20 |
| 劳务费：研究助理 | 1.60 | 七名研究生成员按任务阶段累计16人月×1000元/人月，承担材料整理、轨迹采集、标注协助、复现和日志核查；16人月是拟计费工作量，按实际投入记录分配，不表示每人均投入16个月 |
| 劳务费：外聘专家咨询 | 0.40 | 4人天×1000元/人天，拟用于教学规则、争议案例与报告复核；对象为符合单位规定的外聘专家，不向课题组成员重复列支专家咨询费 |
| **劳务费小计** | **2.00** | 1.60＋0.40；人员资格、标准及税费口径按单位审核结果执行 |
| 设备费 | 0.00 | 使用已确认可用的A40与RTX 3090 Ti设备，不购置新设备 |
| **直接费用合计** | **4.00** | 业务费2.00＋劳务费2.00＋设备费0.00 |
| 间接费用 | 1.00 | 管理及公共资源支出，按总额20%拟列；不表述为学校已核定比例 |
| **申请经费总额** | **5.00** | 直接费用4.00＋间接费用1.00 |

所供官方申请表规定间接费用不超过总预算40%，本方案为20%。此处仅核对表内比例上限，测算单价不是财务报销标准。既有项目经费不并入本课题，同一项实验、劳务或成果费用不重复列支。

指南规定立项先拨60%、中期评价通过后拨余款。按申请总额测算为3万元和2万元，实际到账以批准及拨款为准。前期依托现有设备完成任务准备、预实验及核心标注，通过中期评价后继续留出实验、案例和成果整理，按已到经费控制支出。

模型调用额度覆盖评价器调用、干预分支、重试和仲裁辅助调用，2880次候选运行不等于全部付费调用数。超额时优先减少双智能体等探索扩展，保留主要对照与独立复核。

申报前由申请人与单位审核科目分配、助理和专家工作量、支付标准及间接费用；如需调整，同步修改 `extraTex/budget.tex` 和研究基础中的预算说明。七名研究生成员已按用户2026-09-19指定资料列入本课题；教学复核、外聘专家和实验室合作授权仍须落实，不能由预算安排推定。
