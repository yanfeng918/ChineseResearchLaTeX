# 选题与研究主题

## 主题

**暂定题目：中文预训练语料低质量表征效用异质性的双路径机制。**

本项目拟研究结构破损文本与结构完整但模型低熟悉的中文语体为何会获得相近低质量表征，并通过结构缺陷损伤/恢复和非冗余语义支持损失/补回两套反事实，检验其不同作用路径、候选动力学证据和有限来源运输边界。项目不把两套估计量解释为同一种过滤效应的方向比较，也不以开发新评分器为目标。

该主题由现有“关键语料质量评价”素材抽取并按 NSFC 科学问题导向重新凝练。原素材所属项目的固定指南题目、两年期限、10 万元额度、行政流程和成果采纳口径不适用于本项目。

## 研究对象与边界

- **语料对象**：经过来源、许可和版本核验的公开中文预训练文本，重点覆盖网页、百科、领域文本等异质来源；不把无法追溯来源或无明确使用边界的数据写成既有资源。
- **模型对象**：适于受控继续预训练的小中规模开源自回归语言模型；具体模型、参数规模和训练 token 预算均待可行性预实验后确定。
- **质量对象**：语言规范性、语义完整性、信息密度、重复冗余、领域与语体覆盖、来源可靠性等可观测特征，以及这些特征的交互关系。
- **效用对象**：训练损失与梯度行为、样本学习动态、语言建模能力、知识与推理表现、语言规范和长尾覆盖等多层结果，不以单一榜单总分替代训练效用。
- **研究边界**：以中文文本和继续预训练为主，不从零训练通用大模型，不把多模态/VQA、标准发布、主管部门采纳或大型平台建设列为本项目任务。

## 关键机制与因果链

项目关注如下可检验链条：

> 语料质量特征及其组合 → token/样本层学习难度与梯度贡献 → 训练过程中的知识吸收、遗忘和分布偏置 → 语言能力、知识能力与长尾覆盖变化。

其中包含两个需要共同识别的机制：

1. **质量增益机制**：低信息、重复、破损或不连贯样本会消耗训练预算并引入噪声；但不同缺陷对学习动态和能力维度的影响可能不同。
2. **质量--覆盖制约机制**：强过滤可能提高平均规范性，却同步删去口语、方言、低频知识和特殊语体，因而出现局部指标改善而总体效用下降的反直觉结果。
3. **迁移边界机制**：同一质量分数在不同来源、领域、训练阶段和模型尺度下未必代表同等效用，需要区分稳定关系与条件依赖关系。

## 核心科学问题

**中心问题：** 中文语料中，结构破损文本与结构完整但模型低熟悉的中文语体为何会获得相近低质量表征，却经由结构缺陷削减和非冗余语义支持损失形成不同作用路径与反事实响应；这种效用异质性如何受模型既有知识状态调节？

围绕中心问题设置三个相互衔接的子问题：

1. 如何把语言规范、语义完整、信息价值、重复与覆盖等异质属性分解为可解释、可计算并能由人工复核的质量表征，避免将“质量”压缩为来源不明的单一分数？
2. 不同质量特征及其交互怎样改变样本学习动态和能力形成；在等 token 或等算力条件下，质量筛选的收益何时会被覆盖损失抵消？
3. 质量--效用映射在跨数据来源、跨领域和跨模型条件下哪些成分保持稳定，哪些需要重新校准；如何据此构建带适用边界和不确定性表述的评价方法？

## 文献调研需验证的判断

1. “更高质量”语料是否在等 token、等算力和不同训练阶段下均带来稳定收益。
2. 基于启发式规则、模型打分、困惑度、梯度或影响函数的数据选择方法分别测量了什么，是否存在共同盲区。
3. 强过滤对长尾知识、语言多样性和领域覆盖的损害是否已有可重复证据。
4. 现有研究是否真正建立了质量指标与训练效用之间的外部效度，而非只报告某一数据集、模型或基准上的相关性。
5. 中文语料的文字规范、语体差异和分词特性是否导致英文语料质量指标失效或需要重新校准。
