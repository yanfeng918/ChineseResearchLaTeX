# 科学问题与创新点：ACORE

## 调研摘要

本项目面向 CCF—快手大模型探索者基金课题 1.7，以 NSFC 模板组织正文，研究对象为执行长程多步骤任务的文本与工具调用智能体。项目暂无先导实验，以下假设、实验规模和成果均为拟开展研究，不能表述为已获验证。

**建议以候选 2 为中心，将创新收窄到压缩与证据变化共同作用时，有限资源在依赖保留和主动取证之间的分配规律。** 任务状态保真、可校验证据恢复、预算闭环调度构成三条相互支撑的研究路线。已有工作已经研究统一记忆、版本失效、动作依赖传播和重取成本；将这些功能组合起来不能单独构成创新。

**中心科学问题**：在上下文与累计调用预算同时受限、依赖和版本信息不完全可见的多步骤任务中，保留多少任务依赖、何时重新获取证据，才能使压缩后的动作仍有有效依据，并产生可重复的净收益？

对应三个子问题：

1. **R1，任务状态保真**：约束、未完成子目标和证据依赖的哪类缺失会引发后续动作错误，其影响如何随压缩程度、依赖跨度和环境可重查性改变？
2. **R2，可校验证据恢复**：当来源可定位但依赖或版本信息有缺漏时，何时可复用缓存、何时必须重新查询；哪些信息条件使主动取证相对简单版本过滤存在增益？
3. **R3，预算闭环调度**：计入压缩、索引、取证、校验、重算和失败重试后，上述策略在哪些条件下改善成功率与成本的关系，在哪些条件下应停止压缩或恢复？

## 多个科学问题-科学假设对

### 候选 1：任务依赖保留的条件效应

**科学问题**：同一压缩器和相同输出 Token 额度下，保留动作前置条件及其证据依赖，是否比等长结构摘要、相似度选择或随机保留有效事实，更能减少后续工具动作错误？

**可证伪科学假设**：在跨阶段依赖较强、关键证据不易从当前环境直接重观测的任务中，依赖感知保留能够降低压缩引起的动作失败；这种优势在低依赖或易重查环境中减弱。该假设不预设所有状态字段都有价值，也不预设信息选择必然优于随机有效事实保留。

**关键预测**：相同长度下，删去后续动作所需的依赖关系，比删去无关描述更容易造成前置条件错误；重新提供缺失依赖应部分恢复行为。若只恢复事实值就能恢复动作，则贡献应归于事实覆盖，而不能归于依赖结构。

**反证路径**：以成对轨迹删除、随机置换和事实覆盖匹配进行干预。若依赖选择与随机有效事实选择达到预设等效区间，或增益只存在于评估者提供完整理想依赖图时，应放弃“精细依赖选择具有必要优势”的主张。统计不显著仅表示证据不足，不直接证明等效。

**查新结论**：部分研究但关键缺口存在，修改后保留。ACON 已通过失败分析保留关键状态；AgentFold 已使用多尺度状态摘要，故“从文本转向状态”不能作为首次创新。[ACON](https://arxiv.org/abs/2510.00615)、[AgentFold](https://arxiv.org/abs/2510.24699)。近期受控研究还报告，在部分可查询状态条件下，有效事实覆盖比复杂选样更关键，这是本候选必须主动检验的反例。[压缩的交互成本研究](https://arxiv.org/abs/2608.16370)

**初步评价**：新颖性中等且取决于条件干预；重要性较高，可直接解释压缩失效；可行性较高，可冻结主模型，先采用显式工具参数和可审计轨迹，不以训练大型模型为前提。

### 候选 2：有限信息条件下的证据恢复与主动取证

**科学问题**：压缩删除部分动作依赖且证据随后变化时，有限上下文应优先保留哪些可验证线索；在版本信息不完全可见但当前状态仍可查询的条件下，何时主动取证优于沿用现有缓存失效规则？

**可证伪科学假设**：在同一主模型、相同原文存储、相同环境信息权限和总预算下，适度保留动作—证据依赖，并根据依赖缺口选择重查的策略，在存在局部证据变化、迟用证据和元数据缺漏的条件域，能够比“同等预算的状态压缩＋确定性失效规则”取得更高的任务成功率，或在成功率达到预设非劣标准时降低总取证代价。完整可靠元数据条件下，简单失效规则可能已足够；完全不可观察的新状态也不能由本方法保证恢复。

**关键预测**：依赖保留与有效性检查的作用应随压缩程度、更新方式和可查询性而变化；真实信息获取不足时，多轮自我校验不能代替外部取证。当依赖元数据更完整时，额外主动取证的边际价值可能下降；当元数据严重缺失时，保留结构本身也可能失去价值。预期关系允许出现平台区间或反转，不预设单调改善。

**反证路径**：以“依赖保留有／无×有效性检查有／无”构成核心因子实验，并与近邻工作的强组合比较。联合方法优于任一单项只证明组合收益；若要声称互补，还须检验加性尺度的交互效应。若在相同事实覆盖、候选证据和调用额度下，强组合或简单重查规则进入预设等效区间，应撤回增量机制主张；若只有使用不可部署的理想元数据才有收益，则可行性假设不成立。

**查新结论**：原始“依赖＋版本恢复”表述已被高度覆盖，收窄后按“部分研究但关键缺口存在”保留。MemGPT 与 ReadAgent 已支持外部回取；MemStrata 已研究时态有效性；PLACEMEM 已提出依赖传播与失效控制；这些均是直接先例。[MemGPT](https://arxiv.org/abs/2310.08560)、[ReadAgent](https://arxiv.org/abs/2402.09727)、[MemStrata](https://arxiv.org/abs/2606.26511)、[PLACEMEM](https://arxiv.org/abs/2607.04089)

更近的 Invalidation Contracts 已把版本、行级失效、依赖向量和有效性—应用行为联系起来；Dependency-Guided Rollback Repair 已连接记忆、动作及选择性重放。因此本项目的待检验部分是**压缩造成依赖信息不足时的资源配置与条件效应**，不能写成首次将记忆有效性扩展到动作。[Invalidation Contracts](https://arxiv.org/abs/2609.00243)、[Dependency-Guided Rollback Repair](https://arxiv.org/abs/2608.10502)

**初步评价**：潜在增量尚待同信息、同预算强对照确认，竞争风险较高；重要性较高，直接连接恢复信息与真实执行；可行性中等，以公开可执行环境和显式可查询状态为核心，不依赖企业数据落实，不承诺无元数据条件的普遍保证。

### 候选 3：预算控制的适用区间

**科学问题**：在有限元数据条件下，计入所有运行开销后，状态与风险感知调度在哪些任务区间优于仅基于窗口余量的压缩调度？

**可证伪科学假设**：当任务足够长、工具结果冗余较高且部分证据可复用时，对“保留、压缩、卸载、恢复、重查”进行可解释调度可获得条件性的成功率—成本改善；短任务、低冗余或频繁变化环境可能使额外管理开销超过节约。规则应能在留出的任务家族识别部分增益区和退化区，而非只拟合开发集。

**关键预测**：固定主模型下，净收益随元数据可见性和重取代价改变；仅减少主代理窗口 Token 不必然减少累计 Token 或时延。关闭恢复、固定周期压缩、每步校验和全量重查分别暴露不同的开销来源。

**反证路径**：将压缩器、检索器、校验器和失败重试全部计费，测量从任务开始到成功或失败终止的代价。若计入这些成本后优势消失，或只在同一任务模板内存在，应否定一般化收益主张。窗口容量、累计调用额度和端到端时延分别约束；不能用任意权重把成功率下降掩盖成“综合收益”。

**查新结论**：部分研究但关键缺口存在，修改后保留为候选 2 的边界研究。ContextBudget 已将窗口预算作为顺序决策状态；ACON 已讨论压缩开销；Invalidation Contracts 与压缩交互成本研究也已经分析失效维护及重取代价。本项目不能将“显式预算”或“计入成本”本身宣称为新颖性。[ContextBudget](https://arxiv.org/abs/2604.01664)、[ACON](https://arxiv.org/abs/2510.00615)、[Invalidation Contracts](https://arxiv.org/abs/2609.00243)、[压缩的交互成本研究](https://arxiv.org/abs/2608.16370)

**初步评价**：单独新颖性偏低，与候选 2 联合后可形成明确条件问题；重要性较高，可避免表面效率收益；可行性较高，先用阈值策略和小型价值估计器，训练成本作为独立一次性开销报告。

### 候选 4：统一压缩、卸载与记忆管理

**科学问题**：将短期压缩与长期记忆操作统一到同一策略，能否普遍优于独立模块？

**可证伪科学假设**：在多个任务和同等资源预算下，统一策略相对独立管理提高任务成功率；若等参数、等训练数据和等调用预算后优势消失，或仅来自某个单独模块，则统一性收益主张被削弱。

**关键预测**：收益应跨任务持续，并与操作协调有关；去除统一策略而保留各模块时，表现应有稳定变化。

**反证路径**：等训练投入的统一／独立策略对比，固定主代理并开展逐模块消融；训练规模与主模型改变不能混入统一性归因。

**查新结论**：作为宽泛命题已充分研究，淘汰其核心创新资格。AgeMem 已把存储、检索、更新、摘要及丢弃统一为策略动作；Memory-R1 已学习记忆管理与利用；MemGPT 与 AgentFold 也提供相关管理基础。[AgeMem](https://arxiv.org/abs/2601.01885)、[Memory-R1](https://arxiv.org/abs/2508.19828)

**初步评价**：当前表述新颖性低；作为系统实现重要，作为科学问题过宽；完整端到端训练在一年期、无先导资产的条件下投入较大。保留为方法组合与实验参照，不作为一条额外研究路线。

## 为什么选择这些科学问题-科学假设对

四个候选依次覆盖状态信息丢失、取证有效性、运行成本和系统统一性。前两项说明信息为什么影响后续动作，第三项检验改进何时值得使用，第四项用于排除已被充分覆盖的宽泛主张。现有材料支持通用工具智能体的研究定位，申请人的检索、结构化推理和系统研发积累可支持方法实现；这些基础不能被写成已经完成 ACORE 专属实验。

选择候选 2 是因为它能把三条路线连接为一项可做反证的研究：R1 输出可追溯的有限状态，R2 在证据变化时检验其可用性，R3 决定是否继续保留或重新获取。每条路线都允许独立失败，不能在某一模块没有增益时以总系统复杂度代替贡献。

## 最佳科学问题-科学假设对

**最佳选择**：候选 2，有限信息条件下的证据恢复与主动取证。

**科学重要性**：解释“回取到了原文却仍然执行失败”的条件，并把有效性与可执行行为联系到同一实验。

**新颖性**：现有机制已覆盖版本、依赖与回放；可争取的增量贡献是压缩与信息缺漏共同作用时的可检验资源分配规律，需要由强对照支持。

**可证伪性**：可通过定向删除依赖、控制证据更新及限定查询权限，分开识别状态覆盖、有效性判断和额外调用所产生的收益。

**可行性**：冻结主模型，以显式工具结果为切入点，可在已确认可用算力和公开环境上开展；企业环境用于条件性扩展。

**解释力**：同时解释成功、误用旧证据、冗余重查和超预算失败，而非只比较一个平均分。

**优化后的科学问题**：在有限上下文下，压缩后的依赖信息和当前环境的可观测性如何共同决定证据复用的有效边界，能否据此分配有限的保留与取证预算？

**优化后的可证伪科学假设**：对于“依赖元数据存在缺漏、当前状态可以有成本地重新查询”的多步骤任务，在相同可用信息与总预算下，依据依赖缺口调整保留和重查的策略存在可重复的适用区间；该区间之外应与简单策略相当或主动退回少压缩、直接重查。若强组合基线在预设容差内达到相同表现，或条件区间不能迁移到留出的任务家族，则不支持所提机制的增量优势。

该假设进一步要求区分**原始观察本来没有提供的元数据**与**原本可见、后来被压缩丢失的元数据**。在相同缺漏数量下，分别遮蔽跨阶段动作所需的依赖和与该动作无关的信息，检验缺漏位置及可重新查询程度能否预测“复用节约转为重取负担”的区间。区间及阈值必须在开发阶段确定，再用留出的任务家族验证；事后只挑选有利的更新频率不构成支持证据。运行策略只能使用已识别的前提缺口和已观察信号，不得读取实验者设置的隐藏缺漏率或未来变更。

**最关键的反证实验/观察**：

1. **同信息强对照**：ACON 式状态压缩分别结合时态过滤、细粒度失效和预算自适应重查，给予与 ACORE 完全相同的原文、真实可见版本信号和查询权限；统一开发数据、调参预算与可观察信号。预算分配实验允许强对照调用同一缺口识别结果并计入其成本，另用消融区分识别器和分配策略的贡献，避免把额外信息优势归给调度。
2. **局部干预**：固定事实内容与长度，遮蔽或置换动作依赖；另行控制有效性检查，比较联合效应及压缩前后变化。理想依赖标签只用于诊断参照，不能进入可部署方法。
3. **不可观测反例**：区分可靠元数据可见、元数据缺漏但当前状态可查询、两者均不可见三个条件层。第三层应报告无法识别和任务失败，不能把模型自信或多轮自检当成有效性证明。

**判定规范**：令 \(p_{dv}\) 表示同一预先固定任务分布中，依赖保留状态 \(d\) 与有效性检查状态 \(v\) 下的任务成功概率。若主张两者互补，预先指定加性尺度的交互量 \(I=p_{11}-p_{10}-p_{01}+p_{00}\) 和最小有意义幅度 \(\delta_I\)。区间下界超过该幅度才支持有实际意义的正交互；上界低于该幅度则反对相应主张；跨越该幅度时判为证据不足。不能事后更换效应尺度以获得显著性。交互成立与优于强组合是两个独立判断，必须分别报告。

局部机制实验在同一环境快照、同一决策点干预依赖线索，并采用等长度无关信息删减或关系置换作为对照；用于压缩前后比较的历史须在诊断窗口内均可容纳。真实闭环执行允许轨迹自然分叉，只匹配预算上限，不人为填充无效调用来配齐成本；轨迹分叉后的步骤不能继续视作相同的配对机会。

主结果以程序化环境终态和任务级成功率为准，过期证据驱动失败、证据召回和哈希一致为分层过程指标。环境真值由独立的状态快照和执行反馈确定，不能用待测校验器兼任裁判。多个种子、步骤及同一任务的扰动版本在任务内聚类；超时、拒答、预算溢出、恢复循环和无法处理均计入总体失败。版本校验仅针对检查时可观察的状态，不保证检查与执行之间没有新变化，该类竞态应单独记录。

同信息与同预算是对原始资料、接口权限和资源上限的约束，不能把未来答案或环境隐藏真值只给提出方法。完整可靠元数据条件是信息充足的诊断参照，不是任务性能的数学上界。累计 Token 覆盖全部辅助模型调用；非模型检索、存储、索引和校验另报实际时延与资源，离线训练和一次性构建单列。只有任务成功达到预先规定的非劣标准时，才把运行成本降低解释为效率收益。

确认性比较在开发阶段固定主要强对照及判断顺序：可选择任务成功率优效，或先检验成功率非劣、再检验累计成本降低；不得看到测试结果后在这两条路径中挑选有利者。其余窗口、模型和扰动格点用于预定的次要分析，并报告多重比较处理及区间宽度。自然闭环的成本取所有预注册任务直至成功或失败终止的开销，不只统计成功任务。

## 风险与下一步

**最大不确定性**：最新工作与本项目高度接近，存在简单组合已足够好的可能。早期比较若否定增量收益，应缩小方法贡献，保留经过严格验证的适用边界、失败规律与公开评测材料。

**最容易失败的地方**：依赖抽取错误；版本信息不可靠；评测者向方法泄露真实变更；预算统计遗漏辅助模型或重试；只在手工构造任务中出现收益。上述问题分别通过抽取错误分层、元数据缺漏压力测试、统一权限、逐调用计量和自然任务迁移缓解。

**最小下一步**：先在一类公开可执行工具环境构建 **【暂定 60—100 个开发实例】**，验证轨迹记录、局部证据变化和强组合基线是否可运行。这一批次用于估计效应量、标注误差和统计功效，不作为确认性验证集。随后冻结假设、容差、统计方案与调度参数，在独立任务家族验证；主路线不等待企业数据授权。

**一年期范围**：以 R2 核心反证实验为先，R1 与 R3 各保留一个可检验机制，先完成一个公开可执行环境、一个冻结主模型的最小闭环与独立验证。以 **【暂定 2 个主模型、3 档窗口预算、3 个随机种子】** 作为后续成本估算，最终样本量由开发阶段的方差与可负担预算确定；第二模型和第二环境在强组合基线、查询接口和确认性实验预算可承担后展开。人为注入的更新与自然任务分开报告，避免把多模型、多环境、所有变更与压缩比例做成无限全因子任务。

**成果判断**：计划产出可复现实现、记录真实证据来源的评测材料和机制分析。是否发表论文、获得专利或达到特定性能数值属于预期目标，不能写成保证；任何曲线、显著性或成功率必须等真实实验后绘制。
