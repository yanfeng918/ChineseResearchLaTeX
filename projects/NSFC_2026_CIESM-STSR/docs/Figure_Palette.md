# 全文配色决策

选择classic家族的Nature Blue，分支为scene：四个研究模块、气候科学方案、白底印刷与中文可读性。备选为纯深灰线条方案，适于黑白打印，本轮不混用。

| 语义 | 色值 | 双重编码 |
|---|---|---|
| 主模型、受约束输出 | #1B3A5C | 深色实边框，明确标题 |
| 资料输入、评价 | #2E6B9E | 中蓝实边框，位置和文字区分 |
| 辅助地形、可选分支 | #5BA0D0 | 浅蓝边框，条件性分支使用虚线 |
| 冻结条件 | #616161 | 灰边框与文字“固定” |
| 文字 | #333333 | 白底，不使用浅色小字 |
| 连线 | #4D4D4D | 主流实线，回聚合/可选虚线 |
| 画布及所有容器填充 | #FFFFFF | 无渐变、无阴影 |

四模块通过编号与标题辨认，不使用四色。色觉与灰度情况下仍依赖文字、位置和线型辨认。无照片/图标装饰，采用原生可编辑网格、矩阵和框线。所有图片沿用以上语义绑定。

交接：183mm设计宽度，16:9；Noto Sans CJK SC/Arial；标题11pt、主标签10pt、次标签9pt；容器1.5pt、内线1pt、主箭头1.5pt。图内仅exact_*内容，长公式和说明放正文/图题。全文采用同一规范，不因模块数量扩大色板。
