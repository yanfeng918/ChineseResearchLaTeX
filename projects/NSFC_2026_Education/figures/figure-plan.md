### F01 · 研究背景图

| 字段 | 内容 |
|------|------|
| **图号与中文标题** | F01 研究背景图 |
| **状态** | MANDATORY |
| **优先级** | P0 |
| **Prompt 文件名** | `prompts/01-research-background.md` |
| **建议长宽比** | 16:9 |
| **复杂度** | 中（4 个横向带、约 14 个元素） |
| **标书位置** | （一）1. 立项依据，1.3 现有研究不足之后、1.4 研究切入点之前 |

- **科学传达目的**：说明本项目**为什么必要**——从新疆新能源产业人才需求出发，经由课程多模态资源的固有特征与核心矛盾，收束到三条研究缺口与三个科学问题。
- **一句话结论（take-home）**：新能源课程的多模态材料不缺数量，缺的是“边界明确、条件正确、出处可查”的可教学使用资源，这一缺口构成本项目的科学问题起点。
- **为什么需要这张图**：立项依据横跨产业需求、资源特征、现状综述与三条不足，是全文因果链最长的一段；纯文字阅读需在四个抽象层级间反复跳转，图示可一次性建立“需求→矛盾→缺口→问题”的必然性。
- **标书证据来源**：1.1 研究背景与意义（新疆新能源产业人才需求；资源单元构成；“可检索但不可教学使用”）；1.2 国内外研究现状及发展动态分析（教育知识图谱 [1-8]、跨模态检索与图表理解 [9-21]、RAG 与事实核验 [22-31]、教育资源质量保障 [32-34]）；1.3 现有研究不足（三条）；1.4 研究切入点。
- **核心科学概念**：产业任务知识与课程知识是两类**可比较的约束**而非并列标签；关系成立需同时满足语义相关、对象与条件相容、关键结论可回溯到原始位置。
- **信息层级**：
  - L1：四条横向叙事带（需求 → 资源特征与矛盾 → 研究缺口 → 科学问题）
  - L2：带内并列条目
  - L3：条目内的具体错误类型示例文字
- **主要模块**：
  1. 带 A｜现实与产业需求
  2. 带 B｜课程多模态资源特征与核心矛盾
  3. 带 C｜现有研究进展与三条缺口
  4. 带 D｜本项目科学问题
- **模块内容与标签**：
  - **带 A**：`新疆新能源产业`；`需兼具能源工程 / 数据分析 / 人工智能素养的人才`；`高校新能源课程`
  - **带 B**：五类分散材料图标条 `设备图` `运行曲线` `数据说明` `实验代码` `工程案例`；中央矛盾框 `自动重组易出错：变量 · 单位 · 工况 · 图文关系 · 出处`；结论标签 `可检索，但不可教学使用`
  - **带 C**：三块现状卡片 `教育知识图谱：给出概念层级与资源归属` / `跨模态检索与图表理解：以语义相似为主` / `RAG 与事实核验：单点事实可核`，其下对应三块缺口卡片 `缺口一：缺资源单元层面的产业—课程联合约束` / `缺口二：变量·单位·工况·时序·来源缺失，无法区分检索命中与可支持教学关系` / `缺口三：内容·课程·模态·证据分散评价，缺独立效度`
  - **带 D**：三个科学问题短框 `SQ1 联合知识约束为何、在何条件下改善资源单元构建` / `SQ2 专业属性与来源位置如何共同决定跨模态关联正确性` / `SQ3 不依赖学生行为数据的资源内在质量如何获得独立效度`
- **逻辑关系**：A **驱动** B；B 的矛盾 **暴露** C 中现有方法的能力上界；C 的三条缺口 **一一收敛** 到 D 的三个科学问题（缺口 i → SQi，严格三线对齐）。
- **箭头/连接线语义**：
  - 粗实心向下箭头 = 叙事推进（A→B→C→D）
  - 细实线一对一箭头 = 缺口到科学问题的严格映射（三条平行线，不交叉）
  - 虚线短箭头 = 现状卡片指向其能力边界标注
  - 不使用双向箭头、不使用回环
- **阅读方向**：自上而下（主）；带内自左向右（次）
- **推荐构图**：四层水平泳道，等宽满幅；带 B 使用居中强调框；带 C 采用上下两排三列对齐（现状排 / 缺口排）；带 D 三框与带 C 缺口列严格垂直对齐，形成视觉“漏斗收束”。
- **有意排除的内容**：任何方法步骤、模型名称、公式、指标、技术路线元素；参考文献编号；学生数据/推荐/学习效果相关任何表述。
- **与近邻图的差异**：
  - vs F02：F01 只到“科学问题”为止，不出现研究内容模块、目标或验证体系；F02 从科学问题之后开始。
  - vs F03：F01 无任何执行步骤与数据流。
- **冗余与歧义风险**：① 易被误做成方法流程图 → prompt 中必须显式禁止出现处理步骤与模型；② 带 C 若堆砌文献编号会喧宾夺主 → 只保留三类方法族名称，不写文献序号；③ 缺口与科学问题必须三线严格对齐，错位会破坏“必然性”论证。

- **为什么需要这张图**：这是全篇的概念中枢。标书用 2.1/2.2/2.3/4.2–4.4 四处分别陈述内容、目标、问题与创新，四者的 1:1 对应关系散落在不同页，只有图示能一次呈现该对位矩阵。

- **信息层级**：
  - L1：五个功能区（输入 / 三项研究内容主链 / 关键科学问题带 / 研究目标 / 统一验证体系）
  - L2：每项研究内容内的 2–3 条关键要素
  - L3：创新点角标与目标指标标签
- **主要模块**：
  1. 左侧｜受控资源输入区
  2. 中部｜研究内容主链（RC1 → RC2 → RC3）
  3. 中部下方｜关键科学问题带（SQ1 / SQ2 / SQ3）
  4. 右侧｜研究目标区
  5. 底部｜统一验证体系带
- **模块内容与标签**：
  - **输入区**：`受控资源输入`；来源合规条 `公开许可 / 明确授权 / 自主编写`；`“新能源数据分析与功率预测”示范课程模块`；4 个知识模块小标签 `运行数据与变量认知` `预处理与可视化` `预测建模与实验` `结果评价与工程案例`；模态条 `核心模态：课程文本 · 运行曲线/图表 · 设备结构图`、`扩展模态：实验代码 · 产业案例（单独报告）`
  - **RC1｜产业任务—课程知识联合约束的资源单元构建**：`产业任务知识 Kp` + `课程知识 Kc`；描述模式 `任务—对象—条件—知识点—片段—证据位置`；对照 `无知识 / 单一知识 / 联合知识`；创新角标 `创新点一`
  - **RC2｜专业属性与来源证据约束的跨模态资源关联**：属性条 `对象 · 变量 · 单位 · 工况 · 时间窗口 · 来源位置`；关系类型 `解释 / 实例 / 计算实验 / 对照 / 出处支持`；准入条件 `语义 ∧ 专业条件 ∧ 证据位置`；创新角标 `创新点二`
  - **RC3｜资源内在质量的四层联合验证**：四层标签 `内容 · 课程 · 模态 · 证据`；`任一层严重错误即拒绝`；创新角标 `创新点三`
  - **科学问题带**：`SQ1 联合知识约束的增量作用与适用边界` / `SQ2 专业属性与来源位置对关联正确性的共同决定机制` / `SQ3 不依赖学生行为数据的资源内在质量独立效度`
  - **研究目标区**：`总体目标：揭示三类约束对资源构建质量的作用机制，形成可验证、可追溯的构建与质控方法`；`目标一 边界/覆盖/属性一致性增量` `目标二 Recall@1·Recall@5·MRR·关系 F1·来源定位准确率` `目标三 VRR 主指标 + 五维盲评 + Krippendorff's alpha + 修订时间`
  - **验证体系带**：`受控输入与统一标注` `B0–B3 对照` `逐项消融` `跨来源留出` `独立专家盲评` `负结果如实报告与边界界定`
  - **范围声明角标**：`不含学生画像 · 学习行为分析 · 个性化推荐 · 学习效果预测 · 生产平台接入`
- **逻辑关系**：输入 **供给** RC1；RC1 输出的资源单元 **成为** RC2 的关系判定对象；RC2 写入的关系 **进入** RC3 的质量门控；三项内容 **各自锚定** 对应 SQ 与目标；验证体系 **横向贯通** 三项内容（不是接在 RC3 之后的末端环节）。
- **箭头/连接线语义**：
