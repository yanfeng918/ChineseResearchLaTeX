# 课题二独立申请书LaTeX正式装配报告

## 1. 独立申请书口径修正说明

课题二“跨境物流智能感知与弱网环境通信技术研发”单独形成一册申请书，本册固定栏位全部用于课题二，不再为课题一、课题三预留版面。课题一仅作为货物身份、单证识别和多语种结构化信息的输入方出现；课题三仅作为风险策略或授权请求的反馈方、现场状态数据的接收方和项目一体化平台集成方出现。课题二不承担跨企业运力调配、运输路径重构、应急资源配置及供应链计划重排。

上一阶段报告中有关“为课题一、课题三预留栏位”的判断只适用于当时的项目总稿假设，不再作为本册装配约束。本次在不改变字号、行距、固定坐标和表格结构的前提下，恢复了必要的技术问题、研究方法、验证思路、单位责任和实施节点；未为填满页面重复扩写。

## 2. 编译环境与生成文件

- 编译环境：Linux，XeTeX 3.141592653-2.6-0.999998，TeX Live 2026。
- 文档类与字体：`ctexart`，`fontset=fandol`；正文字号及行距沿用模板的14.17 bp/18.12 bp。
- PDF检查工具：Poppler `pdfinfo`、`pdftotext -layout`、`pdftotext -bbox-layout`、`pdftoppm`，并逐页检查渲染图。
- 本工程是独立固定页式自治区重点研发申请模板，不属于标准`projects/NSFC_*`产品线。构建沿用工程现有的两次XeLaTeX入口，没有调用NSFC产品线脚本，也没有修改公共包。
- PyMuPDF在当前环境不可用，文字坐标检查由Poppler完成。

预览构建命令：

```bash
xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory=build-task2-standalone main-task2-standalone.tex
xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory=build-task2-standalone main-task2-standalone.tex
```

正式构建命令：

```bash
xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory=build-task2-final main.tex
xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory=build-task2-final main.tex
```
