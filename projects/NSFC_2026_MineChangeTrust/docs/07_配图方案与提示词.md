## 三、配色决策

**分支：scene**（框架图 6 模块触发「≥4 模块用单色系」硬规则）。style family = **classic**（box-border），非 pastel。

```yaml
palette: Nature Blue + single warm alert accent
primary:    "#1B3A5C"   # 骨干 / 模型 / 核心      —— 1.5pt 实线粗边
secondary:  "#2E6B9E"   # 约束 / 损失 / 监督      —— 1.5pt 虚线边
tertiary:   "#5BA0D0"   # 数据 / 输入            —— 1.0pt 细实线边
gray:       "#8EAEC4"   # 冻结 / 锁定            —— 虚线边 + [Fixed] 药丸
accent:     "#E69F00"   # 误差 / 反例 / 禁止      —— 边框与斜纹，禁作文字
text:       "#333333"
fill:       "#FFFFFF"
section_bg: "#F7F7F7"
border:     "#CCCCCC"
arrow:      "#4D4D4D"
max_chromatics_per_figure: 3
white_canvas_ratio: ">=70%"
```

### 两条硬性可读性约束

**1. 灰度塌陷** —— 实测感知亮度：`#1B3A5C` ~21%、`#2E6B9E` ~40%、`#5BA0D0` ~61%、`#E69F00` ~66%、`#8EAEC4` ~68%。后三者在黑白打印下几乎不可分，因此**必须双编码**：浅蓝＝细实线、灰蓝＝虚线＋`[Fixed]`药丸、橙＝斜纹＋⚠形状。F4 的四臂另用 4×4 掩码缩略图区分，F5 的选中窗口用斜纹而非填充色。

**2. 橙色禁止作文字** —— `#E69F00` 对白底对比度仅 ~2.3:1，低于 4.5:1。只能用于边框、标记、斜纹；文字一律 `#333333`。
