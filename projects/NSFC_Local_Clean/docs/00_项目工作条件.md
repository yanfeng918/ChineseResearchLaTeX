# 项目工作条件

## 2 工作条件

### 2.1 研究团队与学科基础

本项目依托新疆大学计算机科学与技术学院（网络空间安全学院）开展。学院组建于2001年，依托的计算机科学与技术学科为国家“双一流”建设学科，也是自治区重点建设的国家级学科，在新疆信息科学领域具有较强的人才培养、科学研究和社会服务基础。

学院现有教职员工137人，其中教授22人、副教授41人，在校博士研究生120余名、硕士研究生1100余名，形成了结构合理、层次完整的科研与人才培养队伍。学院现有全国高校黄大年式教师团队1个、自治区教学团队1个、自治区创新团队3个，并拥有中国工程院院士、国家杰出青年科学基金获得者、长江学者讲座教授、国家百千万人才工程人选、教育部新世纪优秀人才以及自治区“天池”“天山”系列高层次人才等一批骨干教师，为项目实施提供了良好的人才与学术支撑。

计算机科学与技术学科围绕**多语言多模态认知计算与内容安全、信号检测与智能处理、大数据分析与智能控制**等方向持续开展研究，在人工智能、自然语言处理、多模态智能、大数据分析、智能计算和信息安全等领域形成了较为扎实的研究积累，与本项目拟开展的相关研究具有较高的学科契合度。

学院具有完整的本、硕、博人才培养体系，拥有计算机科学与技术一级学科博士学位授权点和博士后科研流动站，以及计算机科学与技术、信息与通信工程一级学科硕士学位授权点和计算机技术、新一代电子信息技术等专业学位硕士授权点，可为项目持续提供博士、硕士研究生等科研力量。

### 2.2 科研平台与协同条件

学院已建设形成较为完善的科研平台体系，现有科研用房面积1万余平方米。主要科研平台包括：

- 教育部丝路多语言认知计算国际合作联合实验室；
- 鹏城实验室新疆网络节点（新疆网点）；
- 新疆多语种信息技术重点实验室；
- 新疆信号检测与处理重点实验室；
- 国家语委新疆多语种信息技术研究中心；
- 新疆多模态智能处理与信息安全工程技术研究中心。

学院还建有多个自治区级研究生联合培养基地，与中国移动新疆分公司、华为技术有限公司、中国电信新疆分公司、国网新疆电力有限公司信息通信公司、数字新疆产业投资集团有限公司等单位建立了长期合作关系，并建设有50余个校企联合科研实践基地，可为项目开展数据资源协同、技术验证、成果转化和研究生联合培养提供支撑。

国家语言文字推广基地（新疆大学）拥有教授13人、副教授25人，其中25人具有博士学位；现有普通话水平测试员15人，其中国家级测试员4人、自治区级测试员11人，另有8名教师持有国际汉语教师证书或对外汉语教师资格证。相关师资和平台条件可为涉及多语言、多民族、多模态数据处理、语言资源建设及应用验证的研究任务提供协同支持。

### 2.3 人工智能计算与实验条件

新疆大学计算机科学与技术学院建有较为完备的人工智能计算平台和智能计算机房。人工智能计算平台主要位于工程研究中心大楼108室和206室，使用面积合计约321平方米，自2019年开始建设，并于2020年正式投入使用。

依托国家“双一流”建设经费及各类科研项目经费，计算机科学与技术学科在基础设施及软硬件方面累计投入8000余万元。其中，人工智能算力中心建设投入超过5100万元。现有服务器和工作站210余台（件），包括“双一流”建设经费购置服务器130余台（件）以及科研项目经费购置并托管的服务器80余台（件）。

现有计算资源覆盖：

- CPU大数据计算型服务器；
- GPU通用计算型服务器；
- GPU人工智能训练服务器；
- GPU推理服务器；
- NPU专业计算服务器；
- 通用业务管理服务器及工作站。

目前平台拥有GPU/NPU等各型人工智能加速卡600余块，人工智能计算能力达到百P级规模，最新平台统计的FP16算力约为140P，可较好满足深度学习、大模型、多模态学习、计算机视觉、自然语言处理、语音处理、时间序列分析及其他大规模人工智能实验的计算需求。

此外，平台配置华为Atlas 800/9000系列计算与推理服务器8台，组成计算微集群，并作为鹏城实验室新疆网络节点接入鹏城云调度平台，可进一步获得跨平台计算资源调度能力。

2025年，依托教育部丝路多语言认知计算国际合作联合实验室，学校采购了价值约170万元的A100服务器租赁服务，获得为期3年的A100八卡服务器使用资源，可为本项目开展大规模模型训练、参数优化、消融实验和多组对比实验提供稳定的高性能算力保障。

### 2.4 科研基础与项目实施能力

学院具有较强的科研项目组织和实施能力。近年来承担了国家科技重大专项、国家重点研发计划、国家自然科学基金以及省部级科研项目等多类国家和自治区科研任务。

近五年，学院获批国家科技重大专项1项，项目经费1.5亿元；获批国家重点研发计划项目2项，并承担国家自然科学基金重点、面上项目以及科技部和省部级项目等110余项，科研总经费约3.5亿元。

学院近年来取得了一批具有代表性的科研成果，先后获得国家科技进步二等奖2项、三等奖1项，中国产学研合作创新成果奖二等奖1项，自治区自然科学一等奖1项、二等奖1项，自治区技术发明一等奖2项，自治区科技进步一等奖3项、二等奖5项、三等奖3项，并获得多项自治区高校教学成果奖。学院在国内外高水平期刊和会议发表了大量研究成果，授权发明专利80余项，具备从基础研究、关键技术攻关到系统研发和成果转化的完整科研能力。

上述科研基础表明，依托单位具备较成熟的项目组织管理制度、稳定的科研队伍、完善的实验条件以及较丰富的国家和省部级科研项目实施经验，可为本项目顺利推进提供可靠保障。

### 2.5 项目实施保障

综合来看，本项目具备良好的实施基础：

1. **学科基础扎实。** 依托国家“双一流”建设学科，已形成多语言多模态认知计算、智能信息处理、大数据分析与智能控制等优势研究方向，与项目研究内容具有良好衔接。
2. **科研团队完整。** 学院拥有教授、副教授、博士后、博士生和硕士生构成的多层次科研队伍，高层次人才和创新团队能够为项目提供持续的学术指导与技术支持。
3. **科研平台完善。** 教育部国际合作联合实验室、省部级重点实验室、工程技术研究中心以及鹏城实验室新疆网络节点等平台，可满足项目在数据处理、算法研发、系统验证和成果转化等方面的需要。
4. **计算资源充足。** 现有600余块GPU/NPU加速卡、百P级人工智能算力以及A100八卡服务器等高性能计算资源，可支持大规模深度学习、大模型训练及多轮实验验证。
5. **项目实施经验丰富。** 学院长期承担国家科技重大专项、国家重点研发计划、国家自然科学基金及自治区重大科研任务，具备成熟的科研项目管理和组织实施能力。
6. **产学研协同条件良好。** 学院与通信、电力、数字产业及人工智能相关企业建立了稳定合作关系，并拥有多个研究生联合培养基地和校企科研实践基地，可为项目后续应用验证和成果转化提供支撑。

因此，依托新疆大学计算机科学与技术学院现有的学科、人才、科研平台、高性能算力和产学研合作条件，本项目具备良好的研究基础和充分的实施保障，能够满足项目研究、实验验证及成果形成的需要。
