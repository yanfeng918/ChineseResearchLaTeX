# PACT-Agent：选题与研究主题

研究输入为申请人补充的 `00_项目事实库.md`（2026-09-06），主题提取采用 research-topic-extractor。申报对象为 2026 CCF－百度松果基金，当前使用 NSFC 面上模板作为科研正文载体；正式申报表及附件另行对齐。

中文题目：**面向动态任务的大模型智能体参数高效自适应后训练与可信校准方法研究**。

英文题目：Parameter-Efficient Adaptive and Calibrated Training for LLM Agents under Dynamic Tasks（PACT-Agent）。

研究对象是任务、工具和反馈发生变化时持续后训练的语言模型智能体。研究单位为带有完整任务版本、工具日志、可验证结果和时间标记的多步交互轨迹。通用工具任务为主要验证对象，公开能源时序任务作为受控分布漂移补充环境；不扩展到真实金融交易、私有电网调度、多模态大规模预训练或未获授权的在线业务。

中心问题：在固定训练预算与有限记忆下，能否利用可验证轨迹证据协调参数适配、能力保持和行动校准，使持续学习后的任务收益不以旧能力退化或错误执行增加为代价？

三个子问题分别考察：任务漂移与可训练参数边际效用的关系；多源证据与轨迹训练价值的关系；记忆更新、策略变化与决策校准失效的关系。保留用户的四项研究内容与四条分路线，将参数记忆和经验记忆归于第三项、可信执行归于第四项，避免科学问题数量与实现模块数量机械对应。

核心机制链为：已有任务日志提供漂移证据 → 在累计参数和计算预算内选择适配器与低秩更新 → 用执行与验证证据建立轨迹训练权重 → 通过有界记忆保持旧任务能力 → 在独立校准集上确定行动选择门槛 → 将新产生的可验证日志用于下一轮更新。各轮冻结测试集；未知测试结果不能回流本轮训练或校准。
